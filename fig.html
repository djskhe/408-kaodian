中断响应三件事由硬件完成：关中断、保存断点（PC）、引出服务程序；保存现场与恢复现场由软件做。中断屏蔽字决定多重中断的嵌套顺序。

1.4 循环队列的下标关系

循环队列用取模把线性数组首尾接起来；判满有两种套路——牺牲一个单元（front==(rear+1)%m）或另设计数器，元素个数恒为 (rear−front+m)%m。

1.5 KMP 的 next 数组与滑动

next[j] 的含义是失配后模式串该跳到哪一位，主串指针不回退；手算口诀：看前 j−1 位的最长相等前后缀长度再加 1。
6计算机网络（新增）★★★2 图▼

1.1 曼彻斯特与差分曼彻斯特编码

曼彻斯特：0＝高→低、1＝低→高，每位中间必跳变，自带时钟但带宽翻倍；差分曼彻斯特：每位起始必跳变，位中间有跳变＝0、无跳变＝1，抗干扰更强。

1.2 IP 数据报分片

分片只切数据部分，每片都要重装 20B 首部；片偏移以 8B 为单位，故每片数据长度必须是 8 的倍数。

1.3 二级页表的地址变换

两级页表把页表本身也分页，每级索引 10 位、页内偏移 12 位；一次访存要 3 次访问主存（目录→页表→数据），TLB 命中后降到 1 次。
2计算机组成原理★★★5 图▼

2.1 存储层次结构

越往上越快越贵越小；Cache-主存由硬件解决速度，主存-辅存由软硬件共同解决容量

2.2 Cache 三种映射方式

冲突＝块号 mod 行数（组数）相同；直接映射比较器只要 1 个但命中率低，全相联命中率最高但要比较全部行，组相联是折中

2.3 虚拟地址到物理地址的转换

页内偏移全程不变，只换页号→页框号；TLB 命中 1 次访存，未命中 2 次，多级页表每多一级就多 1 次访存

2.4 五段流水线时空图

满流水后每周期出 1 条；总时间 = k + (n−1)，加速比 = n·k /(k+n−1)；瓶颈段（最慢段）决定流水线周期上限

2.5 程序查询 / 中断 / DMA 三种 I/O 方式

CPU 参与度：DMA < 中断 < 查询；查询方式 CPU 空转最浪费，DMA 由硬件控制器直接搬数据，只在开始和结束时打扰 CPU 一次
4数据结构★★★5 图▼

4.1 单链表插入与删除的指针变化

插入顺序：① s->next=p->next ② p->next=s，反了就断链；删除 p->next=q->next 后 free(q)，虚线为原指针

4.2 二叉树三种遍历

先序"根左右"、中序"左根右"、后序"左右根"；中序序列 + 先序/后序/层次任一即可唯一还原树

4.3 哈夫曼树构造

每次合并最小两权：5+7=12、8+11=19、12+15=27、19+25=44、27+44=71；WPL=(5+7+8+11)×3+(15+25)×2=173，编码无前缀

4.4 快速排序一趟划分

挖坑法：high 找小于枢轴者填 low 坑，low 找大于枢轴者填 high 坑，最后枢轴入位，落位后左边全小于它、右边全大于它；一趟只确定枢轴最终位置，不产生有序子序列

4.5 完全二叉树与数组的对应

结点 i 的左孩子 2i、右孩子 2i+1、父结点 ⌊i/2⌋，数组下标 1 起存才有此公式；结点 4、5 的下标正好是 2i=4、2i+1=5
1计算机网络★★★6 图▼

1.1 HTTP 请求与响应报文格式

请求行（方法+URL+版本）/ 状态行（版本+状态码+短语）+ 首部行 + 空行 + 实体主体；空行是首部结束的标志，绝不能省，否则服务器会一直等首部。

1.2 HTTP 三种连接方式的时间线

以取 3 个对象为例：非持久连接 = 每对象 2RTT（1RTT 建 TCP + 1RTT 请求响应）；持久连接只建一次 TCP，非流水线仍要逐个等响应，流水线可连续发请求，只要 1RTT。

1.3 TCP 三次握手与四次挥手时序图

握手第三次的 ack=x+1 已能携带数据；挥手要 4 次是因为服务器收到 FIN 后可能还有数据要发（CLOSE_WAIT）。主动关闭方最后进入 TIME_WAIT，等 2MSL 才关闭。

1.4 TCP 拥塞控制 cwnd 曲线

慢开始 cwnd 每 RTT 翻倍，到 ssthresh 转拥塞避免（每 RTT +1）；3 个重复 ACK 走快重传快恢复：ssthresh=cwnd/2、cwnd=ssthresh 不回到 1；只有超时才 ssthresh=cwnd/2 且 cwnd=1 重来。

1.5 数据封装与解封装

每下一层就在前面加首部、尾部加 FCS，块越包越宽——封装；收方逐层剥掉首部（解封装）。记住常考字节数：TCP 20B、IP 20B、以太网首部 14B + 尾部 4B = 18B。

1.6 子网划分中的地址位分配

借主机位做子网位：网络位+子网位 = 新的网络前缀。借 n 位 → 前缀 /(24+n)，子网数 2ⁿ，每子网主机数 2^(剩余主机位)−2（去掉全 0 网络地址和全 1 广播地址）。
3操作系统★★★5 图▼

3.1 进程五状态转换

创建→就绪→运行→终止，运行态可转阻塞或就绪；阻塞态不能直接变运行态，必须先回就绪队列被重新调度

3.2 生产者-消费者 PV 流程

生产者先 P(empty) 再 P(mutex)，消费者先 P(full) 再 P(mutex)；两个 P 的顺序不能颠倒，否则持有锁等空位会死锁，V 顺序可交换

3.3 页面置换轨迹对比

引用串 7 0 1 2 0 3 0 4、3 个页框：FIFO 缺页 7 次、LRU 缺页 6 次（实心格为缺页装入）；第 5、7 次访问 0 命中，FIFO 淘汰最早进入者，LRU 淘汰最久未用者

3.4 磁盘调度磁道轨迹

起点 53，请求 98 183 37 122 14 124 65 67：FCFS 按到达顺序来回跑，共 640 磁道；SCAN 先向大号扫到最远请求 183 再折返，只需 299 磁道——纵轴向下是访问顺序，折线左右折返即方向

3.5 进程调度甘特图

P1(0,3)、P2(1,2)、P3(2,1)：FCFS 完成时刻 3/5/6，平均周转 3.67；SJF 在 t=3 选最短的 P3，完成时刻 3/4/6，平均周转 3.33 更优，但需预知服务时间且长作业易饥饿
5进阶图解★★★6 图▼

5.1 HTTP 状态码分类与缓存流程

记住五类语义：2xx 成功、3xx 重定向、4xx 客户端错、5xx 服务端错；缓存命中时服务器只回 304 空体，省的是流量不是时间。

5.2 RIP 距离向量路由更新

看图三步：先把 R2 的每个距离 +1（下一跳记 R2），再与本地表逐项取小，等于 16 表示不可达；只有变小的项才替换。

5.3 CSMA/CD 争用期与最小帧长

记住：2τ 是最坏情况下的冲突检测时间（A 发到最远端再传回），帧必须发得够长，10Mb/s 下 51.2μs 折合 64B 最小帧。

5.4 B 树插入分裂过程

看图记三步：插入找叶 → 叶满 取中位数上移分裂 → 根也满则根再分裂、树高 +1；1~7 插完根为 [4]，共 3 层。

5.5 Dijkstra 逐步求解过程

每轮只做两件事：在未确定顶点里挑 dist 最小的并入 S（表中加粗值），再用它松弛邻居；选中顺序即最短路径的生成顺序。

5.6 银行家算法安全性检查

看两列关系：Work 逐行下传（上一行 Work+Alloc 成为下一行 Work），只要有一轮所有进程都 Need > Work 就不安全。
