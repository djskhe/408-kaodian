错题复盘4 科
1数据结构★★★22 坑▼

复杂度与线性表

  • O(1) 的含义：把 O(1) 当成"只执行 1 次" ✗ → 指执行次数与 n 无关；O 只是上界，说"复杂度为 O(n²)"并不排除实际是 O(n)，问最坏/最好要看清。
  • 循环嵌套与并列：两段并列循环把次数相乘 ✗ → 并列相加取大者，只有真正嵌套才相乘。
  • 位序与下标：位序从 1 开始、数组下标从 0 开始，循环边界和移动个数都差 1 → 第 i 个元素下标是 i-1，插入位置 1..n+1 共 n+1 个。
  • 顺序表平均移动次数：插入平均移动 n/2 次、删除平均移动 (n-1)/2 次，不要一律记成 n/2；n 很大时都记 ≈n/2，但选择题给具体 n 必须精确算。
  • 头结点与判空：把表长算上头结点 ✗ → 头结点不计入表长，判空看 head->next==NULL，循环单链表判空看 head->next==head。
  • 链表删"给定结点"：直接改指针冒充 O(1) ✗ → 单链表必须先从 head 找前驱，是 O(n)；删除后要 free；链表不能折半查找，凡说"链表可二分"一律错。
  • 循环队列判满：判满写 front==rear 或容量记 MaxSize ✗ → 牺牲单元法最多存 MaxSize-1 个，判满 front==(rear+1)%MaxSize，元素个数 (rear-front+MaxSize)%MaxSize；共享栈是栈顶指针"相遇"即满，不是相等。

栈、队列与串

  • 中缀转后缀：括号优先级记反 ✗ → 左括号"栈内最低、栈外最高"，同级运算符按左结合先弹出；后缀求值先出栈的是右操作数，减法和除法极易算反。
  • KMP 的 next 数组：不看下标起点就套 next[1]=0 ✗ → 该式是"位序从 1 起"的教材约定；若数组下标从 0 起则 next[0]=-1、整体左移一位，数值全变，先看清起点否则整题作废。
  • 合法出栈序列数：答成 n! ✗ → n 个元素进出栈序列数为卡特兰数 C(2n,n)/(n+1)，n=3 时只有 5 种，判断题可用"某元素之后比它小的元素必须逆序"快速排除。

树与二叉树

  • 结点数公式混用：把 n₀=n₂+1 用在 m 叉树 ✗ → 它只对二叉树恒成立，度为 m 的树用 n₀=1+Σ(i-1)nᵢ；"高度 h 最多 2^h-1 个结点"同理，m 叉树是 (m^h-1)/(m-1)。
  • 序列还原：先序 + 后序去唯一确定二叉树 ✗ → 单孩子分支无法定左右，只有"先序+中序"或"后序+中序"才唯一，缺中序的题答"不唯一"。
  • AVL 调整：插入后一路向上逐个旋转 ✗ → 只调整自底向上遇到的第一个失衡结点所在的最小不平衡子树，一次旋转后整树即恢复平衡。

图

  • Prim 与 Dijkstra：把两者当同一个算法 ✗ → Prim 的 lowcost 是"到已选集合的最短边权"，Dijkstra 的 dist 是"从源点出发的累计路径长"，且 Dijkstra 一旦入 S 不再修改。
  • 唯一性判断：认为 MST 唯一 ✗ → 权值之和唯一但树形可能不唯一；BFS/DFS 序列、拓扑序列也不唯一，题面未指定存储结构时按顶点编号升序作答并注明前提。
  • 度与入度出度：邻接矩阵第 i 行之和当度用（有向图）✗ → 有向图行和是出度、列和是入度；无向图邻接表算出度容易、数入度必须建逆邻接表；DFS 空间 O(h)、BFS 空间 O(n)。

查找

  • 折半查找判定树：说它是完全二叉树 ✗ → 是平衡二叉树；失败结点共 n+1 个，失败 ASL 的分母是 n+1 而非 n。
  • 散列 ASL：套公式不算比较次数 ✗ → 必须按题目指定的探测方式逐个模拟，成功 ASL 分母是元素数；开放定址删除要打删除标记（直接置空会截断探测链）。
  • B 树与 B+ 树：认为插关键字就长高 ✗ → 只有根分裂才使树高 +1，删除只有"根只剩一个关键字且子女合并"才使树高 -1；m 阶 B 树非根结点关键字数 ⌈m/2⌉-1 ~ m-1。

排序

  • 快排最坏情况：说随机序列最坏 ✗ → 最坏是基本有序或逆序（退化为 O(n²)）；一趟划分只确定 1 个元素的最终位置，不能据此判断整个序列已排好。
  • 稳定性与空间：把快排、堆排、希尔、简单选择当稳定 ✗ → 这四个都不稳定，稳定的是插入、冒泡、归并、基数；基数排序空间是 O(r)，且必须稳定才能保证 LSD 正确。
  • 建堆代价：认为建堆是 O(nlog n) ✗ → 自底向上建堆是 O(n)，堆排序额外空间 O(1)，插入新元素放在末尾再上滤。
2计算机组成原理★★★22 坑▼

数据表示与运算

  • 容量计算：把 MAR 位数当容量 ✗ → MAR 位数决定单元数 2^n、MDR 位数决定存储字长，两者相乘才是总容量；按字编址与按字节编址的单元数差"字长/8"倍，地址线根数随之改变。
  • 主频与 MIPS：认为主频高就快 ✗ → CPI 与 IC 可能同时变差；MIPS 只能在同一指令集内比较，且反映不了浮点与 I/O，评价整机应用执行时间或 SPEC。
  • 浮点对阶：大阶向小阶看齐 ✗ → 小阶向大阶看齐，尾数右移丢低位；方向写反尾数左移会溢出；溢出只看阶码，阶码下溢按机器零处理不算溢出。
  • 补码溢出：把符号位进位当溢出 ✗ → 补码加法最高位进位被丢弃不等于溢出，溢出判据是"同号相加结果变号"或 V=C_s⊕C_1。
  • 大端小端：按内存图从左到右当数值高位 ✗ → 低地址存高字节是大端、存低字节是小端，x86 是小端；同一块内存按字节读与按字读的拼接顺序相反。

存储与 Cache

  • 透明性归属：把页面替换当成硬件做 ✗ → Cache 的映射、替换、写策略全由硬件完成、对程序员透明；虚存的页面替换与缺页处理由操作系统完成。
  • 直接映射取模：用字节地址取模求行号 ✗ → 行号 = 主存块号 mod 行数；块内地址位数 = log₂(块大小)，标记位数 = 主存地址位 − 行号位 − 块内位。
  • 平均访问时间：把"同时访问"和"缺失才访存"两个公式混用 ✗ → 后者会多算一次 t_c；缺失损失 = 块大小/主存带宽，别漏乘。
  • 写策略配对：写回配非写分配 ✗ → 写直达 + 非写分配、写回 + 写分配；写回法每行需脏位，写直达不必。
  • 低位交叉编址：认为交叉越多越快 ✗ → T = T_m + (m-1)τ 只在 m ≥ T_m/τ 时成立；高位交叉只是扩大容量，不提高带宽。
  • TLB 与 Cache：认为 TLB 命中就有数据 ✗ → TLB 只管地址转换、Cache 才管数据；命中率题里 TLB 命中与未命中都要计 TLB 访问时间。

指令系统

  • 基址与变址：两者混答 ✗ → 基址寄存器 BR 由操作系统设定、执行中不变而 A 可变；变址寄存器 IX 由用户改变而 A 不变；计算式相同、用途相反。
  • lea 与 cmp：把 lea 当访存指令 ✗ → 它只算地址不访问内存，常被编译器做快速算术；cmp 与 sub 唯一区别是不写回目的操作数，test 与 and 同理。
  • 相对寻址：偏移相对本条指令地址算 ✗ → 相对的是"下一条指令地址"（取指后 PC 已自增），跳转目标 = PC + A。

CPU 与流水线

  • 流水线收益：认为单条指令变快 ✗ → 提高吞吐率、缩短平均执行时间，单条指令时间不变甚至变长；加速比上限是流水段数 k，受瓶颈段制约。
  • 微程序与中断隐指令：把微程序当主存中的程序 ✗ → 微程序存放在控制存储器 CM（ROM）；中断隐指令由硬件完成，只保存 PC 与 PSW，通用寄存器由中断服务程序保存。
  • 断点与响应时机：认为断点保存本条指令地址 ✗ → 中断在一条指令执行结束后响应，保存的是下一条指令地址；取指周期一定访存。
  • 数据冒险：认为转发能解决一切 ✗ → 转发能解 RAW，但 load-use 必须停顿 1 拍；结构冒险是硬件资源冲突，与数据无关。

总线与 I/O

  • 总线方向与带宽：地址总线当双向 ✗ → 地址单向、数据双向；n 根地址线只给 2^n 个可寻址单元，容量还要乘存储字长；带宽单位 B/s 与 b/s 差 8 倍。
  • 链式查询：认为离控制器越远优先级越高 ✗ → 越近越高，且某一级故障会使其后所有设备都得不到总线；异步定时中"半互锁"是不等请求撤销，别与全互锁混。
  • 编址方式：两种编址混说 ✗ → 统一编址下端口就是主存单元、用访存指令；独立编址必须用 I/O 指令，地址位数与译码方式都不同。
  • 中断与异常：把缺页当外中断 ✗ → 中断是外中断、异常是内中断；缺页与除零是 fault 而非 abort；trap 是非特权指令，由用户态执行。
3操作系统★★★22 坑▼

进程与调度

  • 库函数与系统调用：把库函数当系统调用 ✗ → 库函数可能完全在用户态运行，只有系统调用才陷入内核；态切换必须成对计（进一次必有一次出），只数单向会少一半。
  • 状态转换：画"就绪→阻塞""阻塞→运行" ✗ → 阻塞是进程主动行为、唤醒是被动行为，这两个转换都不存在，状态图题先查这两条。
  • 三级调度：把中级调度当进程调度 ✗ → 中级调度是内存调度（对换），高级调度面向作业且频率最低，低级调度频率最高。
  • 调度指标：把周转时间算成运行时间 ✗ → 周转 = 完成 − 到达（含等待与阻塞），带权周转 = 周转/运行；响应比 = (等待+要求)/要求；SJF 平均等待最短但可能饥饿。

同步与死锁

  • P 操作次序：先互斥后同步 ✗ → 实现互斥的 P 必须放在实现同步的 P 之后，顺序反了会互相等待而死锁。
  • 让权等待：把 Peterson、TS、Swap 当满足让权等待 ✗ → 这三种都是忙等，只有记录型信号量与管程满足。
  • 信号量初值：同步信号量初值写 0 或 1 随手填 ✗ → 互斥信号量初值 1，同步信号量初值 = 初始可用资源数（缓冲空位数或初始产品数），填错整题作废。
  • 不安全与死锁：认为不安全就是死锁 ✗ → 不安全状态可能仍安全推进，死锁才一定不安全；有环不一定死锁，只有单实例资源时"有环即死锁"。
  • 四个必要条件：把"避免"与"预防"混为一谈 ✗ → 预防是破坏四个必要条件之一（静态策略），避免是银行家算法动态判断安全，检测靠资源分配图化简。

内存与置换

  • 虚拟内存容量：答成内存 + 外存之和 ✗ → 由逻辑地址空间与外存容量共同决定，二者取小（还要看实际配置）。
  • Belady 与碎片：认为 LRU 也会有 Belady 异常 ✗ → 该异常只出现在 FIFO 等非栈式算法；分页只有内部碎片、分段只有外部碎片。
  • 多级页表访存次数：漏算页表级数 ✗ → n 级页表无快表需访存 n+1 次（含最后取数据），有 TLB 命中则 1 次。
  • 页内偏移位数：把偏移位数与页表级数挂钩 ✗ → 页内偏移位数 = log₂(页大小)，与级数无关；每级页表项数 = 2^(该级索引位数)。
  • 缺页处理：认为缺页是外中断 ✗ → 缺页是内中断（异常），处理时若被换出页被修改过要写回（脏位），否则可直接覆盖。

文件与磁盘

  • 文件物理结构：三种分配张冠李戴 ✗ → 隐式链接只能顺序访问，FAT 是显式链接、可随机访问，连续分配支持随机但有外部碎片。
  • 位示图与成组链接：公式不管编号起点 ✗ → 位示图公式随"编号从 0 还是 1 开始"变化，题面未说明按 0 起算；成组链接的额外 I/O 只发生在取到组首块那一次。
  • 混合索引最大文件：只算直接块 ✗ → 直接、一级、二级、三级间接各自的块数分别乘块大小再相加，还要减去索引块本身占用的指针空间。
  • 硬链接与软链接：两者混说 ✗ → 硬链接是同一索引结点的多个目录项、计数值加 1，删除任一不影响数据；软链接是独立文件，删除原文件即失效。
  • 磁盘调度：把 SCAN 与 LOOK 混同 ✗ → SCAN 走到端点、LOOK 到最远请求；SSTF 平均寻道最短但可能饥饿；调度算法只缩短寻道时间，不改善旋转延迟与传输时间。
  • 访问时间：漏算旋转延迟 ✗ → 磁盘访问时间 = 寻道 + 旋转延迟（平均半圈 1/(2r)）+ 传输时间；格式化容量小于非格式化容量。

I/O 管理

  • CPU 干预频率：把通道与 DMA 的干预程度写反 ✗ → 由高到低是程序查询、中断、DMA、通道；中断以字为单位，DMA 与通道以数据块为单位。
  • DMA 数据通路：认为 DMA 完全不用 CPU ✗ → 数据不经 CPU 寄存器，但块首块尾仍需 CPU 干预（预处理与后处理）。
4计算机网络★★★20 坑▼

体系结构与物理层

  • 协议与服务：把协议说成上下层之间的约定 ✗ → 协议是"水平"的（对等层之间），服务是"垂直"的（上下层之间）；TCP/IP 把会话层、表示层并入应用层，故无此两层。
  • 时延构成：认为增大带宽能减小传播时延 ✗ → 发送时延 = 数据量/带宽、传播时延 = 距离/电磁波速度，彼此独立；求总时延别漏处理时延与排队时延；时延带宽积单位是比特不是字节。
  • 奈氏与香农：把奈氏准则的 V 当比特数 ✗ → V 是码元的离散状态数，C = 2W log₂V；香农用于有噪声信道 C = W log₂(1+S/N)，信噪比给的是 dB 必须先换成比值。
  • 带宽的含义：物理层"带宽"当比特率用 ✗ → 物理层指频带宽度（Hz），链路层"带宽"才是 b/s；曼彻斯特编码效率只有 50%。

链路层

  • 冲突域与广播域：认为集线器能隔离冲突域 ✗ → 集线器两者都不隔离；隔离冲突域靠交换机/网桥，隔离广播域靠路由器或 VLAN；多台集线器级联冲突域仍为 1。
  • 最小帧长：把前导码算进 64 B ✗ → 以太网最小帧长 64 B 从目的 MAC 算到 FCS，不含前导码 8 B，有效载荷最小 46 B。
  • 窗口上限：GBN 与 SR 窗口公式互换 ✗ → n 位序号时 GBN 窗口 2^n-1、SR 窗口 2^(n-1)，写反会收错帧。
  • 争用期：把争用期当发送时延 ✗ → 是往返传播时延 2τ，与发送时延无关；只有"发送时延 ≥ 2τ"才能在发送期间检测到冲突；全双工以太网无冲突，不再用 CSMA/CD。

网络层

  • 路由协议封装：三者端口/协议号混记 ✗ → RIP 用 UDP 520、BGP 用 TCP 179、OSPF 直接封装在 IP（协议号 89）；ARP 请求广播、应答单播，且不属于网络层。
  • 最长前缀匹配：认为"先到先得" ✗ → 按前缀最长匹配；默认路由 0.0.0.0/0 前缀最短，只在无其他匹配时才用；NAT 改写 IP 与端口号，不改 MAC。
  • 子网可用主机数：答成 2^主机位 ✗ → 要减 2（去掉全 0 网络地址与全 1 广播地址）；CIDR 聚合取最长公共前缀。
  • IP 分片：片偏移按字节算 ✗ → 片偏移以 8 B 为单位，除最后一片外每片数据长度必须是 8 的倍数；总长度字段含首部，MF/DF 含义别混。
  • 首部长度单位：把首部长度字段当字节数 ✗ → IP 与 TCP 的首部长度字段都以 4 B 为单位（IP 最小 5 即 20 B）；UDP 长度字段含 8 B 首部。

传输层

  • 流量控制与拥塞控制：把两者混为一谈 ✗ → 流量控制面向接收方缓存 rwnd，拥塞控制面向网络 cwnd，实际发送窗口取两者较小值；零窗口不等于连接关闭。
  • TIME_WAIT：认为双方都会进入 ✗ → 只有主动关闭方等 2MSL，被动方停在 CLOSE_WAIT（等应用关闭）。
  • 序号与确认号：把确认号当"已收到的最后一个字节" ✗ → 确认号是期望收到的下一个字节序号（ACK=n 表示 n-1 及以前已收到）；SYN 与 FIN 各消耗一个序号。
  • 拥塞窗口调整：两种丢包处理写反 ✗ → 超时：ssthresh=cwnd/2、cwnd=1 重新慢开始；收到 3 个重复 ACK：ssthresh=cwnd/2、cwnd=ssthresh 快恢复。
  • UDP 首部：认为 UDP 校验和必选 ✗ → UDP 首部固定 8 B，校验和可选（全 0 表示未使用），TCP 校验和必选；伪首部只参与计算、不传输。
