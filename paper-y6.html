1.线性表 L 含 n（n≥3）个元素，采用顺序存储方式保存，且仍有空闲存储空间。下列关于在 L 上进行插入、删除操作的叙述中，错误的是　。
I. 在表头插入一个元素，一定需要移动表中所有原有元素
II. 在表尾插入一个元素，不需要移动任何原有元素
III. 在表头删除一个元素，不需要移动任何原有元素
IV. 删除表中第 i 个元素（1≤i≤n），需要移动 n−i 个元素
A. 仅 IIIB. 仅 IC. 仅 II、IIID. 仅 III、IV
答案与解析
答案 A。解析 I 正确：在表头插入时，原第 1 至第 n 个元素都要后移一位，共移动 n 个元素。II 正确：表尾插入只需把新元素写到下标 n 处，不移动原有元素。III 错误：表头删除后，原第 2 至第 n 个元素都要前移一位，共移动 n−1 个元素——表头删除与表头插入同样要移动大量元素。IV 正确：删除第 i 个元素后，原第 i+1 至第 n 个元素各前移一位，共移动 n−i 个元素。易错：以为“删除比插入省事”（只有表尾删除才不移动）；把表头插入的移动个数算成 n−1；混淆“移动 n 个”与“移动 n−1 个”。
2.已知带头结点的双向链表的结点结构为 prior | data | next，指针 p 指向表中某个既非头结点也非尾结点的结点。下列语句序列中，能正确把 p 所指结点从链表中删除的是　。
A. p->next->prior = p->prior; free(p); p->prior->next = p->next;B. p->prior->next = p->next; p->next->prior = p->prior; free(p);C. p->prior->next = p->next; free(p);D. p->next->prior = p->prior; p->prior->next = p->next; p = p->next; free(p);
答案与解析
答案 B。解析 删除 p 需要让 p 的前驱指向 p 的后继、让 p 的后继指回 p 的前驱，两条指针都要改，然后才能释放 p。正确顺序是先把两条指针都改好再 free。其余选项的问题：第一条先 free(p) 再访问 p->prior，是在访问已释放的存储；第二条只改了前驱的 next，p 的后继仍指向 p，链从后往前就断了；第四条多执行了 p = p->next，实际释放的是 p 的后继而不是 p 本身。易错：以为双向链表只需改一条指针；free 之后继续访问 p 的域；把“删除 p”写成“删除 p 的后继”。
3.若二叉树 T 的中序遍历序列是 b, e, d, f, c, a, g，层序遍历序列是 a, b, g, c, d, e, f，则 T 的后序遍历序列是　。
A. e, d, f, c, b, g, aB. f, e, d, c, b, g, aC. e, f, d, c, b, g, aD. e, f, d, c, g, b, a
答案与解析
答案 C。解析 层序遍历的第一个结点 a 就是根。在中序序列中 a 把序列分成左子树 b, e, d, f, c 和右子树 g，故 g 是 a 的右孩子且无孩子。在层序剩余部分 b, g, c, d, e, f 中，属于左子树的第一个结点是 b，故 b 是 a 的左孩子；中序里 b 位于左段首位，说明 b 没有左孩子，其右子树的中序为 e, d, f, c。同理层序中属于该子树的第一个结点是 c，故 c 是 b 的右孩子；中序中 c 位于 e, d, f 之后，故 c 无右孩子，左子树中序为 e, d, f。层序中下一个是 d，故 d 是 c 的左孩子，e、f 分别是 d 的左、右孩子。还原后 T 为 a(b(_, c(d(e, f), _)), g)。后序遍历得 e, f, d, c, b, g, a。易错：把层序首元素当成根以外的结点；误认为 c 是 d 的右孩子；后序与中序、前序的访问次序记混；漏掉 b 没有左孩子、c 没有右孩子这两个空子树。
4.已知由 5 棵树组成的森林 F 中各棵树所含的结点个数分别是 2, 3, 4, 5, 7。若 F 中各棵树的排列次序任意，则与 F 对应的二叉树的高度至少是　。
A. 5B. 7C. 8D. 6
答案与解析
答案 D。解析 森林转二叉树用“左孩子右兄弟”规则：第一棵树的根成为二叉树的根，其余各棵树的根依次成为前一棵树根的右孩子。设各树按 i = 1…5 排列、高度为 h_i，则对应二叉树的高度为 max(h_i + i − 1)。含 n 个结点的二叉树最小高度为 ⌈log₂(n+1)⌉，故 5 棵树的最小高度分别为 2, 2, 3, 3, 3（对应结点数 2, 3, 4, 5, 7）。把较高的树排在前面以抵消 i−1 的累加，取 3, 3, 3, 2, 2，则 h_i + i − 1 依次为 3, 4, 5, 5, 6，最大值为 6。若按 2, 2, 3, 3, 3 排列则为 2, 3, 5, 6, 7，高度 7，更大。易错：直接把最大树高 3 当答案；忘记“其余树根成为右孩子”这一层次累加；用 5 棵树的结点总数 21 求高度。
5.已知二叉树 T 中 7 个叶结点 a, b, c, d, e, f, g 的权值分别是 1, 2, 4, 5, 8, 10, 12。当 T 的带权路径长度最小时，与权值为 8 的叶结点深度相同的叶结点是　。
A. 权值为 10 和 12 的叶结点B. 仅权值为 10 的叶结点C. 仅权值为 12 的叶结点D. 权值为 5 和 10 的叶结点
答案与解析
答案 A。解析 按哈夫曼算法合并：1+2=3；3+4=7；5+7=12；8+10=18；12+12=24；18+24=42（根）。由此得各叶结点深度：12（原权值）与内部结点 12 都是根 42 的孩子 24 的孩子，深度为 2；8 与 10 是 18 的孩子，深度为 2；5 与 7 是内部结点 12 的孩子，深度为 3；4 与 3 深度为 4；1 与 2 深度为 5。故与权值 8（深度 2）同深度的叶结点是权值 10 和 12。验算 WPL = 1×5+2×5+4×4+5×3+8×2+10×2+12×2 = 5+10+16+15+16+20+24 = 106，等于各非叶结点权值之和 3+7+12+18+24+42 = 106。易错：合并时没取最小的两个；把权值小的结点放到浅层；认为同权值的两个结点深度一定相同；用“权值之和”代替 WPL。
6.下列关于图的叙述中，错误的是　。
I. 有 n 个顶点的无向连通图至少有 n−1 条边
II. 有 n 个顶点的有向强连通图至少有 n 条边
III. 无向图的邻接矩阵一定是对称矩阵
IV. 用邻接表存储的有向图中，某顶点的入度等于该顶点边表中的结点个数
A. 仅 IB. 仅 IVC. 仅 II、IIID. 仅 III、IV
答案与解析
答案 B。解析 I 正确：n 个顶点的无向连通图至少是一棵生成树，含 n−1 条边。II 正确：n 个顶点构成一个环即可强连通，恰有 n 条边。III 正确：无向图中边 (i, j) 与 (j, i) 是同一条边，故邻接矩阵关于主对角线对称。IV 错误：邻接表中顶点 v 的边表结点个数是 v 的出度；入度必须扫描所有顶点的边表才能统计出来。易错：把“出度”与“入度”互换（这是本章最高频的错点）；认为强连通图至少需要 2n 条边；把有向图的邻接矩阵也当成对称矩阵。
7.用快速排序对下列序列进行升序排序，若每趟都以当前区间的第一个元素为枢轴，则时间复杂度为 O(n²) 的情形是　。
A. 序列已按降序排好，且每趟取第一个元素为枢轴时划分恰好均分B. 序列元素全部相同，且采用“挖坑填数”的一趟划分C. 序列已按升序排好D. 序列随机排列
答案与解析
答案 C。解析 以第一个元素为枢轴时，若序列已按升序排好，则每趟划分后枢轴都落在最右端（左子区间长 n−1、右子区间为空），递归深度为 n，总比较次数约 n²/2，退化为 O(n²)。这正是快速排序“最坏情况”，也是人们改用“取中值”或“随机取枢轴”的原因。易错：以为元素全部相同一定最坏（采用“挖坑填数”且两侧交替停止时，等值元素会被均匀分到两边，反而接近 O(n log n)，这正是三路划分要解决的问题）；认为快速排序平均与最坏都是 O(n log n)；把“已降序”也当成必然最坏（此时枢轴落在最左端，但本题该选项加了“划分恰好均分”的条件，故不成立）。
8.散列表的装填因子 α 越大，则　。
A. 发生冲突的可能性越小，平均查找长度越小B. 装填因子只影响空间利用率，不影响查找时间C. 平均查找长度与装填因子无关，只与散列函数有关D. 发生冲突的可能性越大，平均查找长度越大
答案与解析
答案 D。解析 装填因子 α = 表中已存记录数 ÷ 表长，它衡量表的装满程度。α 越大，表中空单元越少，新元素插入时探测到已占用单元的概率越高，冲突越多，平均查找长度 ASL 也随之增大。因此散列表的 ASL 是 α 的函数，而与表长 n 无直接关系——这正是散列表“用空间换时间”的体现。易错：以为表越长查找越快（ASL 取决于 α 而非 n）；把 α 与“冲突次数”直接等同（α 是概率性的度量）；忽略 α 可以大于 1（链地址法中）。
9.在中序线索二叉树中（ltag/rtag 为 1 表示线索、为 0 表示孩子），结点 p 有右孩子的充要条件是　。
A. p->rtag == 0B. p->rtag == 1C. p->rchild != NULLD. p->ltag == 0
答案与解析
答案 A。解析 线索二叉树中，若 rtag = 0，则 rchild 指向 p 的右孩子；若 rtag = 1，则 rchild 指向 p 在中序序列中的后继（是线索而不是孩子）。因此“p 有右孩子”的充要条件是 p->rtag == 0。注意 p->rchild != NULL 不能作为判据：当 rtag = 1 且 p 有中序后继时，rchild 也非空，但它指向的是线索。ltag 判断的是左孩子是否存在，与右孩子无关。易错：用 rchild 是否为空来判断（这是普通二叉树的做法）；把 tag 的含义记反；混淆中序前驱/后继线索的位置。
10.模式串 P = 「ababaa」（下标从 1 开始），则其 next 数组为　。
A. 0, 1, 1, 2, 3, 3B. 0, 1, 1, 2, 3, 4C. 0, 0, 1, 2, 3, 4D. 0, 1, 2, 3, 4, 5
答案与解析
答案 B。解析 next[j] 表示 P[1..j−1] 中最长相等前后缀的长度加 1（next[1] 规定为 0）。逐个计算：next[1] = 0；P[1..1] = 「a」无真前后缀 → next[2] = 1；P[1..2] = 「ab」无相等前后缀 → next[3] = 1；P[1..3] = 「aba」，最长相等前后缀为「a」（长 1）→ next[4] = 2；P[1..4] = 「abab」，最长相等前后缀为「ab」（长 2）→ next[5] = 3；P[1..5] = 「ababa」，最长相等前后缀为「aba」（长 3）→ next[6] = 4。故 next = 0, 1, 1, 2, 3, 4。易错：把 next[1] 写成 1 或 −1（取决于教材约定，本题按 0 计）；把 next[j] 理解为“以 j 结尾的最长相等前后缀长度”；忘记加 1；把前后缀算错（如把「abab」的相等前后缀当成「ab」以外的串）。
11.设栈 S 和队列 Q 的初始状态均为空，元素 a, b, c, d, e 依次进栈，每个元素出栈后立即进入队列 Q。若最终队列 Q 中元素的次序为 b, d, c, e, a，则栈 S 的容量至少是　。
A. 2B. 4C. 3D. 5
答案与解析
答案 C。解析 元素出栈的次序就是它们入队的次序，故出栈序列为 b, d, c, e, a。模拟：a 进栈（栈内 a）；b 进栈（a, b）；b 出栈入队（栈内 a）；c 进栈（a, c）；d 进栈（a, c, d）；d 出栈入队（a, c）；c 出栈入队（a）；e 进栈（a, e）；e 出栈入队（a）；a 出栈入队（空）。栈内元素最多时为 3 个（a, c, d），故容量至少为 3。易错：只算到「a, b」两个；把出栈序列误当成队列的输出次序重新排列；忘记元素必须先留在栈中才能实现“a 最后出栈”。

12.下列关于指令集体系结构（ISA）的叙述中，不属于 ISA 规定内容的是　。
I. 指令格式与寻址方式
II. 通用寄存器的个数与位数
III. 指令流水线的级数及每级完成的功能
IV. 是否支持虚拟存储管理
A. 仅 IB. 仅 II、IVC. 仅 IVD. 仅 III
答案与解析
答案 D。解析 ISA 是软件与硬件之间的接口，规定“机器能做什么”：指令格式、寻址方式、寄存器组织（个数与位数）、数据类型、是否支持虚拟存储、中断与异常的处理方式等都由 ISA 规定。而“流水线分几级、每级做什么”“是否采用超标量/超长指令字”属于微架构（计算机组成）的实现细节，同一套 ISA 可以有多种微架构实现，程序员的可见行为不变。易错：把“是否支持虚拟存储”当成操作系统的事（页表格式、TLB 属于实现，但“是否有虚拟存储机制”由 ISA 规定）；把流水线级数当成 ISA 内容（这是本题最高频的错点）；认为寄存器个数属于实现细节（它直接决定指令格式中寄存器字段的位数）。
13.对机器数 1010 0110B 先算术右移 3 位，再算术左移 2 位，最终结果是　。
A. 1101 0000BB. 1101 0011BC. 0101 0000BD. 0101 0011B
答案与解析
答案 A。解析 算术移位保持符号位不变：算术右移时高位补符号位，算术左移时低位补 0。原数 1010 0110B 的最高位为 1（负数），算术右移 3 位得 1111 0100B（符号位 1 逐位填充）；再算术左移 2 位得 1101 0000B（低位补两个 0）。用真值验算：1010 0110B = −90，−90 ÷ 8 = −11.25，向下取整为 −12 = 1111 0100B；−12 × 4 = −48 = 1101 0000B，一致。易错：把算术右移做成逻辑右移（高位补 0，得 0001 0100B，最终 0101 0000B）；以为“右移 3 位再左移 2 位”能还原（算术右移会丢失低位信息）；左移时忘记补 0 而补了符号位。
14.已知 float 型变量采用 IEEE 754 单精度浮点格式，采用就近舍入（中间值取偶数）方式。若 float 型变量 x 的值为 8.25，则 x 的机器数（用十六进制表示）是　。
A. 4108 0000HB. 4104 0000HC. 4084 0000HD. 4102 0000H
答案与解析
答案 B。解析 8.25 = 1000.01B = 1.00001B × 2³，故为规格化正数：符号位 S = 0；阶码 E = 3 + 127 = 130 = 1000 0010B；尾数（去掉隐含的整数位 1）为 00001 后面补 0 至 23 位，即 0000 1000 0000 0000 0000 000B。拼接：0 | 1000 0010 | 0000 1000 0000 0000 0000 000 = 0100 0001 0000 0100 0000 0000 0000 0000B = 4104 0000H。验算：尾数 00001 = 2⁻⁵ = 0.03125，1 + 0.03125 = 1.03125，× 2³ = 8.25，正确。易错：阶码忘记加偏移量 127（直接用 3）；把 8.25 的整数部分当成尾数（8.25 的二进制是 1000.01 而不是 1000.001）；尾数位数不足 23 位就停止补 0；把偏移量记成 128。
15.某计算机按字节编址，数据 Cache 共有 512 行，采用 4 路组相联映射方式，主存块大小为 64B。若要访问主存地址 8320 处的 4 字节数据，则该数据所在主存块对应的 Cache 组号是　。
A. 0B. 1C. 2D. 4
答案与解析
答案 C。解析 组数 = 行数 ÷ 路数 = 512 ÷ 4 = 128 = 2⁷，故组号占 7 位。主存块大小 64B = 2⁶，故块内地址占 6 位。主存块号 = ⌊8320 ÷ 64⌋ = 130。组号 = 主存块号 mod 组数 = 130 mod 128 = 2。用二进制验算：8320 = 0010 0000 1000 0000B，去掉低 6 位块内地址后块号 = 10000010B = 130，取低 7 位得 0000010B = 2，一致。易错：用“行数 512”直接取模（组相联要先用行数除以路数得组数）；用地址除以块大小后又忘了取模；把组号位数算成 9 位（2⁹ = 512，那是行数）；忽略块内地址位数导致块号算错。
16.在不考虑异常/中断处理和访存额外开销的前提下，下列关于数据通路结构与 CPI 之间关系的叙述中，正确的是　。
I. 单周期数据通路的计算机，其 CPI 等于 1
II. 多周期数据通路的计算机，其 CPI 大于 1
III. 理想流水线数据通路的计算机，其 CPI 等于 1
IV. 流水线数据通路的计算机，其 CPI 一定小于 1
A. 仅 I 和 IIB. 仅 I 和 IIIC. I、II、III 和 IVD. 仅 I、II 和 III
答案与解析
答案 D。解析 I 正确：单周期数据通路每条指令都在一个时钟周期内完成，CPI 恒为 1。II 正确：多周期数据通路把一条指令拆成取指、译码、执行、访存、写回等多个周期，不同指令占用的周期数不同且都大于 1，故 CPI 大于 1。III 正确：理想流水线（各段等长、无冲突、无停顿）在稳定状态下每个时钟周期完成一条指令，CPI = 1。IV 错误：流水线通过“重叠执行”提高的是吞吐率，稳定状态下每周期最多完成一条指令，CPI 不会小于 1。易错：把“加速比”与“CPI”混淆；认为流水线能让 CPI 小于 1；忽略“理想”这一前提而认为实际流水线 CPI 也恰好为 1（实际因停顿大于 1）。
17.与程序中断方式相比，DMA 方式的主要特点是　。

24.在时间片轮转调度算法中，若时间片设置得过大，则该算法将退化为　。

41.（13 分）某快递公司用带头结点的单链表 L 保存一批运单编号，结点类型定义如下：
typedef struct LNode {
　　int data;　　　　　　　// 运单编号
　　struct LNode *next;　　// 指向下一个结点
} LNode, *LinkList;
由于录入环节的失误，L 中出现了编号相同的重复结点。现要求设计尽可能高效的算法，删除 L 中所有重复的结点，使每个编号只保留一个（保留首次出现的那个结点），并释放被删结点的存储空间。要求：
（1）给出算法的基本设计思想。（4 分）
（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（7 分）
（3）说明你所设计算法的时间复杂度和空间复杂度。（2 分）
参考答案与给分点

（1）基本设计思想（4 分）
单链表只能顺序访问，无法像顺序表那样借助散列或排序在 O(n) 内完成去重。在不增加额外辅助空间的前提下，采用双重遍历：用指针 p 从第一个数据结点开始，依次把 p 所指结点当作“保留结点”；对每个 p，用指针 q 从 p 的后继开始向后扫描，同时用 pre 记录 q 的前驱。若 q->data 与 p->data 相等，说明 q 是 p 的重复结点，令 pre->next = q->next 后释放 q，并让 q 重新指向 pre->next（pre 不动）；否则 pre 与 q 同步后移。内层扫描结束后 p 后移一位，重复上述过程，直到 p 为空。这样每个编号只保留最先出现的那个结点，空间复杂度为 O(1)。

（2）算法（7 分）
void DelRepeat(LinkList L) {
　　LNode *p = L->next;　　　　　　　// p 依次作为“保留结点”
　　while (p != NULL) {
　　　　LNode *pre = p, *q = p->next;　// q 从 p 的后继开始扫描，pre 是 q 的前驱
　　　　while (q != NULL) {
　　　　　　if (q->data == p->data) {　// 找到与 p 编号相同的重复结点
　　　　　　　　pre->next = q->next;　// 从链表中摘下 q
　　　　　　　　free(q);　　　　　　　// 释放 q 的存储空间
　　　　　　　　q = pre->next;　　　　// q 指向新的后继，pre 保持不动
　　　　　　} else {
　　　　　　　　pre = q;　　　　　　　// pre、q 同步后移
　　　　　　　　q = q->next;
　　　　　　}
　　　　}
　　　　p = p->next;　　　　　　　　// 处理下一个保留结点
　　}
}

（3）复杂度（2 分）
外层对每个结点各做一次内层扫描，比较次数为 (n−1)+(n−2)+…+1 = n(n−1)/2，故时间复杂度 O(n²)；只用了 p、pre、q 三个指针变量，空间复杂度 O(1)。

易错点：① 单链表删除结点必须知道前驱，漏写 pre 就无法删除；② 删除 q 之后若写成 pre = q 再取 pre->next，会访问已释放的结点并漏掉后继结点；③ free(q) 之后不能再访问 q->data；④ 内层循环结束后外层 p 后移，但若 p 本身被删除（本题不会，因为保留的是 p 本身）则需另作处理；⑤ 若题目允许 O(n) 辅助空间，可用散列表把时间降到 O(n)，但本题强调“尽可能高效”且未给额外空间，应在设计思想中说明这是以时间换空间的权衡。

44.（13 分）题 44 图给出了第 43 题中计算机的简化单周期数据通路。图中 ALU 的两个输入端前各有一个多路选择器，写回寄存器堆的数据也经过一个多路选择器；控制单元根据 IR 中的 OP、func 等字段产生全部控制信号。图中未画出的控制信号 RegWr（寄存器堆写使能）在执行需要写回结果的指令时取 1，否则取 0。请回答下列问题。
（1）题 44 图中三个多路选择器分别由哪个控制信号控制？它们各自在什么情况下选择哪一路输入？（3 分）
（2）取指令阶段，PC、指令存储器、IR 之间的操作序列是什么？若该机按字节编址、指令字长 32 位，则每取完一条指令后 PC 的增量是多少？（3 分）
（3）执行 add R10, R8, R9 时，ALUAsrc、ALUBsrc、RegDst、MemtoReg、RegWr 的取值各是什么？（4 分）
（4）执行 lw R5, 16(R6) 时，上述 5 个控制信号的取值各是什么？此时符号扩展单元必须做符号扩展而不能做零扩展，为什么？（3 分）
参考答案与给分点

（1）（3 分）
① ALU 的 A 端多路选择器由 ALUAsrc 控制：ALUAsrc = 0 时选寄存器堆读出的 rs1 数据（运算类指令）；ALUAsrc = 1 时选 PC（用于计算转移目标地址，或取指阶段计算 PC+4）。
② ALU 的 B 端多路选择器由 ALUBsrc 控制：ALUBsrc = 0 时选寄存器堆读出的 rs2 数据（R 型运算指令）；ALUBsrc = 1 时选符号扩展后的 imm（lw/sw 计算有效地址、beq 做比较）。
③ 写回数据多路选择器由 MemtoReg 控制：MemtoReg = 0 时选 ALU 的运算结果（R 型运算指令）；MemtoReg = 1 时选数据存储器的读出数据（lw）。

（2）（3 分）取指令阶段的操作序列：
① PC 的内容送到存储器的地址输入端（经内部总线送往指令存储器）；
② 指令存储器按该地址读出 32 位指令，送入 IR；
③ 同时 ALU 以 ALUAsrc = 1 选 PC、ALUBsrc 选常数 4，计算出 PC+4，在时钟沿到来时写回 PC。
由于按字节编址、指令字长 32 位 = 4B，故每条指令占 4 个字节，PC 的增量为 4。（若按字编址，则增量为 1。）

（3）（4 分）add R10, R8, R9 是 R 型运算指令：
ALUAsrc = 0（选 R[8]）；ALUBsrc = 0（选 R[9]）；RegDst = 1（目标寄存器取 R 型的 rd 字段 = R10）；MemtoReg = 0（写回 ALU 的运算结果）；RegWr = 1（需要写回寄存器）。

（4）（3 分）lw R5, 16(R6) 是 I 型访存指令：
ALUAsrc = 0（选 R[6] 作为基址）；ALUBsrc = 1（选符号扩展后的 imm = 16，用于计算有效地址）；RegDst = 0（目标寄存器取 I 型的 rt 字段 = R5）；MemtoReg = 1（写回存储器读出的数据）；RegWr = 1（需要写回寄存器）。
必须做符号扩展的理由：imm 是 16 位带符号偏移量，可以为负数（例如 lw R5, −8(R6) 表示访问基址之前的数据）。若做零扩展，负数会被当成一个很大的正数，算出的有效地址完全错误；只有符号扩展才能保证正、负偏移都能得到正确的地址。（beq 的 imm 同为带符号偏移量，也必须符号扩展。）

易错点：① 把 RegDst 与 MemtoReg 的作用弄混（前者选“写到哪个寄存器”，后者选“写什么数据”）；② 认为取指阶段 ALUBsrc 也要选 imm（取指时用的是常数 4，与指令中的 imm 无关）；③ 忘记 PC 增量与“按字节编址 / 按字编址”及指令字长的关系；④ 认为 lw 的 RegDst 应为 1（R 型才取 rd 字段）；⑤ 说明符号扩展理由时只说“因为 imm 是补码”，没有指出负偏移这一关键后果。

45.（7 分）某系统采用基于抢占式优先权（优先权值越大优先权越高）和时间片轮转的 CPU 调度算法，仅在时钟中断发生时才能抢占 CPU，时钟中断间隔为 5ms。每当进程进入就绪队列时，其时间片大小均设置为 15ms。进程因时间片用完而再次进入就绪队列时，若其优先权值大于 0，则优先权值减 1；进程因优先权低被抢占 CPU 而再次进入就绪队列时，其优先权值不变。优先权相同时，先进入就绪队列的进程先执行。假设系统中有 3 个进程 P1～P3，各进程的到达时刻、初始优先权值、所需的 CPU 执行时间如题 45 表所示。请回答下列问题。

（1）在忽略时钟中断处理及 CPU 调度时间开销的情况下，在题 45 图中画出 0 ~ 45 ms 内的调度甘特图，并给出各进程的完成时刻与 CPU 调度发生的次数。（5 分）
（2）若将时间片由 15 ms 改为 10 ms，则 CPU 调度次数是增加、不变还是减少？（2 分）
参考答案与给分点

（1）（5 分）只在 5 ms 整数倍的时钟中断处进行抢占判断：
t = 0：P1、P2 同时到达，P2 的优先权 5 > P1 的 2，P2 开始运行（第 1 次调度）。
t = 5：时钟中断，P2 优先权仍最高，继续运行。
t = 10：时钟中断，P2 已运行 10 ms，正好执行完，P2 完成时刻 = 10 ms。同时 P3 到达（优先权 3）。就绪队列中有 P1（优先权 2，剩 20 ms）和 P3（优先权 3，剩 15 ms），P3 优先权更高，P3 开始运行（第 2 次调度）。
t = 15：时钟中断，P3 优先权 3 > P1 的 2，继续运行。
t = 20：时钟中断，P3 已运行 10 ms、剩 5 ms，优先权仍最高，继续运行。
t = 25：时钟中断，P3 的时间片 15 ms 正好用完且数据全部执行完毕，P3 完成时刻 = 25 ms。P1 开始运行（第 3 次调度）。
t = 25 ~ 45：P1 连续运行 20 ms，期间 t = 30、35、40 的时钟中断都没有更高优先权的进程可以抢占，故 P1 完成时刻 = 45 ms。
甘特图（题 45 图填法）：
P2：0 ~ 10 ms；P3：10 ~ 25 ms；P1：25 ~ 45 ms。
结论：P2 完成于 10 ms，P3 完成于 25 ms，P1 完成于 45 ms，CPU 调度共发生 3 次。

（2）（2 分）时间片改为 10 ms 后：
t = 0 ~ 10：P2 运行并完成（第 1 次调度）。
t = 10：P3 到达，优先权 3 > P1 的 2，P3 运行（第 2 次调度）。
t = 20：P3 已运行 10 ms，时间片用完，优先权减 1 变为 2，重新进入就绪队列；此时 P1 的优先权也是 2，但 P1 早在 t = 0 就已在就绪队列中，按“优先权相同时先入队者先执行”，P1 先执行（第 3 次调度）。
t = 30：P1 已运行 10 ms，时间片用完，优先权减为 1，重新入队；此时 P3 的优先权 2 > P1 的 1，P3 执行（第 4 次调度）。
t = 35：P3 剩余 5 ms 执行完毕，完成时刻 35 ms。
t = 35 ~ 45：P1 执行剩余的 10 ms，完成时刻 45 ms（第 5 次调度）。
故 CPU 调度次数由 3 次增加到 5 次（调度次数增加）。

易错点：① 把抢占判断放在任意时刻（本题只在 5 ms 时钟中断处判断）；② t = 0 时忘记比较 P1 与 P2 的优先权，直接让先到达的 P1 运行；③ 时间片用完时忘记优先权减 1；④ 第（2）问 t = 20 时忽略“优先权相同则先入队者先执行”，误让刚被降权的 P3 继续运行；⑤ 把“完成时刻”与“周转时间”混淆（周转时间 = 完成时刻 − 到达时刻，本题 P1 = 45、P2 = 10、P3 = 15）。

46.（8 分）某文件系统采用索引节点（inode）方式管理文件。磁盘盘块大小为 4KB，盘块号占 4B。索引节点表位于从 200 号盘块开始的 2048 个连续盘块中，索引节点号是索引节点在该表中的序号，从 0 开始编号。每个索引节点占 256B，其中包含 8 个直接地址项、1 个一级间接地址项、1 个二级间接地址项和 1 个三级间接地址项。磁盘块位图与索引节点位图分别用 1 位表示一个盘块、一个索引节点的占用情况（0 表示未占用，1 表示已占用）。请回答下列问题。
（1）索引节点号为 3000 的索引节点存放在磁盘的几号盘块中？（2 分）
（2）某普通文件 file 的大小为 200KB。若 file 的索引节点已调入内存，则读取 file 内偏移地址为 150000B 处的一个字节数据，最多需要访问几个盘块？这些盘块分别是什么？（3 分）
（3）该文件系统在磁盘空间足够大时最多能创建多少个文件？（2 分）
（4）若要删除一个非空目录 dir（dir 中含 3 个文件），则文件系统至少需要修改哪些元数据？（1 分）
参考答案与给分点

（1）（2 分）每个盘块可存放 4KB ÷ 256B = 16 个索引节点。索引节点号 3000 在索引节点表中的序号即 3000，3000 ÷ 16 = 187 余 8，故它位于索引节点表内的第 187 个盘块，即磁盘的 200 + 187 = 387 号盘块。

（2）（3 分）盘块 4KB，150000 ÷ 4096 = 36 余 2544，故该字节位于文件的第 36 个逻辑块（从 0 开始编号），块内偏移为 2544。
8 个直接地址项覆盖逻辑块 0 ~ 7；一级间接地址项指向的间接块可存放 4KB ÷ 4B = 1024 个盘块号，覆盖逻辑块 8 ~ 1031。逻辑块 36 落在一级间接范围内。
由于索引节点已在内存，最多需访问 2 个盘块：① 一级间接块（从中取出第 36 − 8 = 28 个表项，得到该数据块的盘块号）；② 该数据块（读出块内偏移 2544 处的那个字节）。

（3）（2 分）索引节点表共 2048 个盘块 × 16 个/块 = 32768 个索引节点，每个索引节点对应一个文件，故最多可创建 32768 个文件。（实际还受位图与磁盘容量的限制，但本题已说明“磁盘空间足够大”，故由索引节点数决定。）

（4）（1 分）至少需要修改：① 目录 dir 的索引节点（文件大小、链接计数、修改时间等）；② 其父目录中与 dir 对应的目录项（把该目录项删除）；③ 递归删除 dir 内 3 个文件各自的索引节点与所占数据块；④ 索引节点位图与磁盘块位图（把被释放的索引节点与盘块对应的位置 0）。

易错点：① 求索引节点所在盘块时忘记“从 0 开始编号”，少减或多加 1；② 逻辑块号从 0 开始，直接用 150000/4096 = 36.6 当成 37；③ 忘记“索引节点已在内存”这一前提，把读索引节点也算作一次访问；④ 把一级间接的覆盖范围算成 1024 个字节而不是 1024 个盘块号；⑤ 删除非空目录时只想到删除目录项，漏掉位图与递归释放文件。

47.（9 分）某公司部署了一个大模型推理服务平台。用户主机 C 通过浏览器向平台服务器 S 上传一个总长度为 4500B 的提示词数据文件，网络拓扑与相关参数如题 47 图所示。C 与 S 之间建立一条 TCP 连接，MSS = 1500B，接收窗口 rwnd 始终为 3000B，慢开始门限 ssthresh 的初始值为 8 MSS，拥塞窗口 cwnd 的初始值为 1 MSS。S 对收到的每个 TCP 段都进行确认，确认段不封装数据，整个传输过程中没有报文段丢失。请回答下列问题。
（1）C 与 S 建立 TCP 连接需要几次握手？C 发出的 SYN 段的序号 seq 是多少？C 收到 S 的 SYN=1、ACK=1 段后发出的确认段的确认序号 ack_seq 是多少？（3 分）
（2）该文件需要划分为几个 TCP 段？各段的序号范围分别是多少？（3 分）
（3）在发送这些段的过程中，C 的发送窗口如何变化？每次最多能连续发送几个段？（2 分）
（4）若忽略报文段的传输时延和处理时延，时间从 C 请求建立 TCP 连接时刻算起，则 S 确认已收到整个文件的时刻是多少？（1 分）
参考答案与给分点

（1）（3 分）需要三次握手。C 的 SYN 段不携带数据但占用一个序号，故 seq = 1000。S 的 SYN+ACK 段中 seq = 3000、ack_seq = 1001（表示期望收到 C 的下一个字节序号 1001）。C 发出的确认段 ack_seq = 3001（S 的 SYN 占用了序号 3000）。

（2）（3 分）4500B ÷ 1500B = 3 个 TCP 段。
第 1 段：seq = 1001，占用序号 1001 ~ 2500（1500B）；
第 2 段：seq = 2501，占用序号 2501 ~ 4000（1500B）；
第 3 段：seq = 4001，占用序号 4001 ~ 5500（500B）。

（3）（2 分）发送窗口 = min(cwnd, rwnd)。
初始 cwnd = 1 MSS，rwnd = 3000B = 2 MSS，故发送窗口 = 1 MSS，C 只能先发送 1 个段（第 1 段）。
收到第 1 段的确认后，cwnd 处于慢开始阶段、按“每收到一个确认 cwnd 加 1 MSS”增长，变为 2 MSS；此时发送窗口 = min(2 MSS, 2 MSS) = 2 MSS，C 可连续发送 2 个段（第 2、3 段），正好把剩余数据发完。
由于 cwnd 最大只到 2 MSS，始终小于 ssthresh = 8 MSS，故整个传输过程都处于慢开始阶段，不会进入拥塞避免。

（4）（1 分）时间线（单向传播时延 10 ms，RTT = 20 ms）：
t = 0：C 发送 SYN；
t = 10 ms：S 收到 SYN，发送 SYN+ACK；
t = 20 ms：C 收到 SYN+ACK，连接建立，随即发送第 1 段；
t = 30 ms：S 收到第 1 段，发送确认；
t = 40 ms：C 收到确认，cwnd 增为 2 MSS，发送第 2、3 段；
t = 50 ms：S 收到第 2、3 段，发送确认。
故 S 确认已收到整个文件的时刻为 50 ms（从 C 请求建立连接算起共 2.5 个 RTT）。

易错点：① 认为 SYN 不占用序号，把 ack_seq 写成 3000；② 段的序号范围用“1000 ~ 2499”这类写法（数据从 1001 开始，SYN 已占用 1000）；③ 把 rwnd 的字节数直接与 cwnd 的 MSS 数比较而不做单位换算；④ 认为 cwnd 会一直翻倍到超过 ssthresh；⑤ 计算时间时漏掉“C 收到 SYN+ACK 后才能发数据”，或把 RTT 与单向传播时延混淆。
