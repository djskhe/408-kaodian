题目

设 T 是一棵采用二叉链表存储的二叉树，root 指向根结点。设计一个算法，求结点 p 和结点 q 的最近公共祖先（LCA），要求时间复杂度 O(n)、空间复杂度 O(h)（h 为树高）。要求给出算法思想、C 语言实现与复杂度分析。

满分答案（照这个格式写）

（1）算法思想

采用后序遍历的递归框架。对以 root 为根的子树，先递归在左子树中找 p、q，再递归在右子树中找 p、q，最后根据两个返回值决定向上报告什么，共四种情况：

  • root 为空，或 root 就是 p 或 q：直接返回 root（空树返回 NULL；碰到 p/q 说明在该子树里找到了它）。
  • 左右子树返回值都非空：说明 p、q 分别位于 root 的两侧子树，root 就是最近公共祖先，返回 root。
  • 只有一个返回值非空：说明 p、q 都在那一侧（或只找到其中一个），把该非空结果原样向上传递。
  • 两个都为空：返回 NULL。

正确性关键：后序保证了"子树结论先出、当前结点后判"，第一次出现"左右都命中"的结点必是深度最大的公共祖先，即最近公共祖先。全过程每个结点只被访问一次，递归栈深度不超过树高，故时间 O(n)、空间 O(h)。

（2）算法实现（考场只写这一段）

/* 二叉树结点类型 BiTNode/BiTree、root、p、q 题目已给出，直接使用 */
BiTNode *LCA(BiTree root, BiTNode *p, BiTNode *q) {
    if (root == NULL || root == p || root == q)   /* 边界：空树，或先碰到 p/q */
        return root;

    BiTNode *left  = LCA(root->lchild, p, q);     /* 左子树里找 */
    BiTNode *right = LCA(root->rchild, p, q);     /* 右子树里找 */

    if (left != NULL && right != NULL)            /* p、q 分居两侧 → root 就是 LCA */
        return root;
    return (left != NULL) ? left : right;         /* 否则把非空的那一侧往上送 */
}

#include <stdio.h>
#include <stdlib.h>

typedef char ElemType;
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

/* 返回以 root 为根的子树中 p、q 的最近公共祖先；
   若该子树中只含 p、q 之一，则返回找到的那个结点；都不含返回 NULL */
BiTNode *LCA(BiTree root, BiTNode *p, BiTNode *q) {
    if (root == NULL || root == p || root == q)   /* 边界：空树 / 先遇到 p 或 q */
        return root;

    BiTNode *left  = LCA(root->lchild, p, q);     /* 左子树中找 */
    BiTNode *right = LCA(root->rchild, p, q);     /* 右子树中找 */

    if (left != NULL && right != NULL)            /* p、q 分居两侧，root 即 LCA */
        return root;
    return (left != NULL) ? left : right;         /* 否则把非空的那一侧向上传 */
}

int main(void) {
    BiTNode n[7];
    int i;
    for (i = 0; i < 7; i++) { n[i].data = 'A' + i; n[i].lchild = n[i].rchild = NULL; }
    n[0].lchild = &n[1]; n[0].rchild = &n[2];
    n[1].lchild = &n[3]; n[1].rchild = &n[4];
    n[2].lchild = &n[5]; n[2].rchild = &n[6];
    printf("LCA(D,E)=%c\n", LCA(&n[0], &n[3], &n[4])->data);  /* 输出 B */
    printf("LCA(D,F)=%c\n", LCA(&n[0], &n[3], &n[5])->data);  /* 输出 A */
    return 0;
}

（3）复杂度分析

时间复杂度：最坏情况下每个结点恰好进入一次递归并做 O(1) 判断，T(n) = O(n)，满足题目要求。空间复杂度：只用了若干指针变量，额外空间全部来自递归工作栈，栈深等于树高 h，故 S(h) = O(h)；最坏（单支树）退化为 O(n)，平均为 O(log n)。

得分点分布：算法思想 2 分（后序遍历框架 1 分、"左右都非空则当前结点即 LCA"1 分）；代码 9 分（typedef 与结构体定义、边界 root==NULL 与 root==p/q 共 2 分；左右递归与两分支判断主干 5 分；返回值写法 return (left!=NULL)?left:right; 2 分）；复杂度 2 分（O(n) 与 O(h) 各 1 分）；卷面 2 分（分小问标号、代码缩进注释、结论加粗）。
这样写会扣分：
  • 不写 root == p || root == q 这个边界，只写 root == NULL → 递归到 p 本身时会继续下探，返回 NULL，答案错。正确：边界与 root 为 p/q 合并成一行 if (root==NULL || root==p || root==q) return root;。
  • 只写 if (left != NULL && right != NULL) return root; 就结束函数，缺 return → 编译告警、路径不完整。正确：末尾必须补 return (left!=NULL)?left:right; 把单侧结果向上传。

  • 函数签名照抄题干：返回类型、函数名、参数个数一个都不能改，改名直接按错处理。
  • 漏掉 root==NULL||root==p||root==q 的提前返回，会多递归一层且结果错。
  • 用全局变量存结果，多组测试数据时忘记清零，第二组就错。
  • 只写「左右都非空返回 root」，漏了「只找到一侧要原样上传」，祖先会跑到更上层。
2数据结构·应用题范文（Dijkstra 手工模拟）★★★15 分▼

题目

给定带权有向图 G，含 6 个顶点 v1~v6，边及权值为：v1→v2 权 10、v1→v4 权 30、v1→v5 权 100、v2→v3 权 50、v3→v5 权 10、v4→v3 权 20、v4→v5 权 60，其余顶点对之间不可达。用 Dijkstra 算法求 v1 到其余各顶点的最短路径，要求给出每一轮的 dist 数组、已确定顶点集合 S 与最终最短路径。

满分答案（照这个格式写）

（1）初始化

源点 v1 入集合，S = {v1}；dist 初值取 v1 的各条直接出边，其余为 ∞：dist[v2] = 10，dist[v3] = ∞，dist[v4] = 30，dist[v5] = 100，dist[v6] = ∞。

（2）逐轮执行（每轮：在 V−S 中选 dist 最小者加入 S，再用它的出边松弛）

轮次   选中顶点(距离)      dist[v2]  dist[v3]  dist[v4]  dist[v5]  dist[v6]    S
初值   —                    10        ∞         30        100       ∞         {v1}
 1     v2 (10)              10       60         30        100       ∞         {v1,v2}
 2     v4 (30)              10       50         30         90       ∞         {v1,v2,v4}
 3     v3 (50)              10       50         30         60       ∞         {v1,v2,v4,v3}
 4     v5 (60)              10       50         30         60       ∞         {v1,v2,v4,v3,v5}
 5     v6 不可达            10       50         30         60       ∞         结束

各轮松弛说明（阅卷时要看到这一步，否则只有结果分）：

  • 第 1 轮选中 v2（10）：松弛 v2→v3，dist[v3] = min(∞, 10+50) = 60。
  • 第 2 轮选中 v4（30）：松弛 v4→v3，dist[v3] = min(60, 30+20) = 50；松弛 v4→v5，dist[v5] = min(100, 30+60) = 90。
  • 第 3 轮选中 v3（50）：松弛 v3→v5，dist[v5] = min(90, 50+10) = 60。
  • 第 4 轮选中 v5（60）：v5 无出边，dist 不再变化；剩余 v6 的 dist 仍为 ∞，说明不可达，算法结束。

（3）最终结果

终点    最短路径              路径长度
v2      v1 → v2               10
v4      v1 → v4               30
v3      v1 → v4 → v3          50
v5      v1 → v4 → v3 → v5     60
v6      不可达                ∞
得分点分布：初始化 dist 数组 2 分（少写 ∞ 或不写初值扣 1 分）；每一轮"选点 + 松弛"表格 8 分（共 4 个有效轮次，每轮选点 1 分、dist 更新正确 1 分）；最终路径与长度 3 分（v3、v5 两条需经 v4 的路径各 1 分，其余 1 分）；S 集合与不可达结论、卷面 2 分。
这样写会扣分：
  • 只写最后 5 个距离，不写逐轮表格 → 过程分 8 分全失。正确：必须逐轮列出 dist[v2..v6] 与 S 集合，见上表。
  • 把 dist[v5] 直接写成 100（v1→v5 直达），忘了经 v4、v3 的更短路径 60 → 结果错扣 2 分。正确：每轮加入新点后都要按 dist[v] = min(dist[v], dist[u]+w(u,v)) 重新松弛。
  • 写出 dist[v3]=50 却说路径是 v1→v2→v3（长度 60）→ 距离与路径不一致，扣 1 分。正确：距离由哪条路径更新得来，路径就写哪条，v3 是由 v4 松弛的，故路径为 v1→v4→v3。
  • 漏写 v6 → 阅卷认为未讨论不可达情形，扣 1 分。正确：末尾注明"dist[v6]=∞，v6 不可达"。
易错点
  • 每轮忘记「从未确定的点里选 dist 最小的」，顺序一乱全错。
  • 更新 dist 时漏掉「经新点更短才更新」的比较，直接把旧值覆盖。
  • 把 ∞ 当 0 参与比较，选出错误的下一个顶点。
  • 最后写路径时把前驱顺序写反，成了终点到起点。
3组成原理·计算大题范文（直接映射 Cache）★★★12 分▼

题目

某计算机主存容量 1MB，按字节编址，Cache 采用直接映射，Cache 共 8 行，每块 32B。Cache 访问时间 10ns，主存访问时间 100ns，采用"先访问 Cache，未命中再访问主存"的方式。求：(1) 主存地址位数与各字段位数；(2) Cache 的总容量（含标记、有效位与数据）；(3) 若程序访问 1000 次，命中 950 次，求命中率与平均访问时间；(4) 若改为 4 路组相联，说明标记位与组号位如何变化。

满分答案（照这个格式写）

（1）主存地址位数与地址格式

地址位数 = log2(主存容量) = log2(1MB) = log2(2^20 B) = 20 位。

块内地址位数 = log2(块大小) = log2(32B) = log2(2^5) = 5 位。

行号（Cache 行索引）位数 = log2(Cache 行数) = log2 8 = 3 位（直接映射时行号即块号低位）。

标记位数 = 地址位数 − 行号位数 − 块内地址位数 = 20 − 3 − 5 = 12 位。

故地址格式为：标记 12 位 | 行号 3 位 | 块内地址 5 位（合计 20 位）。

（2）Cache 总容量

每行需存：数据 32B = 32×8 = 256bit，标记 12bit，有效位 1bit，共 256 + 12 + 1 = 269bit。

总容量 = 每行容量 × 行数 = 269bit × 8 = 2152bit = 2152/8 = 269B。

（分项写：数据区 32B×8 = 256B；标记与有效位 13bit×8 = 104bit = 13B；合计 256B + 13B = 269B，两种写法等价。）

（3）命中率与平均访问时间

命中率 H = 命中次数 / 总访问次数 = 950 / 1000 = 95%，缺失率 1−H = 5%。

平均访问时间 = H×Tc + (1−H)×(Tc + Tm) = 0.95×10ns + 0.05×(10ns + 100ns) = 9.5ns + 5.5ns = 15ns。

说明：因采用"先访 Cache、未命中再访主存"，缺失时的总时间为 Tc + Tm = 110ns，不能只算 Tm。

（4）改为 4 路组相联后的变化

组数 = Cache 行数 / 路数 = 8 / 4 = 2 组，故组号位数 = log2 2 = 1 位（原行号 3 位减少 2 位）。

标记位数 = 地址位数 − 组号位数 − 块内地址位数 = 20 − 1 − 5 = 14 位（原 12 位增加 2 位）。

块内地址仍为 5 位不变；每行仍需 1 位有效位，且组相联通常每行还需替换算法所需的标志位。总容量变为每行 (32B + 14bit + 1bit) × 8 行 = 8×(256+15)bit = 2168bit = 271B。

得分点分布：(1) 4 分——地址 20 位 1 分、块内 5 位 1 分、行号 3 位 1 分、标记 12 位 1 分；(2) 3 分——每行 269bit（或 32B+13bit）1 分、乘以 8 行 1 分、结果 269B 带单位 1 分；(3) 3 分——命中率 95% 1 分、公式 H×Tc+(1−H)(Tc+Tm) 1 分、结果 15ns 带单位 1 分；(4) 2 分——组号 1 位、标记 14 位各 1 分。
这样写会扣分：
  • 只写"标记 12 位、行号 3 位、块内 5 位"不给推导 → 逻辑分扣 1 分。正确：每题先写"地址位数 = log2(1MB) = 20 位"这类公式再代入。
  • 把 1MB 当作 2^20 位 → 地址算成 20 位却把块内地址算成 log2(32)=5 位后仍写"标记 12 位"，前后矛盾。正确：明确"按字节编址，1MB = 2^20 B，故 20 位"。
  • 平均访问时间写成 0.95×10 + 0.05×100 = 14.5ns → 漏掉缺失时的那次 Cache 访问，扣 1 分。正确：缺失时间 = Tc + Tm = 110ns，答案 15ns。
  • 第 (4) 问只写"组号 1 位"就停，或把标记写成 20−3−5 仍为 12 位 → 扣 1 分。正确：组数 8/4 = 2 → 组号 1 位 → 标记 20−1−5 = 14 位，并说明块内地址不变。
易错点
  • 地址划分位数相加 ≠ 地址总位数：常见漏算块内偏移或组号。
  • 标记位忘加有效位、脏位、LRU 位，总容量算小。
  • AMAT 公式记混：应为「命中时间 + 缺失率 × 缺失代价」。
  • 主存按字节编址却按字算块内偏移，差 4 倍。
4操作系统·PV 大题范文★★★12 分▼

题目

某仓库可存放 10 件产品。生产者每次生产 1 件放入仓库，消费者每次取 1 件。为加快速度，允许 3 个生产者进程和 2 个消费者进程并发工作，且要求同一时刻仓库中只允许一个进程操作（存取互斥）。请用信号量与 P、V 操作描述生产者进程与消费者进程，要求：（1）说明各信号量的含义与初值；（2）写出生产者与消费者进程的完整代码；（3）说明你的解法为什么不会死锁。

满分答案

（1）信号量定义

信号量含义初值使用方
mutex仓库互斥信号量，保证同一时刻只有一个进程对仓库存取13 个生产者与 2 个消费者共用
empty仓库中空闲存放位置的个数（空位数）10生产者 P、消费者 V
full仓库中已有产品的件数（非空位数）0消费者 P、生产者 V

说明：empty 的初值取仓库容量 10，full 初值取 0，二者互为对称且恒有 empty + full = 10；mutex 初值为 1，只用于保护临界区，不表示资源数量。3 个生产者与 2 个消费者共用这同一组信号量，因此天然实现“多个进程并发、互斥存取、按空位限流”。

（2）生产者进程与消费者进程

semaphore mutex = 1;    // 仓库互斥，初值 1
semaphore empty = 10;   // 空位个数，初值 = 仓库容量 10
semaphore full  = 0;    // 产品件数，初值 0
item buffer[10];        // 容量为 10 的循环缓冲区

void producer_i() {           // i = 1, 2, 3（3 个生产者）
    while (true) {
        item p = produce();   // 生产一件产品
        P(empty);             // 第一步：申请一个空位（先申请资源）
        P(mutex);             // 第二步：申请仓库互斥锁（后申请临界区）
        put(p);               // 临界区：把产品放入仓库
        V(mutex);             // 退出临界区
        V(full);              // 产品数加 1，唤醒消费者
    }
}

void consumer_j() {           // j = 1, 2（2 个消费者）
    while (true) {
        P(full);              // 第一步：申请一件产品（先申请资源）
        P(mutex);             // 第二步：申请仓库互斥锁
        item c = get();       // 临界区：从仓库取走一件产品
        V(mutex);             // 退出临界区
        V(empty);             // 空位数加 1，唤醒生产者
        consume(c);
    }
}

（3）为什么不会死锁

  • P 操作次序统一：两类进程都遵循“先资源信号量（empty／full）、后互斥信号量 mutex”的固定次序，全系统只有一种申请顺序，不构成循环等待。
  • 持锁不等待：进程只有在已获得“空位”或“产品”之后才去抢 mutex，进入临界区后只做存取（有限步、无阻塞），随即 V(mutex) 释放，不存在“占着锁等资源”。
  • 资源可回补：empty 与 full 之和恒为 10，生产者的 V(full) 与消费者的 V(empty) 保证任一方都不会永久等待，5 个进程均能在有限时间内推进。

得分点分布（12 分）

① 三个信号量的名称、含义、初值全部正确（mutex=1、empty=10、full=0）：4 分（错一个扣 1~2 分）。

② 生产者代码顺序正确 P(empty); P(mutex); 放产品; V(mutex); V(full);：3 分。

③ 消费者代码顺序正确 P(full); P(mutex); 取产品; V(mutex); V(empty);：3 分。

④ 不死锁说明（先资源后互斥、P 次序一致、无循环等待）：2 分。只写代码不写信号量含义与初值，①④ 两处共 6 分全失。

这样写会扣分

① 写成 P(mutex); P(empty); → 应写 P(empty); P(mutex);（必须先申请资源再进临界区，否则死锁，②③ 连带扣分）。

② 生产者临界区后只写 V(mutex);，漏掉 V(full); → 必须 V(mutex); V(full); 两条都写（漏 V 会让消费者永久阻塞）。

③ 只设 mutex=1，不设 empty／full → 必须三个信号量齐全，缺一个至少扣 2 分。

④ 把 empty 初值写成 0 或把 mutex 初值写成 10 → 初值必须是 mutex=1、empty=10、full=0。

易错点
  • 信号量初值设错：empty 应等于缓冲区容量、full=0、mutex=1。
  • P 顺序颠倒：先 P(mutex) 再 P(empty)，缓冲区满时双方永久等待。
  • 多生产者或多消费者时漏设 mutex，临界区被并发进入。
  • V 顺序写反：应先 V(mutex) 再 V(full)，否则可能唤醒后又被挡住。

题目

某单位分配到地址块 192.168.10.0/24，需要划分成 4 个大小相同的子网，每个子网主机数不少于 50 台。（1）写出子网掩码与每个子网的网络地址、可用主机地址范围、广播地址；（2）若要把这 4 个子网聚合成一条路由，写出聚合后的地址与掩码；（3）设某 TCP 连接的 MSS=1000B、初始 cwnd=1、ssthresh=16，在慢开始阶段第 5 轮发生超时，写出第 1~8 轮结束时的 cwnd 值，并标明每轮所处阶段。

满分答案

（1）子网划分

第一步，确定借位数：需 4 个等长子网，2^n ≥ 4，解得 n = 2，即向主机位借 2 位，网络前缀长度 = 24 + 2 = 26 位（/26）。

第二步，验证主机数：主机位数 = 32 − 26 = 6 位，每子网地址数 = 2^6 = 64 个，可用主机数 = 2^6 − 2 = 62 台 ≥ 50 台，满足要求。

第三步，写掩码：/26 对应掩码 11111111.11111111.11111111.11000000，即 255.255.255.192；子网块大小 = 256 − 192 = 64，故 4 个子网的网络地址依次为 .0、.64、.128、.192。

子网网络地址可用主机地址范围广播地址
子网 1192.168.10.0/26192.168.10.1 ~ 192.168.10.62192.168.10.63
子网 2192.168.10.64/26192.168.10.65 ~ 192.168.10.126192.168.10.127
子网 3192.168.10.128/26192.168.10.129 ~ 192.168.10.190192.168.10.191
子网 4192.168.10.192/26192.168.10.193 ~ 192.168.10.254192.168.10.255

子网掩码统一为 255.255.255.192（/26），每子网 64 个地址、62 个可用主机地址。

（2）路由聚合

四条 /26 路由的第 25、26 位分别为 00、01、10、11，四位组合恰好覆盖全部取值，故公共前缀只能保留前 24 位：

聚合前缀长度 = 32 − log2(子网个数 × 每子网地址数) = 32 − log2(4 × 64) = 32 − 8 = 24 位。

聚合后的路由为 192.168.10.0/24，掩码 255.255.255.0（即聚合后与原分配地址块一致，无地址浪费）。

（3）拥塞窗口推演

慢开始阶段每经过一个 RTT，cwnd 翻倍（cwnd = 2 × cwnd）；到达 ssthresh 后转入拥塞避免，每轮 cwnd 加 1。超时处理：ssthresh = 超时时的 cwnd / 2 = 16 / 2 = 8，cwnd = 1，重新执行慢开始。

轮次轮末 cwnd（MSS）所处阶段依据
第 1 轮2慢开始1 × 2 = 2
第 2 轮4慢开始2 × 2 = 4
第 3 轮8慢开始4 × 2 = 8
第 4 轮16慢开始（到达 ssthresh = 16）8 × 2 = 16，此后转拥塞避免
第 5 轮1超时，重新慢开始ssthresh = 16 / 2 = 8，cwnd 置 1
第 6 轮2慢开始1 × 2 = 2
第 7 轮4慢开始2 × 2 = 4
第 8 轮8慢开始（到达新 ssthresh = 8）4 × 2 = 8，第 9 轮起转拥塞避免，每轮 +1

结论：第 1~8 轮结束时的 cwnd 依次为 2、4、8、16、1、2、4、8（单位 MSS）；其中第 1~4 轮与第 6~8 轮为慢开始，第 5 轮因超时回到慢开始起点，第 9 轮起进入拥塞避免（cwnd = 9、10、11……线性增长）。

得分点分布（13 分）

① 借 2 位得 /26、掩码 255.255.255.192、可用 62 台 ≥ 50 的验证：3 分。

② 四个子网的网络地址、可用范围、广播地址（每子网 1 分，共 4 分，广播地址写错该子网不得分）：4 分。

③ 聚合地址与掩码 192.168.10.0/24、255.255.255.0：3 分（只写地址或只写掩码各扣 1 分）。

④ 8 个 cwnd 值及阶段标注：3 分（第 4 轮末 16、第 5 轮超时 ssthresh=8 且 cwnd=1 两个关键点各 1 分，其余值 1 分）。

这样写会扣分

① 掩码写成 255.255.255.0 或 /25 → 必须写 255.255.255.192（/26），借 2 位才够 4 个子网。

② 可用范围写成 192.168.10.0 ~ 192.168.10.63 → 必须去掉网络地址 .0 与广播地址 .63，写 .1 ~ .62。

③ 聚合写成 192.168.10.0/26 → 四条 /26 的公共前缀只有 24 位，应聚合为 192.168.10.0/24。

④ 超时后写成 cwnd = 8 → 超时后必须 cwnd = 1、ssthresh = 8（8 是门限值，不是窗口值）。

易错点
  • 子网划分借位后，可用主机数忘减 2（网络号 + 广播地址）。
  • IP 分片偏移字段以 8 字节为单位，直接写字节数扣分。
  • 超时后 ssthresh 减半、cwnd 置 1；不是 cwnd 也减半。
  • 传输时延与传播时延混用，时延算错整题连锁错。
