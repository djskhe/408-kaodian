复杂度与线性表

  • 时间复杂度分析〔选择〕：常问题干「下列程序段的时间复杂度是」，给一段 while／for 嵌套代码（如 i=1; while(i<=n) i=i*2; 或双重循环内层上界随外层变化）；落点：数最内层语句执行次数，得到关于 n 的函数后取最高阶项、去系数；坑：把 i=i*2 误算成 O(n)（应为 O(log₂n)），以及内层上界为 i 时误算成 O(n²)（应为 O(n²) 但系数为 1/2，仍是 O(n²)，不要写 n(n-1)/2 当阶）。
  • 顺序表与链表的选择〔选择+大题〕：常问「在长度为 n 的顺序表中插入一个元素平均移动多少个元素」「删除一个元素平均移动多少个元素」「顺序表和链表各适合什么场景」；落点：插入平均移动 n/2、删除平均移动 (n-1)/2，插入位置有 n+1 个、删除位置有 n 个；坑：把插入的分母写成 n，或忽略"平均"与"最坏"（最坏均为 n）的区别。
  • 循环队列〔选择〕：常问「队头指针 front、队尾指针 rear、数组容量为 m，当前元素个数是多少」「判空与判满条件」；落点：元素个数 (rear-front+m)%m，为区分空满牺牲一个单元时队满 (rear+1)%m==front；坑：容量 m 与实际可存 m-1 个元素差一个单元，或把队尾指针指向队尾元素还是其后一位置搞混。
  • 栈的应用〔选择+大题〕：常问「给定入栈序列，判断哪个出栈序列合法」「中缀表达式转后缀表达式」「用栈求后缀表达式的值」；落点：合法出栈序列共 Catalan(n)=C(2n,n)/(n+1) 种，转后缀按运算符优先级与括号出栈，求值时遇运算符弹出两个操作数（先弹出的是右操作数）；坑：转后缀时同级运算符要先弹出栈内同级（左结合），以及减/除的操作数顺序颠倒。

树与二叉树

  • 二叉树结点计数〔选择〕：常问「某二叉树有 n 个度为 2 的结点，则叶子结点数是多少」「一棵完全二叉树有 1000 个结点，求叶子结点数」「高度是多少」；落点：n0=n2+1、完全二叉树叶子数 ⌈n/2⌉（n 为偶数时 n/2）、高度 ⌊log₂n⌋+1、顺序存储编号 i 的孩子为 2i 与 2i+1、双亲为 ⌊i/2⌋；坑：把"度为 2"当成"度为 1"，或忘记 n=n0+n1+n2 与 n0=n2+1 联立时还需 n1 的奇偶约束。
  • 遍历序列还原〔选择+大题〕：常问「已知先序序列和中序序列，求后序序列」「已知中序和后序，求先序」「能否唯一确定一棵二叉树」；落点：先序（后序）定根、中序定左右子树，递归划分；坑：只有先序+后序不能唯一确定（无法区分单孩子的左右），必须含中序；层序+中序也可唯一确定。
  • 线索二叉树〔选择〕：常问「n 个结点的二叉树中有多少条线索」「某结点的前驱／后继是谁」「中序线索树中如何找后继」；落点：n 个结点共 2n 个指针域，空指针域 n+1 个即线索条数；中序后继：有右孩子则右子树最左下结点，否则沿 rtag=1 的右指针走；坑：先序线索树找前驱、后序线索树找后继仍需借助双亲，不能直接由线索得到。
  • 哈夫曼树与编码〔选择+大题〕：常问「求哈夫曼树的带权路径长度 WPL」「某字符的编码长度」「平均码长」「哈夫曼树是否唯一」；落点：WPL=Σ wᵢlᵢ，且 WPL 等于所有非叶（合并产生）结点权值之和，n 个叶子共 2n-1 个结点、无度为 1 的结点；坑：哈夫曼树形态不唯一但 WPL 唯一，编码前缀性必须验证，n 个叶子的哈夫曼树高度最多 n-1。

图

  • 图的基本性质〔选择〕：常问「n 个顶点的无向完全图有多少条边」「有向完全图有多少条弧」「所有顶点度数之和与边数的关系」「至少多少个顶点才能保证连通」；落点：无向完全图 n(n-1)/2、有向完全图 n(n-1)、ΣTD=2E、ΣID=ΣOD=E、保证连通至少 C(n-1,2)+1 条边；坑：把"边数"与"度数和"混淆，或忘记无向图 ΣTD=2E 中每条边贡献 2 度。
  • 最小生成树〔选择+大题〕：常问「用 Prim／Kruskal 求最小生成树，写出依次选中的边」「最小生成树的权值是多少」「最小生成树是否唯一」；落点：n 个顶点必选 n-1 条边、Prim O(n²) 适合稠密图、Kruskal O(ElogE) 适合稀疏图；坑：MST 形态可能不唯一但权值唯一，且当图中存在权值相同的边时才可能不唯一；负权边不影响 MST 正确性。
  • 最短路径〔选择+大题〕：常问「用 Dijkstra 求源点到各顶点最短路径，写出每轮 dist 数组」「用 Floyd 写出每轮矩阵」「求最短路径长度及路径」；落点：Dijkstra 每轮选未确定顶点中 dist 最小者加入集合 S 并松弛其邻边，Floyd 三重循环 A[i][j]=min(A[i][j],A[i][k]+A[k][j])；坑：Dijkstra 不能处理负权边，Floyd 可以；注意题目问的是"路径长度"还是"经过的顶点序列"。
  • 拓扑排序与关键路径〔大题〕：常问「给出一个拓扑序列」「是否存在拓扑序列，说明理由」「求各事件最早发生时间 ve、最迟发生时间 vl、活动最早开始 e、最迟开始 l」「求关键路径与工期」；落点：ve 取最大（顺推）、vl 取最小（逆推）、e=ve(起点)、l=vl(终点)-dur、l-e=0 的活动为关键活动；坑：关键路径可能有多条，加快关键活动可能改变关键路径，加快非关键活动不能缩短工期。

查找与排序

  • B 树与 B+ 树〔选择+大题〕：常问「m 阶 B 树中每个结点关键字个数的取值范围」「插入某关键字后画出 B 树」「删除某关键字后画出 B 树」「为什么 B+ 树更适合做文件索引」；落点：m 阶 B 树根结点至少 1 个关键字、其余结点关键字数 ⌈m/2⌉-1 ~ m-1、孩子数 ⌈m/2⌉ ~ m，插入溢出时中间关键字上移分裂、删除不足时向兄弟借或与兄弟合并；坑：B 树关键字数与孩子数差 1（k 个关键字对应 k+1 个孩子），B+ 树 n 个关键字对应 n 棵子树且只有叶子存记录。
  • 散列表〔选择+大题〕：常问「给定关键字序列与散列函数 H(key)=key mod p，用线性探测／链地址法构造散列表，求查找成功与失败的平均查找长度」「装填因子是多少」；落点：ASL成功 按关键字个数取平均、ASL失败 按散列函数值域（表长或模数 p）取平均，链地址法失败 ASL 分母为 p；坑：失败 ASL 的分母不是关键字个数，开放地址法还要数探测到空单元的比较次数（含与空单元比较那一次）。
  • 排序过程与稳定性〔选择+大题〕：常问「对序列 {...} 进行一趟快速排序／希尔排序／堆排序后的结果是什么」「下列排序算法中哪个不稳定」「哪个排序的比较次数与初始序列无关」「哪种排序最坏时间复杂度为 O(nlog₂n)」；落点：稳定算法为直接插入、冒泡、归并、基数，不稳定为希尔、快排、简单选择、堆排；比较次数与初始序列无关的是简单选择排序与折半插入（元素移动次数无关）、堆排序建堆；坑：一趟快排结果是按枢轴划分而非有序，希尔排序一趟按增量分组插入，堆排序要先建堆再调整。

算法设计题

  • 算法设计题〔大题〕：常问「设计一个尽可能高效的算法，要求时间复杂度为 O(n)、空间复杂度为 O(1)，并说明算法思想」「若采用...存储结构，给出算法并分析复杂度」（常见落点：找主元素、找中位数、删除重复元素、链表就地逆置、判断链表是否有环、求两链表的公共结点）；落点：答题三件套——算法思想 2~3 行 + 关键代码（含边界处理）+ 时间/空间复杂度分析，O(1) 空间意味着只能用常数个辅助变量或原地交换；坑：忘记写复杂度分析直接丢分，或用 O(n) 辅助数组与题目 O(1) 要求冲突。

数据表示

  • 补码与溢出〔选择〕：常问「[x]补 与 [y]补 相加后结果是多少、是否溢出」「n 位补码能表示的整数范围」「判断溢出的条件」；落点：n 位补码范围 -2^(n-1) ~ 2^(n-1)-1，双符号位法（00 正常、01 正溢、10 负溢）、单符号位法看进位 C_n ⊕ C_(n-1)；坑：补码加法符号位直接参与运算、结果仍为补码，别把溢出当成"最高位进位"（有进位不一定溢出）。
  • IEEE 754〔选择〕：常问「十进制数 -12.5 的单精度浮点数表示（十六进制）是什么」「某 32 位机器数按 IEEE 754 单精度解释，其真值是多少」；落点：1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数，尾数隐含最高位 1，真值 (-1)^S × 1.M × 2^(E-127)；坑：阶码用移码（偏置 127）而尾数用原码，全 0／全 1 阶码是特殊值（0、非规格化数、无穷、NaN），规格化数隐含的 1 不写入尾数字段。
  • 定点数与浮点数的表示范围〔选择〕：常问「n 位定点小数／定点整数能表示的最大最小数」「浮点数能表示的最大正数、最小正数（规格化）」「规格化条件是什么」；落点：定点小数原码范围 -(1-2^-(n-1)) ~ 1-2^-(n-1)，浮点范围由阶码位数决定、精度由尾数位数决定，原码规格化要求尾数最高数值位为 1、补码规格化要求尾数符号位与最高数值位相反；坑：浮点数表示范围由阶码决定、精度由尾数决定，别把"精度"与"范围"答反。
  • 校验码〔选择+大题〕：常问「数据位 k 位时海明码需要多少位校验位、求某数据的海明码」「给生成多项式求 CRC 校验码，并判断接收端是否出错」「奇偶校验能检测／纠正几位错」；落点：海明码 2^r ≥ k+r+1，校验位放在 1,2,4,8... 位上、分组按二进制位编号覆盖；CRC 用模 2 除法（异或，不借位），被除数左移 r 位后除以生成多项式取余数；坑：CRC 余数位数恒为 r（生成多项式最高次），海明码"纠一位错"需 2^r ≥ k+r+1、只检错则 2^r ≥ k+r。

存储系统

  • 存储芯片扩展〔大题〕：常问「用 16K×8 位的芯片组成 128K×16 位的主存，需要多少片芯片、地址线和数据线各多少根、如何连接」「写出各芯片的地址范围与片选逻辑」；落点：芯片数 =（总容量/单片容量）=（字数比）×（位数比），数据线根数由字长决定、地址线根数由字数决定、需 log₂(组数) 根片选译码输入，地址范围按芯片编号连续划分；坑：区分"位扩展"（共用地址线、数据线并联）与"字扩展"（地址线高位译码产生片选），片选信号低电平有效与地址重叠区（若未全译码）。
  • Cache 映射与地址划分〔选择+大题〕：常问「主存地址共 n 位、块大小 x 字节、Cache 共 y 行（z 路组相联），求标记、组号（行号）、块内地址各多少位」「直接映射／全相联／组相联的地址格式」；落点：块内地址 log₂(块大小)、直接映射行号 log₂(行数)、组相联组号 log₂(组数)=log₂(行数/路数)、标记位 = 主存地址位数 − 组号（行号）位 − 块内地址位；坑：标记位不含有效位与脏位（除非题目另说），全相联无组号位、标记最长；组相联中"路数"是每组行数而不是总行数。
  • Cache 性能〔选择+大题〕：常问「求 Cache 命中率 H、平均访问时间 T」「写回法与写直达法下一次写操作的访存次数」「Cache 总容量如何计算」；落点：H=N_c/(N_c+N_m)、T=H·t_c+(1-H)·t_m（并行／串行访问公式不同）、写直达每次写都访存、写回只在换出时写回、Cache 容量 =（标记位 + 有效位 + 脏位 + 数据位）× 行数；坑：未命中时"先访问 Cache 再访问主存"与"同时访问"的 T 公式不同，写回法还要加脏位。
  • 虚拟存储器〔选择〕：常问「一次访存过程中 TLB、页表、Cache、主存被访问的顺序和次数」「TLB 命中／未命中时各访问几次主存」「页式虚拟存储器的地址如何转换」；落点：虚拟地址 → 虚页号 + 页内地址，先查 TLB（命中则直接得实页号）、未命中查页表（可能多次访存），再按实地址查 Cache，TLB 命中时仍可能 Cache 未命中；坑：TLB 未命中不等于缺页（页表命中则只需一次额外访存），页表项中的有效位／修改位／访问位作用不同。

指令与CPU

  • 指令格式与扩展操作码〔选择+大题〕：常问「指令字长 16 位、地址码 4 位，采用扩展操作码，最多可有多少条指令」「设计一个扩展操作码方案，使二地址指令 m 条、一地址指令 n 条、零地址指令 p 条」；落点：先算各字段位数，短操作码数量由长操作码剩余码点递归扣减，零地址指令数 =（剩余码点）×2^地址码位数；坑：短码不能是长码的前缀（如 00 已作二地址操作码，则 0000 不能再作一地址操作码），要留出扩展标志位。
  • 寻址方式〔选择+大题〕：常问「写出各条指令源操作数的寻址方式和有效地址 EA」「相对寻址的 EA 是多少」「基址／变址寻址的区别」；落点：立即数 EA 即操作数本身、直接寻址 EA=A、间接 EA=(A)、寄存器间接 EA=(R)、相对 EA=(PC)+A（PC 已指向下条指令）、基址 EA=(BR)+A、变址 EA=(IX)+A；坑：相对寻址要加指令长度（PC 已自增），变址可自动修改而基址不变，间接寻址需两次访存。
  • 数据通路与微操作〔大题〕：常问「写出取指周期的微操作序列」「写出 ADD R1,(R2) 指令执行阶段的微操作」「单总线结构下完成一条指令需要几个时钟周期」；落点：取指固定三步——PC→MAR、M(MAR)→MDR、MDR→IR 且 (PC)+1→PC，执行阶段按"取数 → 运算 → 存结果"逐步写，每个时钟周期总线只能传送一次；坑：忘记写 PC 自增，或一个时钟周期内写两条总线冲突的微操作。
  • 流水线〔选择+大题〕：常问「k 段流水线执行 n 条指令需要多少时间、吞吐率、加速比」「指出数据冒险／控制冒险／结构冒险并给出解决方法」「流水线时钟周期取多少」；落点：总时间 (k+n-1)·Δt、吞吐率 TP=n/((k+n-1)Δt)、加速比 S=n·k·Δt/((k+n-1)Δt)、时钟周期取最长一段 Δt=max(Δtᵢ)；坑：Δt 按最长段算（不是各段平均），数据冒险用转发／阻塞解决，控制冒险用分支预测／延迟槽。

总线与I/O

  • 总线与性能指标〔选择+大题〕：常问「求总线带宽」「传送 n 个字节需要多少时间」「突发传送方式下的有效带宽」「同步总线与异步总线的区别」；落点：带宽 = 总线宽度（字节）× 总线频率、一次突发传送含地址周期与数据周期，有效数据传输率要扣掉地址／等待周期，异步总线用握手（不互锁／半互锁／全互锁）；坑：位宽与字节数换算（8 位 = 1 字节），总线频率是 MHz 时带宽单位是 MB/s，别忘除以 8。
  • 磁盘〔选择+大题〕：常问「求磁盘容量、平均存取时间、数据传输率」「读一个扇区需要多少时间」「磁盘地址格式」；落点：容量 = 记录面数 × 柱面数 × 扇区数 × 每扇区容量，平均存取时间 = 平均寻道时间 + 平均等待时间（1/2 转）+ 传输时间，传输率 = 每道容量 × 转速；坑：平均等待时间取半圈（60/(2r)），扇区按柱面—盘面—扇区顺序编号，磁盘地址含驱动器号、柱面（磁道）号、盘面号、扇区号。
  • 中断与 DMA〔选择+大题〕：常问「中断响应过程包括哪些步骤」「给出中断屏蔽字并排出中断处理顺序」「DMA 传送过程是怎样的、CPU 参与程度如何」；落点：中断响应由硬件完成（关中断、保存断点 PC 与 PSW、识别中断源、转中断服务程序），屏蔽字中 1 表示屏蔽、决定优先级，DMA 由 DMA 控制器直接控制总线成块传送、仅在预处理与后处理阶段需 CPU 参与；坑：中断隐指令不是指令、由硬件完成，中断屏蔽字"某位为 1"是屏蔽该中断而非开放，DMA 传送期间 CPU 仍可执行程序（周期挪用）。
  • 程序查询/中断/DMA 三种方式的比较〔选择〕：常问「下列场景应选择哪种 I/O 控制方式」「三种方式中 CPU 用于 I/O 的时间占比／效率最高的是哪种」「哪种方式数据传送不经过 CPU」；落点：程序查询方式 CPU 全程等待（效率最低）、中断方式每传一个字（块）就中断一次、DMA 方式以数据块为单位且数据不经过 CPU、通道方式进一步减轻 CPU 负担；坑：DMA 并非完全不占用 CPU（总线与内存仍由 CPU 与 DMA 争用），中断方式适合低速设备、DMA 适合高速块设备。
3操作系统★★★15 条▼

进程与调度

  • 进程状态转换〔选择〕：常问「下列哪种状态转换不可能发生」「就绪→阻塞能否直接发生」；落点：三态/五态图中只存在就绪→运行、运行→就绪、运行→阻塞、阻塞→就绪（事件完成）、运行→终止；坑：阻塞→运行不可能，阻塞态必须先回就绪队列；挂起态进出要靠激活/挂起原语。
  • 周转时间计算〔大题〕：常问「按 FCFS/SJF/RR/优先级调度，求各进程周转时间与平均周转时间」「求平均带权周转时间」；落点：周转时间=完成时间−到达时间，带权周转=周转时间/服务时间，等待时间=周转−服务；坑：抢占式要标出被抢占时刻与剩余时间，RR 时间片用尽要重新排队，同到达时刻按题给顺序或编号小者优先。
  • 调度算法特性〔选择〕：常问「哪种调度算法可能导致饥饿」「哪种算法响应比最高」「实时调度中哪种可抢占」；落点：FCFS 利于长作业不利于短作业、SJF 平均周转最短但长作业饥饿、RR 对交互友好但时间片过大退化为 FCFS、高响应比 R=(等待+服务)/服务 兼顾长短；坑：优先级调度分静态/动态，动态优先级+老化才能避免饥饿；多级反馈队列「时间片递增、优先级递减」。

同步与死锁

  • PV 操作与信号量〔大题〕：常问「用信号量实现生产者-消费者（读者-写者/哲学家进餐）的同步与互斥」「按前驱图写出各进程的 PV 操作」；落点：互斥信号量初值 1、同步信号量初值 0 或资源数，P 在临界区前、V 在临界区后，前驱图用「前驱进程 V、后继进程 P」的私有信号量；坑：读者写者要加 count 的互斥信号量防多个读者同时改计数，哲学家要限制最多 4 人取筷或奇偶顺序防死锁。
  • 信号量取值范围〔选择〕：常问「信号量 S 的最小值是多少」「S=−2 表示什么」；落点：S 值域为 [初值−申请总数, 初值]，S<0 时 |S| 等于在该信号量上阻塞的进程数；坑：P、V 成对出现才不改变终值，问最小值要看并发最多同时申请几次而非进程总数。
  • 死锁〔选择+大题〕：常问「系统至少需要多少同类资源才不会死锁」「用银行家算法判断该状态是否安全并给出安全序列」「化简资源分配图，判断是否死锁」；落点：n 个进程各需 m 个同类资源，不发生死锁最少资源数 n(m−1)+1；银行家先算 Need=Max−Allocation，再找 Need≤Available 的进程回收资源；坑：安全状态≠不会死锁（只是存在安全序列），资源分配图能完全化简才无死锁，有环不一定死锁（每类资源多实例时）。

内存管理

  • 页面置换〔选择+大题〕：常问「采用 FIFO/LRU/OPT 算法，求缺页次数与缺页率」「访问过程中发生多少次页面置换」；落点：逐次扫描引用串维护页框，缺页率=缺页次数/访问总次数；坑：FIFO 会出现 Belady 异常（页框增多缺页反增），LRU 与 OPT 不会；缺页率分母是访问次数不是不同页数；初始页框为空时首次装入也算缺页。
  • 有效访问时间 EAT〔选择+大题〕：常问「已知 TLB 命中率与访存时间，求有效访问时间」「引入缺页处理后 EAT 为多少」；落点：EAT=(1−p)·t_TLB命中+(p)·t_TLB未命中，命中=λ(t+ε)+(1−λ)(2t+ε)（λ 为 TLB 命中率，t 访存、ε 查 TLB）；含缺页时 EAT=(1−f)·常规EAT+f·缺页处理时间；坑：未命中要算两级访存，缺页处理时间含磁盘 I/O 通常是毫秒级，必须与纳秒级分开单位。
  • 地址变换〔大题〕：常问「给定逻辑地址与页大小，求对应的物理地址」「两级页表下访问一个数据需几次访存」；落点：页号=逻辑地址/页大小、页内偏移=逻辑地址%页大小，物理地址=页框号×页大小+偏移；k 级页表需 k+1 次访存（加 TLB 命中可减）；坑：页大小是 2 的幂时用移位而非除法，多级页表要把逻辑地址按每级页表项数拆位。
  • 分段与分页比较〔选择〕：常问「分页/分段是否产生内部碎片」「段的长度是否可变」；落点：页是物理单位、大小固定、有内部碎片无外部碎片；段是逻辑单位、长度可变、有外部碎片无内部碎片；段页式先分段再分页，每段一张页表；坑：分段地址是二维的（段号+段内偏移），页表项数由逻辑地址空间决定而非实际使用量。
  • 位示图〔选择+大题〕：常问「块号为 x 的磁盘块对应位示图的字号和位号」「已知字号位号求物理块号」；落点：按行优先 字号=块号/字长、位号=块号%字长；坑：题给编号从 0 还是从 1 开始，从 1 开始要减 1 再换算；位示图大小=磁盘块数/8 字节。

文件与I/O

  • 文件物理结构〔选择+大题〕：常问「连续/链接/索引分配各有什么优缺点」「混合索引的最大文件长度是多少」；落点：连续支持随机访问但易外部碎片、链接无碎片但只能顺序访问、索引支持随机访问但索引块占空间；混合索引最大长度=直接块数×块大小+一级间接项数×块大小+二级间接项数×块大小+…；坑：索引表项指向的是磁盘块，先算每块能放多少地址（块大小/地址长度）再逐级相乘。
  • FAT 与 inode〔选择〕：常问「FAT 表项为 n 位时最大磁盘容量是多少」「inode 中若干直接/间接地址能支持的最大文件大小」；落点：FAT 最大容量=2^n×块大小（n 位表项可表示 2^n 个块）；inode 按直接+一级+二级+三级间接求和；坑：FAT 表项数决定块数，与块大小相乘才是容量；FAT 本身占用磁盘空间且需常驻内存，故不适合大磁盘。
  • 磁盘调度〔大题〕：常问「按 FCFS/SSTF/SCAN/CSCAN 调度，求磁头移动总磁道数与访问顺序」；落点：按当前磁头位置找最近请求（SSTF）、单向扫到端点再折返（SCAN）、只单向循环（CSCAN）；坑：要看清磁头初始移动方向与磁盘最大柱面号，SCAN 到端点是否包含端点柱面、CSCAN 回程是否计入移动距离。
  • 缓冲与 SPOOLing〔选择〕：常问「单缓冲/双缓冲下处理一块数据的时间是多少」「SPOOLing 技术是否实现了设备共享」；落点：单缓冲每块耗时 max(C,T)+M、双缓冲 max(C+M,T)（C 计算、T 输入、M 传送）；SPOOLing 用输入井/输出井把独占设备虚拟为共享设备；坑：单缓冲是 max(C,T)+M 而非 C+T+M，双缓冲在 C+M 与 T 中取大；SPOOLing 并未真正让物理设备并行，只是逻辑上共享。
4计算机网络★★★15 条▼

性能计算

  • 时延与带宽计算〔选择+大题〕：常问「求发送时延与传播时延」「求时延带宽积」「求端到端总时延」；落点：发送时延=数据长度/发送速率，传播时延=链路长度/传播速率，时延带宽积=传播时延×带宽（即链路中比特数），总时延=各段发送+传播+处理+排队；坑：发送时延用带宽算、传播时延用光速算，二者常被混用；经交换机/路由器转发时每跳都要重算发送时延。
  • 奈氏与香农〔选择〕：常问「带宽为 W、采用 N 种码元，求最大数据率」「信噪比为 S/N，求信道极限速率」；落点：奈氏 C=2W·log2(N)，香农 C=W·log2(1+S/N)，dB=10·log10(S/N)；坑：同时给码元数与信噪比时取两者较小值；香农公式与码元种类无关，奈氏公式与信噪比无关；带宽单位 Hz 与数据率 bit/s 不可混。
  • 编码与调制〔选择〕：常问「曼彻斯特编码的波特率与比特率是什么关系」「采用 4 相调制时波特率与比特率的关系」；落点：曼彻斯特与差分曼彻斯特波特率=2×比特率，4B/5B 有 20% 开销，QAM-16 每码元 4 bit；坑：波特率是码元速率、比特率=波特率×log2(码元种类)；曼彻斯特编码自带同步但频带利用率仅 50%。

链路层

  • 差错控制〔大题〕：常问「用 CRC 求发送的帧（含校验码）」「海明码需多少位校验位、能纠正几位错」；落点：CRC 用生成多项式做模 2 除法，余数即 FCS，帧=数据左移 r 位再减余数；海明码校验位数满足 2^k≥n+k+1，纠 1 位错需码距 ≥3；坑：模 2 除法不借位，余数位数必须等于生成多项式最高次幂；CRC 只能检错不能纠错。
  • 滑动窗口与信道利用率〔选择+大题〕：常问「求使信道利用率达 100% 的最小窗口大小」「n 位序号下 GBN/SR 的窗口上限」「求信道利用率」；落点：利用率=窗口×帧发送时延/(帧发送时延+RTT) 或 W·T/(T+RTT)；序号 n 位时 GBN 窗口 ≤2^n−1、SR 窗口 ≤2^(n−1)；坑：GBN 与 SR 上限不同，别混用；窗口≥(T+RTT)/T 才能连续发送填满链路。
  • CSMA/CD 与最小帧长〔选择+大题〕：常问「求争用期（端到端往返时延）」「求最小帧长」「第 k 次冲突后从哪些数中随机取值」；落点：争用期=2τ，最小帧长=2τ×数据率，退避从 {0,1,…,2^k−1} 取 k 且 k≤10；坑：最小帧长对应 64B（10Mbps 以太网），争用期是往返时延不是单程；CSMA/CD 只用于半双工有线，全双工与无线（CSMA/CA）不用。
  • 以太网帧与交换机〔选择〕：常问「以太网 MAC 帧首部/最小帧长/前导码是多少」「交换机收到未知目的地址的帧如何处理」「划分后有几个冲突域和广播域」；落点：MAC 帧 6+6+2+46~1500+4 字节、最小 64B，交换机按源 MAC 自学习、目的未知则泛洪，每端口一个冲突域但整个交换机一个广播域；坑：前导码 8B 不计入帧长，VLAN 划分可切分广播域但交换机默认不切分；集线器所有端口同一冲突域。

网络层

  • IP 分片〔选择+大题〕：常问「MTU 为 1500B 时 4000B 的 IP 数据报分成几片，各片长度与片偏移是多少」「MF 与 DF 标志如何变化」；落点：每片数据部分 ≤(MTU−20) 且为 8 的倍数，片偏移=该片首字节在原数据部分中的位置/8，除最后一片外 MF=1；坑：片长必须是 8 的倍数，否则偏移无法表示；片偏移以 8 字节为单位，且偏移不含首部。
  • 子网划分与聚合〔选择+大题〕：常问「求该 IP 与掩码下的网络地址、广播地址与可用主机数」「把 4 个连续子网聚合成一条 CIDR 路由」；落点：网络地址=IP AND 掩码，广播地址=网络地址+主机位全 1，可用主机数=2^h−2；聚合时找共同前缀，掩码长度取公共前缀位数；坑：可用主机数要减 2（去掉网络与广播），/31 与 /32 特例除外；聚合后的地址块必须覆盖全部子网且不能再缩小。
  • 路由算法与协议〔选择+大题〕：常问「按 RIP 收到邻居的距离向量后更新路由表」「OSPF 与 BGP 分别属于什么算法、封装在哪一层」；落点：RIP 是距离向量，d(x,y)=min{c(x,v)+d(v,y)}，先加一跳再比较取小；OSPF 链路状态用 Dijkstra 算最短路，直接封装在 IP 中；BGP 是路径向量，封装在 TCP 上（端口 179）；坑：RIP 中 16 跳表示不可达，且「下一跳相同则必须更新、下一跳不同取较小」；RIP 报文用 UDP 520 端口。
  • ARP/DHCP/DNS〔选择〕：常问「ARP 请求报文是广播还是单播、封装在哪一层」「主机跨网段访问时 ARP 解析的是谁的 MAC」「DHCP 的四步报文名称」；落点：ARP 请求广播、响应单播，直接封装在链路层帧中（无 IP 首部）；跨网段解析的是默认网关的 MAC；DHCP 为 DISCOVER→OFFER→REQUEST→ACK，用 UDP 67/68；DNS 用 UDP 53；坑：ARP 报文没有 IP 首部，DNS 区域传送才用 TCP。

传输层与应用层

  • TCP 连接管理〔选择+大题〕：常问「三次握手各报文的 seq/ack 如何变化」「四次挥手后主动关闭方进入什么状态、停留多久」「为什么需要 TIME_WAIT」；落点：SYN 消耗一个序号，ack=对方seq+1，第三次握手可携带数据；挥手 FIN 与 ACK 各占一序号，TIME_WAIT 停留 2MSL（通常 2×2min）；坑：SYN=1 的报文不能携带数据但占序号，半关闭状态下仍可单向传输数据。
  • TCP 拥塞控制〔选择+大题〕：常问「初始 cwnd=1、ssthresh=16，第 n 轮后 cwnd 为多少」「超时后 ssthresh 与 cwnd 如何变化，共需几轮恢复」；落点：慢开始每 RTT 翻倍、到 ssthresh 转拥塞避免每 RTT 加 1；超时：ssthresh=cwnd/2、cwnd=1；收到 3 个重复 ACK：ssthresh=cwnd/2、cwnd=ssthresh（快重传快恢复）；坑：快恢复不回 cwnd=1；阈值取半是向下取整；「第 n 轮」按 RTT 计而非按报文段计。
  • TCP 与 UDP 比较〔选择〕：常问「TCP 与 UDP 首部各多少字节」「哪些应用适合用 UDP」「UDP 是否有拥塞控制」；落点：TCP 首部 20B（可扩到 60B）、UDP 首部固定 8B；UDP 无连接、不可靠、无拥塞控制、面向报文，适合实时音视频与 DNS；TCP 面向字节流、可靠、全双工；坑：UDP 有伪首部参与校验但伪首部不传输；TCP 提供流量控制与拥塞控制，UDP 都不提供。
  • HTTP 与应用层协议〔选择+大题〕：常问「非持久/持久/流水线方式下请求一个含 n 个引用对象的页面需多少 RTT」「状态码 301/404/502 分别表示什么」「FTP、SMTP、POP3 的端口是多少」；落点：非持久=2(n+1) RTT（含 TCP 建连），持久非流水线=n+1，持久流水线=2（一个 RTT 建连+一个 RTT 取全部对象）；端口：HTTP 80、HTTPS 443、FTP 21/20、SMTP 25、POP3 110；坑：RTT 计算别漏 TCP 三次握手的 1 个 RTT，状态码 1xx/2xx/3xx/4xx/5xx 分类含义要分清。
