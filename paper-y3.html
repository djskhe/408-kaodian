1.下列递归函数的时间复杂度是　。
int f(int n) {
    if (n <= 1) return 1;
    return f(n-1) + f(n-1);
}
A. O(n)B. O(n log n)C. O(2ⁿ)D. O(n²)
答案与解析
答案 C。解析 递归关系为 T(n) = 2T(n−1) + O(1)，展开得 T(n) = 2T(n−1) + c = 4T(n−2) + 3c = … = 2ⁿ⁻¹T(1) + (2ⁿ⁻¹−1)c，故 T(n) = O(2ⁿ)。这实际上是在计算 2ⁿ⁻¹，递归树的结点数为 2ⁿ−1。易错：看到“每次 n 减 1”就以为只有 n 层而答 O(n)，忽略了每层调用两次形成二叉树；若改成 return f(n-1) + 1 才是 O(n)。
2.某顺序表中现有 n 个元素。若在表中插入一个元素时各插入位置等概率，平均需要移动的元素个数为 A；若删除一个元素时各元素被删除的概率相等，平均需要移动的元素个数为 B。则 A − B 等于　。
A. 1B. 1/2C. n/2D. 0
答案与解析
答案 B。解析 顺序表有 n 个元素时，插入位置共 n+1 个，在第 i 个位置插入需移动 n−i+1 个元素，故 A = (1/(n+1))·Σ(n−i+1) = (1/(n+1))·(n+(n−1)+…+0) = n/2。删除第 i 个元素需移动 n−i 个元素，共 n 个位置，故 B = (1/n)·Σ(n−i) = (1/n)·((n−1)+(n−2)+…+0) = (n−1)/2。于是 A − B = n/2 − (n−1)/2 = 1/2。易错：把插入与删除的平均移动次数都记成 n/2；忘记插入有 n+1 个可选位置。
3.若 3 个互不相同的元素依次入栈，则可能得到的不同出栈序列的个数是 a；若元素个数为 4，则可能得到的不同出栈序列的个数是 b。则 a 与 b 分别是　。
A. 5，15B. 6，24C. 6，14D. 5，14
答案与解析
答案 D。解析 n 个元素依次入栈时可能的出栈序列数等于第 n 个卡特兰数 Cₙ = (1/(n+1))·C(2n, n)。n=3：C₃ = (1/4)·C(6,3) = 20/4 = 5；n=4：C₄ = (1/5)·C(8,4) = 70/5 = 14。易错：用 n! 得 6 和 24（那是任意排列的个数，其中含有非法序列，如 3 个元素时的 3,1,2）；用 2ⁿ 或其他公式。
4.用一个大小为 6 的数组实现循环队列，队列中最多存放 5 个元素，front 指向队头元素，rear 指向队尾元素的后一个位置。当 front=2、rear=5 时，队列中的元素个数是多少？若此后先连续入队 2 个元素，再出队 1 个元素，则 front 和 rear 分别是多少？　
A. 3；front=3，rear=1B. 3；front=2，rear=1C. 4；front=3，rear=1D. 3；front=3，rear=2
答案与解析
答案 A。解析 元素个数 = (rear − front + 6) mod 6 = (5 − 2 + 6) mod 6 = 3。连续入队 2 个后个数为 5（正好队满），rear = (5+2) mod 6 = 1，front 仍为 2。再出队 1 个后 front = (2+1) mod 6 = 3，rear 不变仍为 1，此时个数 = (1 − 3 + 6) mod 6 = 4。故元素个数为 3，最终 front=3、rear=1。易错：出队时误改 rear（出队只改 front）；把数组大小 6 当作最大元素个数（应为 5）；入队时漏掉取模而算成 rear=7。

I. 3 阶 B 树中，每个非根结点至少有 1 个关键字
II. 4 阶 B 树中，每个结点最多有 3 个关键字
III. B+ 树的叶结点中包含了全部关键字，且叶结点按关键字大小顺序链接
IV. 在 B 树中做范围查询比在 B+ 树中更高效

12.某 8 位计算机中，整数 x 的补码表示为 1000 0000。则 x 的值，以及把 x 算术右移一位后得到的机器数分别是　。
A. −128，1100 0000B. −128，0100 0000C. 0，1100 0000D. −127，1100 0000
答案与解析
答案 A。解析 8 位补码的表示范围是 −128 ~ +127，其中 1000 0000 是最特殊的一个：它没有对应的相反数（+128 无法表示），其值为 −128。算术右移时符号位保持不变并参与移位（即最高位补 1），故 1000 0000 右移一位得 1100 0000，其值为 −64。易错：按“取反加 1”算得 1000 0000 的反码是 0111 1111、加 1 得 1000 0000，得出 x = 0 的错误结论（−128 是补码中的特例，不能这样验算）；把算术右移当作逻辑右移而补 0 得 0100 0000 = 64。
13.已知 x 与 y 均为 IEEE 754 单精度浮点数，其机器数分别为 7F80 0000H 和 FF80 0000H。则 x、y 分别表示的值是　。
A. 最大规格化正数、最小规格化负数B. NaN、NaNC. +∞、−∞D. 非规格化数、非规格化数
答案与解析
答案 C。解析 7F80 0000H = 0 11111111 000…0，阶码全 1、尾数全 0，按 IEEE 754 规定表示 +∞；FF80 0000H = 1 11111111 000…0，符号为 1、阶码全 1、尾数全 0，表示 −∞。若阶码全 1 而尾数非 0，则表示 NaN。易错：把阶码全 1 当成“最大阶码”而误认为是最大规格化数（最大规格化数的阶码是 1111 1110）；把 −∞ 误认为 NaN。
14.采用海明校验传输 8 位数据，校验位位于第 1、2、4、8 位，数据位位于其余各位（位号从 1 开始）。接收端收到码字后，由各校验组计算得到的指误字为 101。则出错的是哪一位？该位属于数据位还是校验位？　
A. 第 3 位，数据位B. 第 5 位，校验位C. 第 6 位，数据位D. 第 5 位，数据位
答案与解析
答案 D。解析 指误字就是出错位的位号：101B = 5，故第 5 位出错。8 位数据加 4 位校验共 12 位，其中第 1、2、4、8 位是校验位，其余第 3、5、6、7、9、10、11、12 位是数据位，故第 5 位是数据位，纠正时把该位取反即可。易错：把指误字按“第 1 位对应最低位”的顺序读成 5（此处恰好相同，但若指误字为 110B 则应为第 6 位，须按二进制数值解释）；误认为第 5 位是校验位。
15.某 Cache 采用 4 路组相联映射，主存地址划分如题 15 图所示，Cache 初始时为空，采用 LRU 替换算法。某程序依次访问的主存块号为 0, 64, 128, 192, 0, 64, 256, 0（均为十进制）。则访问过程中共发生缺失多少次？　
A. 4 次B. 5 次C. 6 次D. 7 次
答案与解析
答案 B。解析 组号占 5 位，故共有 32 组，映射关系为“组号 = 块号 mod 32”。0、64、128、192、256 除以 32 的余数都是 0，全部映射到第 0 组，而第 0 组可容纳 4 块。访问 0、64、128、192 时均为缺失（4 次），此时第 0 组被填满；访问 0、64 均命中；访问 256 时缺失（第 5 次），按 LRU 淘汰最久未用的块 128；再访问 0 命中。共缺失 5 次。易错：只按块号低位判断而漏看组号位宽（若误以为 64 与 0 不同组则会算出更多命中）；把 4 路组相联误当成直接映射而每次访问都缺失（得 7 次）。
16.某处理器采用 5 段流水线（IF、ID、EX、MEM、WB），采用转发（旁路）技术，但不允许在同一时钟周期内同时进行寄存器写回与读出。现连续执行下列三条指令：
I1：add R1, R2, R3
I2：sub R4, R1, R5
I3：and R6, R1, R7
则执行完这三条指令共需多少个时钟周期？　
A. 6B. 8C. 7D. 9
答案与解析
答案 C。解析 流水线排布：I1 占周期 1~5（IF/ID/EX/MEM/WB），I2 占周期 2~6，I3 占周期 3~7，中间无阻塞。虽然 I2、I3 在 ID 段（周期 3、4）读 R1 时 I1 尚未写回（WB 在周期 5），但 I2 的 EX 段在周期 4、I3 的 EX 段在周期 5，都可以通过“EX/MEM→EX”和“MEM/WB→EX”转发通路拿到 I1 在周期 3 末算出的结果，因此不需要插入气泡。三条指令填满流水线后共需 5+(3−1) = 7 个时钟周期。易错：以为 ID 段读不到最新值就必须阻塞（有了转发后不需要）；忘记 5 段流水线的填充开销而得 3 或 5。
17.某系统采用中断方式控制外设 I/O。中断响应需要 3 个时钟周期，中断处理（含保存与恢复现场、执行服务程序）需要 20 个时钟周期。若该外设平均每 50 个时钟周期产生一次中断请求，则 CPU 用于该外设 I/O 的时间占比是　。
A. 46%B. 40%C. 6%D. 54%
答案与解析
答案 A。解析 每次中断 CPU 总共要花 3+20 = 23 个时钟周期，而两次中断之间的间隔为 50 个时钟周期，故占比 = 23/50 = 46%。注意中断响应时间（关中断、保存断点、转入服务程序）也属于 CPU 为 I/O 付出的开销，必须计入。易错：只算 20/50 = 40%（漏掉中断响应时间）；只算 3/50 = 6%（把响应时间当成全部开销）；把 50 − 23 = 27 个周期算成 54% 作为答案。
18.某计算机采用四体交叉存储器，每个存储体的存取周期为 200ns，总线传输周期为 50ns。若 CPU 连续读取 8 个字，则从发出第一个读命令到读完全部 8 个字所需的时间是　。
A. 1600nsB. 400nsC. 600nsD. 550ns
答案与解析
答案 D。解析 四体交叉存储器中，各存储体分时启动，总线每隔一个总线传输周期（50ns）就可送出下一个字。读第 1 个字需等第一个存储体完成一次存取（200ns），此后每 50ns 出一个字。故总时间 = 200 + (8−1)×50 = 200 + 350 = 550ns。易错：算成 8×200 = 1600ns（那是顺序存储、不交叉的情况）；算成 8×50 = 400ns（忽略了第一个字的存取周期）；算成 200+8×50 = 600ns（多算了一个传输周期）。
19.下列关于 Cache 与虚拟存储器比较的叙述中，错误的是　。
I. 两者都利用了程序访问的局部性原理
II. Cache 的块大小固定且远小于页大小，Cache 缺失的损失也远小于缺页损失
III. Cache 的替换由硬件实现，页面的替换由操作系统实现
IV. Cache 缺失时 CPU 会切换到其他进程，缺页时 CPU 只需停顿等待
A. 仅 II、IVB. 仅 IVC. 仅 ID. 仅 III、IV
答案与解析
答案 B。解析 只有 IV 错误，且把两者的处理方式说反了：Cache 缺失的代价只有几十到上百个时钟周期，CPU 只需停顿（stall）等待数据从主存取回，不需要切换进程；缺页的代价高达数毫秒（涉及磁盘 I/O），必须把当前进程阻塞并切换到其他进程。I 正确：两者都建立在时间局部性与空间局部性之上。II 正确：Cache 块通常为几十字节，页通常为 4KB，缺失损失分别是百纳秒级与毫秒级。III 正确：Cache 完全由硬件管理，页面置换由操作系统的缺页处理程序完成。
20.已知 x = 0.1101×2³，y = −0.1010×2⁵，采用 IEEE 754 单精度格式（阶码用移码表示、尾数用原码表示）。则 x + y 的结果的阶码字段是　。
A. 1000 0101B. 1000 0100C. 1000 0011D. 1000 0111
答案与解析

【基本设计思想】（4 分） 图的“直径”需要所有顶点对之间的最短路径长度，故采用 Floyd 算法一次求出全部顶点对的最短路径： ① 初始化二维数组 d[][]，d[i][j]=edge[i][j]，d[i][i]=0，无边处为 INF； ② 以每个顶点 k（1≤k≤n）作为中间顶点，对所有 i、j 尝试用 d[i][k]+d[k][j] 更新 d[i][j]； ③ 三重循环结束后，d[i][j] 即为 i 到 j 的最短路径长度； ④ 遍历所有 i≠j，找出 d[i][j] 的最大值及其对应的 (i, j)。若发现某个 d[i][j] 仍为 INF（i≠j），说明图不连通，返回 −1。 本题图中各顶点对最短路径长度为：d(1,2)=3（v1→v3→v2）、d(1,3)=2、d(1,4)=8、d(1,5)=10、d(1,6)=13、d(2,3)=1、d(2,4)=5、d(2,5)=7、d(2,6)=10、d(3,4)=6、d(3,5)=8、d(3,6)=11、d(4,5)=2、d(4,6)=5、d(5,6)=3，最大值为 13，故直径为 13，对应顶点对为 v1 和 v6。 【C 语言实现】（7 分：初始化 2 分，三重循环 3 分，求最大值与连通性判断 2 分） int diameter(MGraph G, int *u, int *v){ int d[MAXV][MAXV], i, j, k, n=G.vexnum, best=-1, x=-1, y=-1; for(i=1;i<=n;i++) for(j=1;j<=n;j++) d[i][j] = (i==j) ? 0 : G.edge[i][j]; // 初始化 for(k=1;k<=n;k++) // 以 k 为中间顶点 for(i=1;i<=n;i++) for(j=1;j<=n;j++) if(d[i][k]+d[k][j] < d[i][j]) // 注意 INF+INF 的溢出 d[i][j] = d[i][k] + d[k][j]; for(i=1;i<=n;i++) for(j=1;j<=n;j++){ if(i!=j && d[i][j]>=INF) return -1; // 图不连通 if(i!=j && d[i][j]>best){ best=d[i][j]; x=i; y=j; } } *u = x; *v = y; return best; } （若担心 INF+INF 溢出 int，可在更新前加判断 if(d[i][k]<INF && d[k][j]<INF)。） 【复杂度】（2 分） 三重循环各执行 n 次，时间复杂度 O(n³)；需要 n×n 的二维数组存放最短路径长度，空间复杂度 O(n²)。 【易错点】Floyd 的 k 循环必须放在最外层，放在内层会得到错误结果；必须先把 d[i][i] 置为 0 并处理好 INF，否则 INF+INF 会溢出成负数而被误判为更短路径；求直径要排除 i=j 的情形（自身到自身距离为 0）；图不连通时不存在直径，必须先判断再返回 −1，不能直接返回一个 INF 相关的值。

【数据传输率与扇区间隔】（3 分） 转速 7200r/min = 120r/s，每转一周的时间 = 1/120s ≈ 8.33ms。 每个磁道容量 = 512 扇区 × 512B = 256KB。 数据传输率 = 256KB ÷ (1/120)s = 256×1024×120 B/s = 31 457 280 B/s ÷ 2²⁰ ≈ 30.00 MB/s。 平均每个扇区的传送时间 = 8.33ms ÷ 512 ≈ 16.28µs。 【程序查询方式能否满足】（2 分） 磁盘每传送 1 个字节所需时间 = 1 ÷ 31 457 280 B/s ≈ 31.8ns。 程序查询方式下 CPU 每传送 1 个字节需 100 条指令 × 2 个时钟周期 ÷ 1GHz = 200ns。 200ns 远大于 31.8ns（约为其 6.3 倍），CPU 根本来不及在下一个字节到来之前完成查询与传送，故程序查询方式不能满足该磁盘的数据传输率要求，会丢失数据。 【中断方式的 CPU 开销】（3 分） 每传送 1 个扇区产生 1 次中断，中断处理开销 = 500 条指令 × 2 个时钟周期 ÷ 1GHz = 1µs。 每个扇区的传送时间为 16.28µs，故 CPU 用于该磁盘 I/O 的时间百分比 = 1µs ÷ 16.28µs ≈ 6.14%。 【DMA 方式的带宽与 CPU 开销】（2 分） 每次 DMA 传送 4B、占用 1 个总线周期 0.1µs，故 DMA 传送时占用的总线带宽 = 4B ÷ 0.1µs = 40MB/s，大于磁盘的 30.00MB/s，足以支持该磁盘的传输。 每传送 1 个扇区产生 1 次 DMA 中断，CPU 开销 = 50 条指令 × 2 ÷ 1GHz = 0.1µs， CPU 用于该磁盘 I/O 的时间百分比 = 0.1µs ÷ 16.28µs ≈ 0.61%。 比较：DMA 方式的 CPU 开销仅为中断方式的约十分之一。原因是在中断方式下，每传送一个扇区（512B）都要由 CPU 执行完整的保存现场、服务、恢复现场等操作；而在 DMA 方式下，数据块在主存与设备之间的搬运完全由 DMA 控制器硬件完成，CPU 只需在传送开始前初始化 DMA 控制器、在传送结束后做一次善后处理，从而把 CPU 从大量数据搬运中解放出来。 【易错点】数据传输率要用“每磁道容量 ÷ 每转时间”，不能只看扇区大小；程序查询的瓶颈是“每字节的 CPU 开销”与“每字节的到达间隔”之比，不能只比较总时间；中断开销要按 CPI 换算成时间，不能直接用指令条数比较；DMA 的“周期挪用”会占用总线带宽，必须验证该带宽是否大于外设的传输率，否则 DMA 也支撑不住；DMA 并非完全不占用 CPU，开始与结束阶段仍需 CPU 参与。

【T0 时刻的安全性】（3 分） 初始 Work = Available = (3, 3, 2)。 ① P1 的 Need=(1,2,2) ≤ Work=(3,3,2)，可满足。P1 完成并释放资源，Work = (3,3,2)+(2,0,0) = (5,3,2)。 ② P3 的 Need=(0,1,1) ≤ (5,3,2)，可满足。Work = (5,3,2)+(2,1,1) = (7,4,3)。 ③ P4 的 Need=(4,3,1) ≤ (7,4,3)，可满足。Work = (7,4,3)+(0,0,2) = (7,4,5)。 ④ P0 的 Need=(7,4,3) ≤ (7,4,5)，可满足。Work = (7,4,5)+(0,1,0) = (7,5,5)。 ⑤ P2 的 Need=(6,0,0) ≤ (7,5,5)，可满足。Work = (7,5,5)+(3,0,2) = (10,5,7)。 5 个进程都能顺利执行完，故 T0 时刻系统处于安全状态，存在安全序列 P1 → P3 → P4 → P0 → P2（其他安全序列如 P1→P3→P4→P2→P0 也可）。 【P1 的请求 Request1(1,0,2)】（2 分） 先做合法性检查：Request1(1,0,2) ≤ Need1(1,2,2)，且 ≤ Available(3,3,2)，检查通过。 试探性分配后：Available = (3,3,2) − (1,0,2) = (2,3,0)；P1 的 Allocation = (3,0,2)，Need = (0,2,0)。 再做安全性检查，Work = (2,3,0)： P1 的 Need=(0,2,0) ≤ (2,3,0) → Work = (2,3,0)+(3,0,2) = (5,3,2)； P3 的 Need=(0,1,1) ≤ (5,3,2) → Work = (7,4,3)； P4 的 Need=(4,3,1) ≤ (7,4,3) → Work = (7,4,5)； P0 的 Need=(7,4,3) ≤ (7,4,5) → Work = (7,5,5)； P2 的 Need=(6,0,0) ≤ (7,5,5) → Work = (10,5,7)。 存在安全序列 P1→P3→P4→P0→P2，故系统可以满足该请求。 【P4 的请求 Request4(3,3,0)】（2 分） 合法性检查：Request4(3,3,0) ≤ Need4(4,3,1)，且 ≤ Available(3,3,2)，检查通过。 试探性分配后：Available = (3,3,2) − (3,3,0) = (0,0,2)；P4 的 Allocation = (3,3,2)，Need = (1,0,1)。 安全性检查，Work = (0,0,2)： P0 的 Need=(7,4,3) 不满足；P1 的 Need=(1,2,2) 中 B 需 2 > 0，不满足； P2 的 Need=(6,0,0) 中 A 需 6 > 0，不满足；P3 的 Need=(0,1,1) 中 B 需 1 > 0，不满足； P4 的 Need=(1,0,1) 中 A 需 1 > 0，不满足。 没有任何进程能满足，系统进入不安全状态，故不能立即满足该请求，P4 必须等待。 【易错点】安全性检查必须用“试探分配后的 Available”作为初始 Work，不能仍用原 Available；Need 要重新计算（Need = Max − Allocation），试探分配后 Max 不变、Allocation 增加、Need 减少；判断能否满足请求前必须先做两道合法性检查（Request ≤ Need、Request ≤ Available），缺一不可；不安全不等于死锁，只是“可能”导致死锁，因此银行家算法拒绝分配。
46.（8 分）某 32 位计算机采用两级页表实现虚拟存储管理，按字节编址，页大小为 4KB，页表项大小为 4B。虚拟地址结构为「页目录索引（10 位）| 页表索引（10 位）| 页内偏移（12 位）」。页目录的起始物理地址存放在页目录基址寄存器中，当前值为 0020 1000H。题 46 图给出了页目录和某个页表的部分内容，表中“项内容”均为十六进制，其低 12 位为标志位，高 20 位为页框号。请回答下列问题。 （1）该进程的虚拟地址空间最多可包含多少个页面？页目录最多有多少个表项？每个页表最多有多少个表项？（2 分） （2）写出访问虚拟地址 0040 3FF8H 时地址转换的完整过程，要求列出页目录索引、页表索引、页内偏移，以及每次访存的物理地址和最终得到的物理地址。（3 分） （3）若该次访问在 TLB 中命中，则整个访问过程共需访问几次主存？（1 分） （4）与采用一级页表相比，采用两级页表可为该进程节省多少页表存储空间？请通过计算说明。（2 分）
参考答案与给分点
【页数与表项数】（2 分） 虚拟地址 32 位、页内偏移 12 位，故虚页号为 20 位，虚拟地址空间最多包含 2²⁰ = 1M 个页面。 页目录索引占 10 位，故页目录最多有 2¹⁰ = 1024 个表项；页表索引占 10 位，故每个页表最多也有 2¹⁰ = 1024 个表项。 【地址转换过程】（3 分） 虚拟地址 0040 3FF8H = 0000 0000 0100 0000 0011 1111 1111 1000B。 页目录索引 = 虚拟地址第 31~22 位 = 0000000001B = 1 页表索引 = 虚拟地址第 21~12 位 = 0000000011B = 3 页内偏移 = 虚拟地址第 11~0 位 = 1111 1111 1000B = FF8H 转换过程： ① 第一次访存：页目录项物理地址 = 0020 1000H + 4×1 = 0020 1004H，读出内容 0021 2007H，去掉低 12 位标志后得页表基址 0021 2000H； ② 第二次访存：页表项物理地址 = 0021 2000H + 4×3 = 0021 200CH，读出内容 0060 0007H，去掉低 12 位标志后得页框号 00600H； ③ 第三次访存：把页框号与页内偏移拼接，物理地址 = 00600H × 4KB + FF8H = 0060 0000H + 0FF8H = 0060 0FF8H，访问该单元取出数据。 【TLB 命中时的访存次数】（1 分） 若 TLB 命中，页目录项与页表项的查找都由 TLB 直接给出，无需访问主存中的页表，只需访问 1 次主存取数据，故共需 1 次访存。 【两级页表节省的空间】（2 分） 若采用一级页表，需要为整个 2²⁰ 页的虚拟地址空间连续地建立一个页表，共 2²⁰ 个表项，占用 2²⁰ × 4B = 4MB。 采用两级页表时，页目录占 1 个页面（4KB）；页表按需建立，若该进程当前只用到 1 个页表（页目录中只有索引 1 有效），则页表占 4KB，合计 8KB。 节省的空间 ≈ 4MB − 8KB ≈ 4MB（节省比例约 99.8%）。两级页表的意义正在于：只在页目录项有效时才为其建立页表，未使用的虚拟地址区间不占用页表空间，从而避免了巨大的连续页表。 【易错点】页目录索引取的是虚拟地址最高 10 位（第 31~22 位），不是最低 10 位；页表项的物理地址要用“页表基址 + 页表索引 × 页表项大小”，不是“页表基址 + 页表索引”；项内容中的低 12 位是标志位（有效位、访问位、修改位等），提取页框号时必须把它们屏蔽掉；一级页表的 4MB 是“整个虚拟地址空间”的表项总量，不是进程实际使用的量，这正是两级页表要解决的问题。
47.（9 分）主机 A 与主机 B 之间建立了一条 TCP 连接，A 向 B 持续发送数据，B 的接收窗口 rwnd 始终足够大，A 的初始拥塞窗口 cwnd = 1 MSS，初始慢开始门限 ssthresh = 16 MSS，A 采用标准的 TCP 拥塞控制算法（慢开始、拥塞避免、快重传与快恢复），并以“传输轮次”为单位描述 cwnd 的变化。题 47 图给出了 cwnd 随传输轮次变化的情况，图中第 8 轮次发生了超时（重传计时器超时），第 14 轮次收到了 3 个重复确认。请回答下列问题。 （1）指出第 1~8 轮次、第 9~14 轮次、第 15 轮次以后分别使用了哪种拥塞控制算法。（2 分） （2）第 8 轮次超时后，ssthresh 和 cwnd 分别被调整为多少？该调整依据的是什么原则？（2 分） （3）第 14 轮次收到 3 个重复确认后，ssthresh 和 cwnd 分别被调整为多少？此时进入的是慢开始还是拥塞避免？（2 分） （4）若第 7 轮次时 B 通告的接收窗口 rwnd = 24 MSS，则 A 在该轮次的发送窗口是多少？为什么？（1 分） （5）从第 1 轮到第 7 轮次，A 共发送了多少个 TCP 报文段？（2 分）
参考答案与给分点
【各阶段的拥塞控制算法】（2 分） 第 1~5 轮次：cwnd 按 1、2、4、8、16 倍增，为慢开始阶段；第 5 轮次 cwnd 达到 ssthresh = 16，第 6、7 轮次起每轮只加 1 个 MSS（16→17→18），进入拥塞避免阶段。故第 1~8 轮次中，第 1~5 轮为慢开始，第 6~8 轮为拥塞避免。 第 9~12 轮次：超时后 cwnd 重置为 1，又按 1、2、4、8 倍增，为慢开始；第 13、14 轮次 cwnd 为 9、10，进入拥塞避免。 第 15 轮次以后：收到 3 个重复确认后执行快重传与快恢复，此后 cwnd 每轮加 1，处于拥塞避免阶段。 【第 8 轮次超时后的调整】（2 分） 第 8 轮次时 cwnd = 19 MSS，检测到超时后： ssthresh = ⌊19 ÷ 2⌋ = 9 MSS，cwnd 被重置为 1 MSS。 依据的原则是：网络出现拥塞时，把慢开始门限减半（取发送窗口的一半），并让 cwnd 回到 1，重新执行慢开始，以迅速减小注入网络的报文数量。 【第 14 轮次收到 3 个重复确认后的调整】（2 分） 第 14 轮次时 cwnd = 10 MSS，收到 3 个重复确认说明只是个别报文段丢失而非严重拥塞，执行快重传与快恢复： ssthresh = ⌊10 ÷ 2⌋ = 5 MSS，cwnd 被设置为 ssthresh = 5 MSS（而不是回到 1）。 此后 cwnd 从 5 开始每轮加 1（5、6、7、8、9、10），进入的是拥塞避免阶段，而不是慢开始。这正是快恢复与超时处理的本质区别：快恢复不把 cwnd 降为 1，从而避免了网络吞吐量的剧烈下降。 【第 7 轮次的发送窗口】（1 分） TCP 的发送窗口 = min(cwnd, rwnd)。第 7 轮次 cwnd = 18 MSS，rwnd = 24 MSS，故发送窗口 = min(18, 24) = 18 MSS，即由拥塞窗口决定，接收窗口此时不是瓶颈。 【第 1~7 轮次发送的报文段数】（2 分） 每轮次发送的报文段数等于该轮次开始时的 cwnd： 第 1~7 轮次 cwnd 依次为 1、2、4、8、16、17、18， 总数为 1+2+4+8+16+17+18 = 66 个报文段。 【易错点】慢开始“每轮加倍”只持续到 cwnd 达到 ssthresh 为止，达到后立即转入拥塞避免（每轮加 1），不能继续加倍；超时处理与 3 个重复确认的处理方式不同：超时令 cwnd=1 并重新慢开始，3 个重复确认令 cwnd=ssthresh 并进入拥塞避免（快恢复）；ssthresh 一律取“当前 cwnd 的一半”并向下取整；发送窗口是 cwnd 与 rwnd 的较小者，不能只写 cwnd；统计发送量时要用“每轮开始时的 cwnd”，不能用轮末值。
