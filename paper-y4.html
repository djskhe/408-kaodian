1.已知递归函数
int f(int n) { return n <= 1 ? 1 : f(n - 1) + f(n - 1); }
则调用 f(n) 的时间复杂度是　。
A. O(2ⁿ)B. O(n)C. O(n²)D. O(n log n)
答案与解析
答案 A。解析 每次调用都产生两个规模为 n − 1 的子调用，递归式为 T(n) = 2T(n−1) + O(1)，展开得 T(n) = 2ⁿ⁻¹ + (2ⁿ⁻¹ − 1) = O(2ⁿ)，调用次数呈指数增长。对比：若把函数体改成 f(n−1) + n，则每次只产生一个子调用，调用树退化成一条链，复杂度才是 O(n)。易错：只数递归深度 n 就答 O(n)；与二分递归 T(n) = 2T(n/2) + O(1)（结果是 O(n)）混淆；把“两个子调用”误当成“两个规模减半的子调用”。
2.下列关于带头结点的单链表 L 的叙述中，错误的是　。
I. 头结点的数据域不存放有效数据，但可以用来存放表长等信息
II. 删除首元结点与删除表中其他结点的操作完全一致，不需要特殊处理
III. 若只给出尾指针（非循环单链表），则在表头插入一个结点可在 O(1) 时间内完成
IV. 单链表无法在 O(1) 时间内访问第 k 个结点
A. 仅 IIB. 仅 IIIC. 仅 III、IVD. 仅 I、III
答案与解析
答案 B。解析 I 正确：头结点是为操作统一而设的“哑结点”，其数据域可以另作他用（如存表长）。II 正确：有了头结点，删除首元结点时“前驱”就是头结点，与删除其他结点的代码完全一致，这正是设置头结点的目的。III 错误：非循环单链表只给尾指针时，从尾结点无法沿指针回到表头，根本找不到头结点，因此不仅不是 O(1)，而是无法完成；只有循环单链表给尾指针时，tail->next 就是头结点，表头插入才能 O(1)。IV 正确：单链表只能顺序访问。易错：把“循环”与“非循环”混为一谈；以为有尾指针就能双向走；忘记头结点的作用而认为删除首元结点要特判。

4.若循环队列存放在数组 Q[0..n−1] 中，采用牺牲一个存储单元区分队空与队满，约定 front 指向队头元素的前一个位置、rear 指向队尾元素，则队满的条件是　。
A. rear == frontB. (front + 1) % n == rearC. rear == n − 1D. (rear + 1) % n == front
答案与解析
答案 D。解析 本约定中 front 指向队头元素之前，故 (front, rear] 这一段就是队列元素，元素个数 = (rear − front + n) % n。当 rear 再前进一格就撞上 front 时，队列已满（此时若再插入就会与“空”的判据 rear == front 混淆），故判满条件为 (rear + 1) % n == front。易错：套用“front 指向队头元素”的约定而写成 (front + 1) % n == rear；把判空条件 rear == front 当判满；用 rear == n − 1 判断（那只是“队尾到了数组末尾”，与队列是否已满无关）。

6.关于 AOE 网与关键路径，下列叙述中正确的是　。
I. 关键路径是从源点到汇点的最长路径
II. 关键路径上所有活动的时间余量（松弛时间）都为 0
III. 缩短任意一个关键活动的持续时间，都一定能缩短整个工程的工期
IV. 一个 AOE 网的关键路径可能不止一条
A. 仅 I 和 IIB. 仅 I、II 和 IVC. I、II、III 和 IVD. 仅 I、II 和 III
答案与解析
答案 B。解析 I 正确：工程的最短工期由最长路径决定，这条最长路径就是关键路径。II 正确：关键活动的 e(i) = l(i)，时间余量 l − e = 0，没有任何机动时间。III 错误：当存在多条关键路径时，只缩短其中一条上的活动，工期仍被另一条关键路径卡住，必须同时缩短所有关键路径上的活动才能缩短工期。IV 正确：多条最长路径可以并存。易错：把“最长路径”说成“最短路径”；忽略多关键路径的情形；认为关键活动缩短后一定还是关键活动（可能变成非关键活动）。
7.若要求排序过程中每趟都能确定一个元素的最终位置（该元素确定后不再移动），则下列排序算法中不满足该性质的是　。
A. 冒泡排序B. 简单选择排序C. 归并排序D. 堆排序
答案与解析
答案 C。解析 冒泡排序每趟把当前最大（小）元素“冒”到末尾；简单选择排序每趟选出最小元素放到已排序段末尾；堆排序每趟把堆顶与堆尾交换，最大值就此定位。这三者都每趟定位一个元素。而归并排序是把两个有序段合并成一个更长的有序段，合并过程中元素仍可能被移动到其他位置，只有最后一趟结束才全部就位，因此不满足“每趟定位一个”。（快速排序每趟把枢轴放到最终位置，也满足该性质。）易错：把“每趟有序段长度增加 1”（归并排序）与“每趟定位一个元素”混淆；忘记快速排序的枢轴也是每趟定位；把直接插入排序当成满足该性质（它只是局部有序，元素后续仍会移动）。

11.用 Dijkstra 算法求单源最短路径时，若图中存在负权边（但不存在负权回路），则　。
A. 算法仍然正确，只要不存在负权回路B. 算法会陷入无限循环C. 算法可能求出错误的最短路径，因为它是贪心算法，顶点一旦并入已确定集合就不再更新D. 算法只影响时间复杂度，不影响结果的正确性
答案与解析
答案 C。解析 Dijkstra 每轮从尚未确定的顶点中选当前距离最小者，并认定它的最短距离已经最终确定、此后不再修改。这个“认定”依赖“所有边权非负”这一前提：若存在负权边，一个已经确定的顶点之后可能通过一条负权边被绕出更短的路径，而算法不会回头修正它，于是结果错误。存在负权边时应改用 Bellman-Ford 或 Floyd 算法。易错：以为“只要没有负权回路就没事”（没有负权回路只保证最短路径存在且有限，不保证 Dijkstra 求对）；把“不能处理负权”与“不能处理负权回路”混为一谈；认为会死循环（那是负权回路导致的问题）。

12.关于中断方式与 DMA 方式，下列叙述中错误的是　。
I. 中断方式下，数据的传送由 CPU 执行中断服务程序完成
II. DMA 方式下，数据传送完全不需要 CPU 参与
III. DMA 请求的优先级通常高于中断请求
IV. 中断方式下 CPU 与外设可以并行工作
A. 仅 IB. 仅 II、IVC. 仅 IIID. 仅 II
答案与解析
答案 D。解析 I 正确：中断方式靠 CPU 执行中断服务程序逐字（或逐块）搬移数据，数据要经过 CPU 的寄存器。II 错误：DMA 传送的是数据块不需要 CPU 干预，但传送前要由 CPU 初始化 DMA 控制器（设置主存起始地址、传送长度、方向等），传送后要由 CPU 做后处理（校验、唤醒进程），并非“完全不需要 CPU”。III 正确：DMA 请求意味着高速外设的数据即将丢失，必须优先响应，否则会丢数据。IV 正确：CPU 执行主程序与外设准备数据是并行的，只是外设就绪时 CPU 要被打断。易错：把“数据传送不需要 CPU”扩大成“整个过程不需要 CPU”；认为 DMA 优先级低于中断；把中断的并行性说成“串行”。
13.某系统采用页式虚拟存储，页表存放在主存中，配有 TLB。已知 TLB 访问时间 10ns、主存访问时间 100ns、TLB 命中率 98%、缺页率 0.001%，缺页处理时间 10ms。则该系统的有效访问时间约为　。
A. 约 212 nsB. 约 112 nsC. 约 210 nsD. 约 2.1 µs
答案与解析
答案 A。解析 TLB 命中时需 10 + 100 = 110ns；TLB 未命中时需 10 + 2×100 = 210ns。加权得 0.98×110 + 0.02×210 = 107.8 + 4.2 = 112ns。再计入缺页：0.001% = 10⁻⁵，10⁻⁵ × 10ms = 10⁻⁵ × 10⁷ ns = 100ns。故 EAT ≈ 112 + 100 = 212ns。易错：只算 112ns（漏掉缺页项）；把 10ms 当成 10µs（差 1000 倍）；把缺页率 0.001% 当成 0.001（差 100 倍）；注意缺页率虽极小，但缺页代价极大，往往与命中路径同一量级甚至主导。
14.某 Cache 采用 LRU 替换算法，容量为 4 个块，初始为空。程序依次访问主存块 0, 1, 2, 3, 0, 1, 4, 0, 1, 2, 3, 4，则命中率约为　。

答案 B。解析 逐次模拟（方括号内按“最久未用”到“最近使用”排列）：0 缺[0]；1 缺[0,1]；2 缺[0,1,2]；3 缺[0,1,2,3]；0 命中[1,2,3,0]；1 命中[2,3,0,1]；4 缺，淘汰 2 [3,0,1,4]；0 命中[3,1,4,0]；1 命中[3,4,0,1]；2 缺，淘汰 3 [4,0,1,2]；3 缺，淘汰 4 [0,1,2,3]；4 命中[0,1,2,3]→[1,2,3,4]。命中 5 次、访问 12 次，命中率 = 5 ÷ 12 ≈ 41.7%。易错：命中时忘记刷新次序（会少算命中）；把容量 4 块误当成 3 块；把 LRU 当成 FIFO（同一序列在 4 个页框下用 FIFO 只有 2 次命中，命中率 2/12 ≈ 16.7%）。
15.某机指令字长 16 位，采用相对寻址方式，取指后 PC 的值为 0x1002，指令中形式地址字段为 0xF6（按补码解释）。则该转移指令的转移目标地址为　。
A. 0x0FF6B. 0x0FFAC. 0x0FF8D. 0x0FFE
答案与解析
答案 C。解析 相对寻址的有效地址 EA = (PC) + A，其中 PC 取的是取指完成后的值（已指向下一条指令）。A = 0xF6 是 8 位补码，0xF6 = 1111 0110B，符号位为 1，故其真值为 −(0000 1010) = −10 = −0xA。于是 EA = 0x1002 − 0xA = 0x0FF8。易错：用取指前的 PC 0x1000 相加（得 0x0FF6）；把 0xF6 当成无符号数 246 直接相加；补码求真值时算错（把 −10 当成 −9 或 −6）；忘记相对寻址的位移量是有符号的。
16.两个 IEEE 754 单精度浮点数 x = 0x3F800000、y = 0x40000000，则 x + y 的机器数为　。
A. 0x40300000B. 0x3FC00000C. 0x40800000D. 0x40400000
答案与解析
答案 D。解析 0x3F800000 = 0 01111111 000…0，阶码 127 → 真阶 0，尾数 1.0，故 x = 1.0。0x40000000 = 0 10000000 000…0，阶码 128 → 真阶 1，尾数 1.0，故 y = 2.0。x + y = 3.0 = 1.5 × 2¹，故符号位 0、阶码 = 1 + 127 = 128 = 10000000、尾数 = 1000…0（23 位）。拼成 0100 0000 0100 0000 … 即 0x40400000。易错：忘记浮点加法要先对阶（不能直接把两个机器数相加）；把阶码偏移量记成 128；尾数 1.5 的小数部分 0.5 写成 100…0 时少写或多写一位。
17.某 5 段流水线（IF、ID、EX、MEM、WB）执行下列指令序列，各段均需 1 个时钟周期，采用转发（旁路）技术但未采用乱序执行：
I1: ADD R1, R2, R3

则该序列在流水线中需要插入的气泡是　。
A. I3 与 I4 之间需插入 1 个气泡（load-use 冒险，转发无法消除）B. I1 与 I2 之间需插入 2 个气泡C. I2 与 I3 之间需插入 1 个气泡D. 任何位置都不需要插入气泡

18.某总线有 32 位数据线、20 位地址线，采用同步方式工作，时钟频率为 100MHz，每 2 个时钟周期完成一次读或写。则该总线的数据传输率与可寻址的最大主存空间分别为　。
A. 400 MB/s，1 MBB. 200 MB/s，1 MBC. 200 MB/s，4 MBD. 100 MB/s，1 MB

（1）基本设计思想（4 分）

图的连通分量个数，等于从每个尚未访问的顶点出发做一次遍历所能覆盖的“连通块”个数。因此用一个全局的 visited[] 数组标记顶点是否已被访问，然后按下标 0 ~ vexnum−1 依次扫描：每当遇到一个 visited[i] 为假的顶点，就说明发现了一个新的连通分量，令计数器 k 加 1、该分量的顶点数清零，再从 i 出发做一次深度优先遍历（DFS）；DFS 每访问一个顶点就把它标记为已访问、把本分量的顶点计数加 1，并沿该顶点的邻接表递归访问所有尚未访问的邻接顶点。一次 DFS 结束时，与 i 连通的所有顶点都已标记，接着继续向后扫描。扫描结束后 k 就是连通分量的个数，cnt[0..k−1] 就是各分量的顶点数。

关键点：DFS 必须沿邻接表的链表遍历，用 p = p->nextarc 推进，这样才能保证每条边只被检查常数次；此外，若图不连通，外层必须对每个未访问顶点都启动一次 DFS，不能只从 0 号顶点出发一次。

（2）算法实现（7 分；外层扫描 2 分，DFS 主体 3 分，计数与传参 2 分）

int visited[MAXV];

/* 从顶点 v 出发做 DFS，把本次遍历到的顶点个数累加到 *num 上 */
void DFS(ALGraph G, int v, int *num) {
    ArcNode *p;
    visited[v] = 1;                 /* 标记已访问，避免重复计数 */
    (*num)++;                       /* 本连通分量的顶点数加 1 */
    for (p = G.vertices[v].firstarc; p != NULL; p = p->nextarc)
        if (!visited[p->adjvex])    /* 只递归未访问过的邻接点 */
            DFS(G, p->adjvex, num);
}

int CountComponents(ALGraph G, int cnt[]) {
    int i, k = 0;

    for (i = 0; i < G.vexnum; i++)  /* 初始化访问标记 */
        visited[i] = 0;

    for (i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {          /* 发现一个新的连通分量 */
            cnt[k] = 0;             /* 该分量计数清零 */
            DFS(G, i, &cnt[k]);      /* 一次 DFS 遍历完整个分量 */
            k++;                    /* 分量个数加 1 */
        }
    }
    return k;
}

（3）复杂度与运行结果（2 分）

时间：外层扫描 O(n)，DFS 中每条边在无向图中被两个端点各检查一次、每个顶点被访问一次，总计 O(n + e)。空间：visited[] 占 O(n)，DFS 递归栈最深为 O(n)，故 O(n)。

对题 41 图：v1、v2、v3、v4 构成一个 4 个顶点的连通块；v5、v6、v7 构成一个 3 个顶点的连通块；v8 是孤立顶点，单独成一个分量。故函数返回 3，cnt 数组内容为 {4, 3, 1}。

易错点：① 只从 0 号顶点做一次 DFS 就返回 1（漏掉“外层必须扫描所有未访问顶点”）；② 在邻接表中把无向边只存一次，导致反向遍历不到（无向图的每条边要在两个顶点的链表中各出现一次，arcnum 计数时也只算一次）；③ 把 visited[] 的初始化放进 DFS 内部，每进一次递归就清空一次，造成死循环；④ 用 p++ 而不是 p = p->nextarc 推进链表；⑤ 把顶点计数写成传值参数，函数返回后 cnt 仍是 0。

43.（13 分）某计算机主频为 1GHz，某外设的数据传输率为 2MB/s，每次传送 4B（一个字）。系统分别用三种方式控制该外设与主存之间的数据传送：
· 程序查询（轮询）方式：每传送一个字之前都要执行一段轮询程序，平均耗时 500 个时钟周期；
· 中断方式：每次传送都要引起一次中断，中断响应与处理（含保存、恢复现场）共需 200 个时钟周期；
· DMA 方式：以 4KB 为一块成块传送，每传送完一块，DMA 控制器占用总线及 CPU 进行预处理、后处理共需 500 个时钟周期。
请回答下列问题。
（1）该外设每秒需要传送多少次？三种方式下 CPU 用于 I/O 的时间占比各是多少？（7 分）
（2）若外设的数据传输率提高到 40MB/s，中断方式还能否胜任？说明理由并给出定量依据。（4 分）
（3）从 CPU 干预程度与适用场合两方面比较这三种方式。（2 分）
参考答案与给分点

（1）传送次数与 CPU 占用率（7 分）

每秒传送次数 = 2MB/s ÷ 4B = 2 × 10⁶ ÷ 4 = 5 × 10⁵ 次/s。CPU 每秒有 1 × 10⁹ 个时钟周期。

程序查询：5×10⁵ × 500 = 2.5×10⁸ 周期/s  → 2.5×10⁸ ÷ 1×10⁹ = 25%
中断方式：5×10⁵ × 200 = 1.0×10⁸ 周期/s  → 1.0×10⁸ ÷ 1×10⁹ = 10%
DMA 方式：每秒块数 = 2MB ÷ 4KB = 500 块/s
          500 × 500 = 2.5×10⁵ 周期/s → 2.5×10⁵ ÷ 1×10⁹ = 0.025%

（2）40MB/s 时中断方式是否可行（4 分）

此时每秒中断次数 = 40 × 10⁶ ÷ 4 = 1 × 10⁷ 次/s，CPU 用于中断的周期数 = 1 × 10⁷ × 200 = 2 × 10⁹ 周期/s。

而 CPU 每秒只有 1 × 10⁹ 个周期，所需周期数是可供周期的 2 倍，CPU 将完全被中断处理占满，无法胜任（实际中还会因频繁中断导致响应不过来而丢失数据）。必须改用 DMA 方式：此时每秒 40MB ÷ 4KB = 10000 块，占用 10000 × 500 = 5 × 10⁶ 周期，仅占 0.5%。

（3）三种方式的比较（2 分）

· 程序查询：CPU 全程参与，一直在轮询状态寄存器，CPU 与外设串行工作，效率最低；只适合外设极慢、CPU 有大量空闲的简单场合。
· 中断方式：CPU 平时可执行其他程序，外设就绪时“通知”CPU，二者并行；但每次传送一个字都要一次中断，开销随传输率线性增长，适合中低速、随机发生的 I/O。
· DMA 方式：数据传送由 DMA 控制器直接在主存与外设之间完成，CPU 只在传送前初始化、后处理时介入，干预最少、适合高速成块传送（如磁盘、网卡）。

易错点：① 把 2MB/s 当成 2Mb/s（差 8 倍）；② DMA 的占用率忘记先换算“每秒多少块”；③ 计算中断占比时漏乘“每次中断的周期数”；④ 认为中断方式一定优于程序查询——当每次传送的数据量很小而中断开销很大时，中断的 CPU 占用反而可能更高（本题 25% vs 10% 说明查询更差，但若把中断开销改为 3000 周期，结论就会反过来，要按数据算而不能死记）；⑤ 忘记 CPU 主频 1GHz = 1 × 10⁹ 个周期/秒。

t = 5  P2 运行完（已运行 4ms）；就绪：P1(剩 5,3)、P3(2,4)、P4(3,2) → 选 P4
t = 5~8    P4 运行完；就绪：P1(剩 5,3)、P3(2,4) → 选 P1
t = 8~13   P1 运行完；t = 13~15  P3 运行完

运行区间：P1: 0~1 与 8~13   P2: 1~5   P4: 5~8   P3: 13~15

周转时间 = 完成时刻 − 到达时刻：
P1 = 13 − 0 = 13    P2 = 5 − 1 = 4    P3 = 15 − 2 = 13    P4 = 8 − 4 = 4

注意 P1 被抢占后又恢复运行，其周转时间是从第一次到达算到最终完成（13ms），而不是最后一段的 5ms。

（2）平均周转时间（3 分）

平均周转时间 = (13 + 4 + 13 + 4) ÷ 4 = 34 ÷ 4 = 8.5 ms

带权周转时间 = 周转时间 ÷ 服务时间：
P1 = 13/6 ≈ 2.17   P2 = 4/4 = 1.00   P3 = 13/2 = 6.50   P4 = 4/3 ≈ 1.33
平均带权周转时间 = (2.17 + 1.00 + 6.50 + 1.33) ÷ 4 ≈ 2.75

（3）改为非抢占式（1 分）

非抢占时 P1 一旦开始就必须运行到 t = 6 才让出 CPU。t = 6 时就绪的 P2(1)、P4(2)、P3(4) 中优先级最高的是 P2，于是顺序变为 P1(0~6) → P2(6~10) → P4(10~13) → P3(13~15)。周转时间分别为 6、9、13、9，平均周转时间 = 37 ÷ 4 = 9.25ms，比抢占式的 8.5ms 更大。

易错点：① 把“优先级数值小”当成“优先级低”（本题是数值小优先级高）；② 抢占判断用“新进程的优先级”与“当前进程的优先级”比较，而不是与服务时间比较；③ P2 在 t = 2、t = 4 时被误判为抢占（P3 优先级 4、P4 优先级 2，都低于 P2 的 1，不应抢占）；④ P1 恢复运行时忘记它只剩 5ms；⑤ 带权周转时间用“等待时间 ÷ 服务时间”。

46.（8 分）某系统采用请求页式存储管理，页大小为 4KB。某进程当前的部分页表如题 46 图所示（“—”表示该页不在内存，其页框号、修改位、访问位无意义）。请回答下列问题。
（1）访问逻辑地址 0x2A5C 与 0x1A10 时，是否会发生缺页？对不发生缺页的地址，求出其物理地址。（4 分）
（2）若访问 0x1A10 时发生缺页且内存已无空闲页框，系统采用 CLOCK（时钟）算法，当前指针指向页 0，请写出扫描过程并指出最终淘汰哪一页。（3 分）
（3）被淘汰的那一页是否需要写回磁盘？说明理由。（1 分）
参考答案与给分点

（1）地址变换（4 分）

页大小 4KB = 2¹² = 0x1000，故低 12 位为页内偏移，其余高位为页号。

0x2A5C = 0010 1010 0101 1100B
  页号 = 0x2A5C ÷ 0x1000 = 0x2 = 2，页内偏移 = 0xA5C
  查页表：页 2 有效位 = 1，页框号 = 5 → 不产生缺页
  物理地址 = 5 × 0x1000 + 0xA5C = 0x5000 + 0xA5C = 0x5A5C

0x1A10 = 0001 1010 0001 0000B
  页号 = 0x1A10 ÷ 0x1000 = 0x1 = 1，页内偏移 = 0xA10
  查页表：页 1 有效位 = 0 → 该页不在内存，产生缺页中断

故访问 0x2A5C 不产生缺页，物理地址为 0x5A5C；访问 0x1A10 产生缺页中断，需由操作系统把页 1 调入后才能重新执行该指令。

（2）CLOCK 算法的扫描过程（3 分）

CLOCK 算法把内存中的页组织成循环队列，指针沿队列移动，遇到访问位为 1 的页就把它清 0 并跳过，遇到访问位为 0 的页就淘汰它。本题内存中只有页 0、2、3（页 1、4 不在内存，不参与扫描）。

指针指向页 0：访问位 = 1 → 置 0，指针移向下一页 2
指针指向页 2：访问位 = 1 → 置 0，指针移向下一页 3
指针指向页 3：访问位 = 0 → 淘汰页 3，把页 1 装入该页框

（此时页 0 与页 2 的访问位已被清 0，页 1 装入后访问位置 1）

最终淘汰的是 页 3（页框号 8）。

（3）是否需要写回（1 分）

页 3 的修改位为 1，说明它被调入内存后被改写过，磁盘上的副本已过时，因此必须写回磁盘才能淘汰。若被淘汰页的修改位为 0，则磁盘副本仍是最新的，直接覆盖即可，可省去一次写盘。

易错点：① 用十进制除法求页号（应除以 0x1000 即右移 12 位）；② 物理地址写成“页框号 + 偏移”而没有把页框号乘页大小；③ CLOCK 算法第一轮扫描时忘了把访问位清 0；④ 把不在内存的页 1、4 也纳入 CLOCK 的扫描队列；⑤ 把修改位与访问位的作用混淆，认为只要淘汰就要写回。

47.（9 分）某公司网络如题 47 图所示。交换机 S1 上划分了两个 VLAN，路由器 R1 通过一个物理接口上的两个子接口实现单臂路由（trunk 链路连接 R1 与 S1）。地址规划如下：
VLAN 10（研发部）：192.168.10.0/26
VLAN 20（市场部）：192.168.10.64/26
服务器区：      192.168.10.128/25
请回答下列问题。
（1）写出 VLAN 10、VLAN 20 与服务器区三个网段的可用主机地址数、网络地址与广播地址。（4 分）
（2）这三个网段能否聚合成一条 192.168.10.0/24 的路由？请通过地址范围计算说明理由。（2 分）
（3）简述 VLAN 10 中的主机 A 访问 VLAN 20 中的主机 B 时，数据帧从 A 到 B 的完整转发过程（要求指出 VLAN 标签在何处被添加、剥除）。（3 分）
参考答案与给分点

（1）三个网段的参数（4 分）

VLAN 10：192.168.10.0/26
  地址数 2^(32-26) = 2^6 = 64，可用主机 64 − 2 = 62
  网络地址 192.168.10.0，广播地址 192.168.10.63

VLAN 20：192.168.10.64/26
  地址数 64，可用主机 62
  网络地址 192.168.10.64，广播地址 192.168.10.127

服务器区：192.168.10.128/25
  地址数 2^7 = 128，可用主机 128 − 2 = 126
  网络地址 192.168.10.128，广播地址 192.168.10.255

（2）能否聚合成 /24（2 分）

能。三个网段的地址范围分别是 192.168.10.0 ~ .63、.64 ~ .127、.128 ~ .255，首尾相接、恰好完整覆盖 192.168.10.0 ~ 192.168.10.255，没有空洞也没有重叠，而这一段正好就是 192.168.10.0/24 的全部地址。因此 R1 对外可以只宣告一条 192.168.10.0/24 的聚合路由。

（对照：若第三个网段只规划到 /26，即只占 128 ~ 191，则 .192 ~ .255 是空洞，此时只能聚合到 /23 或分别宣告，不能简单聚成 /24 而不误伤未分配的地址。）

（3）跨 VLAN 转发的完整过程（3 分）

① 主机 A 用自己的掩码 /26 判断出目的 IP 192.168.10.x（属于 VLAN 20）与本机不在同一网段，于是把帧的目的 MAC 填为网关（R1 的 VLAN 10 子接口）的 MAC，而不是主机 B 的 MAC。

② 帧从 A 的接入端口进入 S1。该端口属于 VLAN 10，S1 给它打上 VLAN 10 标签，再按 VLAN 10 的 MAC 地址表转发到连接 R1 的 trunk 端口，标签原样带出。

③ R1 的物理接口收到带 VLAN 10 标签的帧，交给 VLAN 10 子接口处理；子接口剥掉 VLAN 10 标签，得到原始以太网帧，取出 IP 分组查路由表，发现目的网段 192.168.10.64/26 对应 VLAN 20 子接口。

④ R1 重新封装成以太网帧（源 MAC 为 VLAN 20 子接口的 MAC，目的 MAC 为主机 B 的 MAC），打上 VLAN 20 标签，从同一个物理接口发回 trunk 链路。

⑤ S1 从 trunk 口收到带 VLAN 20 标签的帧，按 VLAN 20 的 MAC 地址表转发到 B 所在的接入端口，出端口时剥除 VLAN 20 标签，主机 B 收到普通以太网帧。

易错点：① 认为主机 A 直接把帧发给主机 B 的 MAC（跨网段必须发给网关）；② 认为 VLAN 标签由 R1 添加、由 S1 添加混为一谈（接入端口打标签、trunk 口携带标签、出接入端口剥标签）；③ 认为单臂路由需要两个物理接口（单臂路由的关键正是“一个物理接口 + 多个子接口”）；④ 计算可用主机数时忘记减 2（网络地址与广播地址）；⑤ 聚合时不做地址范围核算，误以为“前缀变短就一定正确”。
