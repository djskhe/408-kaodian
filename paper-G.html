数据结构（第 1~11 题，22 分）

1.下列递归算法的空间复杂度是　。
int f(int n) {
    if (n == 0) return 0;
    int a[100];
    return f(n-1) + 1;
}
A. O(1)B. O(n²)C. O(log n)D. O(n)
答案与解析
答案 D。解析 递归的空间开销来自每层调用占用的栈帧。每层的局部数组大小固定（100 个 int），递归深度为 n，故总空间为 O(n)。易错：答 O(1)（以为局部数组大小固定就与 n 无关，忽略了栈帧会随递归层数累加）；答 O(n²)（把空间与时间混淆，本算法时间也是 O(n)）；注意若把 a 声明为 static 或全局变量则空间为 O(1)。
2.在长度为 n 的单链表中查找倒数第 k 个结点（1 ≤ k ≤ n），下列做法中时间复杂度最低的是　。
A. 先遍历求出表长 n，再从头走 n−k 步B. 用快慢指针，快指针先走 k 步，再与慢指针同步前进C. 把链表逆置后取第 k 个结点D. 先遍历把结点地址存入数组，再按下标取
答案与解析
答案 B。解析 快慢指针法只需一趟遍历：快指针先走 k 步，然后两指针同步前进，快指针到达表尾时慢指针恰好指向倒数第 k 个结点，时间 O(n)、空间 O(1)。A 需两趟遍历（仍为 O(n) 但常数更大）；C 会破坏原链表且需额外 O(1) 指针但实现复杂；D 需要 O(n) 额外空间。易错：误选（认为都是 O(n) 就等价，但题目问“最优”）；忽略空间复杂度。
3.中缀表达式 A−(B+C/D)×E 所对应的后缀表达式是　。
A. A B C D / E * + −B. A B C + D / E * −C. A B C D / + E * −D. A B C D / + E − *
答案与解析
答案 C。解析 按算符优先法转换：A 输出；− 入栈；左括号入栈；B 输出；+ 入栈；C 输出；/ 优先级高于 +，入栈；D 输出；遇右括号，弹出 / 与 +，输出 / +，丢弃左括号；× 优先级高于 −，入栈；E 输出；结束弹出 × 与 −。得 A B C D / + E * −。易错：漏掉括号内 / 要先于 + 输出；把 × 与 − 的弹出顺序颠倒。
4.某循环队列存放在数组 Q[0..n−1] 中，front 指向队头元素，rear 指向队尾元素的后一个位置。若采用“牺牲一个存储单元”的方法区分队空与队满，则队满的条件是　。
A. rear == frontB. (rear + 1) mod n == frontC. (front + 1) mod n == rearD. rear + 1 == front
答案与解析
答案 B。解析 牺牲一个单元后，队列最多存放 n−1 个元素。当 rear 再前进一格就会与 front 重合时即判为队满，故条件为 (rear+1) mod n == front。易错：答 rear == front（那是队空条件）；答 rear+1 == front（漏掉取模，当 rear = n−1、front = 0 时会判断失败）。
5.题 5 图所示为一棵二叉树，则该二叉树的后序遍历序列是　。
A. D, B, A, E, C, FB. A, B, D, C, E, FC. D, B, E, C, F, AD. D, B, E, F, C, A
答案与解析
答案 D。解析 后序遍历按“左子树 → 右子树 → 根”进行。A 的左子树只有 B，B 的左孩子为 D，故先输出 D、再输出 B；A 的右子树为 C，C 的左孩子 E、右孩子 F，故输出 E、F、再输出 C；最后输出根 A。得 D, B, E, F, C, A。易错：误选（那是中序序列）；误选（那是先序序列）；把 C 的两个孩子顺序颠倒。
6.对 8 个字符构造哈夫曼树，若这 8 个字符的权值全部相等，则最长编码长度与最短编码长度之差是　。
A. 1B. 0C. 2D. 3
答案与解析
答案 B。解析 权值全部相等时，哈夫曼树退化为完全二叉树，8 = 2³ 个叶结点恰好排满 3 层，所有编码长度均为 3，故最长与最短之差为 0。易错：答 1 或 2（以为哈夫曼树一定不平衡）；注意权值不等时才会出现编码长度差异，且最长编码长度不超过 n−1。
7.题 7 图所示为一个无向图，则该图的连通分量个数与边数分别是　。
A. 1，5B. 2，4C. 2，5D. 3，5
答案与解析
答案 C。解析 图中 v1、v2、v3 两两相连构成一个三角形（3 条边），是一个连通分量；v4 只与 v5 相连、v5 又与 v6 相连，构成一条长度为 2 的链（2 条边），是另一个连通分量。两部分之间没有任何边，故连通分量共 2 个、边共 5 条。易错：答 1 个连通分量（把整个图当作连通的）；把三角形的边数数成 2；忽略孤立顶点也算一个连通分量。
8.某线性表共有 900 个元素，采用分块查找。若将其等分成 30 块，块内采用顺序查找，则查找成功时的平均查找长度约为　。
A. 30B. 16C. 31D. 61
答案与解析
答案 C。解析 每块含 900 ÷ 30 = 30 个元素。分块查找的平均查找长度 = 索引表查找 ASL + 块内查找 ASL = (b+1)/2 + (s+1)/2 = (30+1)/2 + (30+1)/2 = 15.5 + 15.5 = 31。易错：答 16（只算了一块内的平均查找长度）；答 61（把两者相加时未除以 2）；注意分块查找的最优块数是 √n = 30，此时 ASL 取最小值 √n + 1 = 31。
9.在一棵初始为空的 3 阶 B 树中依次插入关键字 1, 2, 3, 4, 5，则最终根结点中的关键字是　。
A. 2, 4B. 3C. 2, 3D. 4
答案与解析
答案 A。解析 3 阶 B 树每个结点最多 2 个关键字。插入 1、2 得 [1,2]；插入 3 时溢出，中间关键字 2 上移为新根，分裂为 [1] 与 [3]；插入 4 进入右结点得 [3,4]；插入 5 时右结点 [3,4,5] 溢出，中间关键字 4 上移到根，根变为 [2,4]。易错：答 3（只做了一次分裂）；答 2,3（分裂时取错了上移的关键字）；忘记 B 树分裂是“取中间关键字上移”。
10.对序列 49, 38, 65, 97, 76, 13, 27, 49* 进行希尔排序，第一趟取增量 d = 4，则第一趟结束后的序列是　。
A. 13, 27, 38, 49, 49*, 65, 76, 97B. 49, 13, 27, 49*, 76, 38, 65, 97C. 49, 38, 65, 49*, 76, 13, 27, 97D. 13, 38, 27, 49*, 49, 65, 76, 97
答案与解析
答案 B。解析 增量 d = 4 把序列分成 4 组：(49,76)、(38,13)、(65,27)、(97,49*)，各组内部用直接插入排序：得 (49,76)、(13,38)、(27,65)、(49*,97)。按原下标位置回填即 49, 13, 27, 49*, 76, 38, 65, 97。易错：误选（那是整个序列排好序的最终结果）；误选（根本没做排序）；分组时按“连续 4 个一组”而不是“间隔 4 个一组”。
11.对 10000 个记录进行外部排序，内存工作区可容纳 1000 个记录，采用 5 路归并，则归并趟数是　。
A. 2B. 1C. 3D. 4
答案与解析
答案 A。解析 初始归并段个数 = 10000 ÷ 1000 = 10。5 路归并的趟数为 ⌈log₅10⌉：5¹ = 5 < 10，5² = 25 ≥ 10，故需 2 趟。易错：答 1（5 路一次只能归并 5 段，不够 10 段）；答 3（把 5 路当成 2 路算成 ⌈log₂10⌉ = 4 之外的其他值）；注意 k 路归并每趟把段数变为原来的 1/k。

计算机组成原理（第 12~22 题，22 分）

12.某 8 位机器中，整数 x 的补码表示为 1011 0100，则 x 的真值是　。
A. −76B. −75C. 76D. −180
答案与解析
答案 A。解析 补码 1011 0100 的符号位为 1，是负数。求其真值：取反得 0100 1011，加 1 得 0100 1100 = 76，故 x = −76。易错：答 −75（忘记加 1）；答 76（漏看符号位）；可用 256 − 76 = 180 = 1011 0100B 验证。
13.IEEE 754 单精度浮点数 C120 0000H 所表示的值是　。
A. 10.0B. −5.0C. −10.0D. −20.0
答案与解析
答案 C。解析 C120 0000H = 1100 0001 0010 0000 …B：符号位 1（负）；阶码 1000 0010 = 130，真值 = 130 − 127 = 3；尾数 010…0 加隐含 1 得 1.01B = 1.25。故值 = −1.25 × 2³ = −10.0。易错：答 10.0（漏看符号位）；答 −5.0（把阶码算成 2）；答 −20.0（把阶码算成 4）。
14.用 8K×8 位的存储芯片构成容量为 64K×32 位的存储器，共需多少片芯片？
A. 8 片B. 32 片C. 64 片D. 16 片
答案与解析
答案 B。解析 位扩展：32 ÷ 8 = 4 片并联成一组，提供 8K×32 位；字扩展：64K ÷ 8K = 8 组。共需 4 × 8 = 32 片。易错：只算字扩展得 8 片；只算位扩展得 4 片；把 64K/8K 算成 4。
15.某 Cache 采用 4 路组相联映射方式，主存地址划分如题 15 图所示，块大小为 128B。则该 Cache 的容量，以及主存块号 200 所映射的组号分别是　。
A. 16KB，第 200 组B. 32KB，第 8 组C. 4KB，第 8 组D. 16KB，第 8 组
答案与解析
答案 D。解析 组号占 5 位，故共 2⁵ = 32 组；每组 4 路、每块 128B，故容量 = 32 × 4 × 128B = 16384B = 16KB。组相联映射中组号 = 主存块号 mod 组数 = 200 mod 32 = 8。易错：答第 200 组（忘记取模）；答 32KB（把路数乘了两次）；答 4KB（漏乘路数）。
16.某 32 位系统采用一级页表，页大小为 4KB，页表项长 4B。若某进程实际只使用了 1MB 的虚拟地址空间，则该进程的页表占用多少存储空间？
A. 1KBB. 1MBC. 4KBD. 4MB
答案与解析
答案 D。解析 一级页表必须能覆盖整个虚拟地址空间，其大小与进程实际用了多少虚拟空间无关。页内偏移 12 位 → 页号 20 位 → 页表有 2²⁰ 项，每项 4B，故占用 2²⁰ × 4B = 4MB。易错：答 1MB（用实际使用的空间去算，忽略页表按虚拟地址空间全范围建立）；答 4KB（只算了一页）；这正是引入多级页表的原因。
17.某指令系统共有 64 条指令，采用定长操作码。则操作码字段至少需要多少位？
A. 6 位B. 5 位C. 8 位D. 64 位
答案与解析
答案 A。解析 定长操作码要求 2ⁿ ≥ 64，n = 6 时 2⁶ = 64 恰好满足，故至少 6 位。易错：答 5 位（2⁵ = 32 < 64）；答 64 位（把指令条数当作位数）；注意“恰好等于”时已满足要求，不必再加 1 位。
18.某 5 段流水线的各段执行时间均为 1ns，连续执行 50 条指令。与串行执行相比，其加速比约为　。
A. 5B. 约 4.63C. 50D. 约 4.9
答案与解析
答案 B。解析 串行执行需 50 × 5 = 250ns；流水执行需 (5 + 50 − 1) × 1 = 54ns。加速比 = 250 ÷ 54 ≈ 4.63。易错：答 5（那是 n 趋于无穷时的极限加速比，忽略了填充开销）；答 50（把条数当作加速比）；答 4.9（用 250/51 之类算错）。
19.下列指令中，最可能是零地址指令的是　。
A. 寄存器之间的加法B. 立即数传送C. 栈顶元素出栈（POP）D. 直接寻址方式取数
答案与解析
答案 C。解析 零地址指令的指令字中不给出操作数地址，操作数隐含约定（如栈顶、累加器）。POP 操作隐含“栈顶元素”，故属于零地址指令。易错：误选（寄存器间加法通常需要两个寄存器地址）；误选（立即数传送至少需要寄存器地址和立即数字段）；误选（直接寻址必然给出地址字段）。
20.某同步总线的时钟频率为 66MHz，数据线宽度为 32 位，每 2 个时钟周期传送一次数据。则该总线的带宽是　。
A. 132 MB/sB. 264 MB/sC. 2112 MB/sD. 66 MB/s
答案与解析
答案 A。解析 带宽 = 每次传送字节数 × 每秒传送次数 = (32/8)B × (66×10⁶ ÷ 2) = 4 × 33×10⁶ = 132×10⁶ B/s = 132MB/s。易错：答 264MB/s（漏掉“每 2 个时钟周期传一次”）；答 2112MB/s（把 32 位当作 32B）；答 66MB/s（漏乘位宽）。
21.某磁盘的平均寻道时间为 5ms，转速为 10000r/min，每个磁道有 200 个扇区。则读取一个扇区的平均时间约为　。
A. 5.03 msB. 11.03 msC. 8.03 msD. 8 ms
答案与解析
答案 C。解析 转一周时间 = 60s ÷ 10000 = 6ms；平均旋转延迟 = 3ms；读一个扇区的传输时间 = 6ms ÷ 200 = 0.03ms。总时间 = 5 + 3 + 0.03 = 8.03ms。易错：答 5.03ms（漏掉平均旋转延迟）；答 11.03ms（把旋转延迟算成整周 6ms）；答 8ms（忽略传输时间）。
22.下列关于 CPU 与 I/O 设备并行工作的叙述中，错误的是　。
I. 程序查询方式下 CPU 与外设不能并行工作
II. 中断方式下 CPU 与外设可以并行工作
III. DMA 方式下 CPU 与外设可以并行，且 CPU 不必为每个数据介入
IV. 通道方式下 CPU 必须为每一个字节执行一条通道指令
A. 仅 IB. 仅 II、IIIC. 仅 I、IVD. 仅 IV
答案与解析
答案 D。解析 只有 IV 错误。通道是独立的 I/O 处理器，它执行的是通道程序，一条通道指令可控制一批数据块的传送，CPU 只需在通道程序开始与结束时介入，不可能为每个字节执行一条通道指令。I、II、III 均正确：程序查询是纯串行“忙等”；中断与 DMA 都能让 CPU 与设备并行，区别在于 DMA 以数据块为单位、CPU 干预更少。

操作系统（第 23~32 题，20 分）

23.下列关于进程控制块（PCB）的叙述中，错误的是　。
I. PCB 是进程存在的唯一标志
II. PCB 中包含进程标识符、进程状态、程序计数器等内容
III. 创建进程时需要建立 PCB，撤销进程时需要回收 PCB
IV. PCB 通常存放在用户进程的栈中以便快速访问
A. 仅 IVB. 仅 IC. 仅 II、IIID. 仅 I、IV
答案与解析
答案 A。解析 只有 IV 错误。PCB 全部由操作系统在内核空间中统一管理，通常组织成 PCB 表或 PCB 链表（就绪队列、阻塞队列等），进程自己无法访问，更不可能放在用户栈中。I、II、III 均正确：操作系统通过 PCB 感知进程的存在，PCB 是进程存在的唯一标志；PCB 记录了进程的全部描述信息与控制信息。
24.有 P1、P2、P3 三个进程，到达时间分别为 0、1、2（单位 ms），所需运行时间均为 3ms。若采用最短剩余时间优先（SRTN）调度算法，则 P1 的完成时间是　。
A. 4 msB. 3 msC. 6 msD. 9 ms
答案与解析
答案 B。解析 t=0 时只有 P1 到达，开始运行。t=1 时 P2 到达，剩余时间 3ms，而 P1 剩余 2ms，2 < 3，P1 继续；t=2 时 P3 到达，P1 剩余 1ms 仍最短，继续执行；t=3 时 P1 执行完毕。故完成时间为 3ms。易错：答 4ms（以为 P2 一到达就抢占）；答 6 或 9ms（把 P1 当作被抢占后延后执行）；注意 SRTN 抢占的前提是“新进程剩余时间更短”。
25.某系统采用信号量解决生产者-消费者问题，缓冲区大小为 10，信号量 empty 初值为 10、full 初值为 0。若某时刻测得 empty = 4，则此时缓冲区中的产品数，以及还能再放入的产品数分别是　。
A. 4，6B. 6，6C. 6，4D. 4，4
答案与解析
答案 C。解析 full 与 empty 满足 full + empty = 缓冲区大小 10，故产品数 = 10 − 4 = 6；empty 的值本身就是“空闲缓冲区个数”，即可再放入 4 个产品。易错：答 4，6（把 empty 当作产品数）；答 6，6（把 empty 既当空闲数又重复计算）；注意 empty 的初值就是缓冲区大小。
26.下列关于银行家算法的叙述中，正确的是　。
I. 分配资源前先做试探性分配，再检查系统是否仍处于安全状态
II. 若试探后找不到安全序列，则恢复原状态并让该进程等待
III. 银行家算法属于死锁检测算法
IV. 银行家算法要求预先知道每个进程对各类资源的最大需求量
A. 仅 I、II、IVB. I、II、III、IVC. 仅 I、IVD. 仅 II、III
答案与解析
答案 A。解析 只有 III 错误。银行家算法在每次分配前先判断“分配后系统是否仍安全”，若不安全就不分配，属于死锁避免算法，而不是死锁检测算法（检测算法是在死锁可能已经发生后去查找环路或化简资源分配图）。I、II、IV 均正确：试探分配—检查安全序列—不安全则回滚，正是其核心流程；它也必须预先获得各进程的最大需求。
27.某进程的页面访问序列为 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5，系统分配 3 个页框。若采用 LRU 页面置换算法，则缺页次数是　。
A. 9B. 8C. 11D. 10
答案与解析
答案 D。解析 逐次模拟（淘汰最久未被访问的页）：1 缺[1]；2 缺[1,2]；3 缺[1,2,3]；4 缺，淘汰 1 →[2,3,4]；1 缺，淘汰 2 →[3,4,1]；2 缺，淘汰 3 →[4,1,2]；5 缺，淘汰 4 →[1,2,5]；1 命中；2 命中；3 缺，淘汰 5 →[1,2,3]；4 缺，淘汰 1 →[2,3,4]；5 缺，淘汰 2 →[3,4,5]。共缺页 10 次。易错：按 FIFO 模拟得 9 次（本题 FIFO 反而更优）；把命中判错。
28.某分页系统中页大小为 1KB，某进程的页表显示页号 4 对应的页框号为 7。若该进程访问的逻辑地址为 0x1234，则对应的物理地址是　。
A. 0x1234B. 0x1C34C. 0x7234D. 0x1E34
答案与解析
答案 D。解析 页大小 1KB = 2¹⁰B，故低 10 位为页内偏移。逻辑地址 0x1234 的页号 = 0x1234 >> 10 = 4，页内偏移 = 0x234。物理地址 = 7 × 0x400 + 0x234 = 0x1C00 + 0x234 = 0x1E34。易错：答 0x1234（直接照抄逻辑地址）；答 0x1C34（把偏移算错）；答 0x7234（把页框号当作高位直接拼接，忽略了页大小）。
29.某文件系统采用位示图法管理磁盘空闲块。若磁盘共有 4096 个物理块，则位示图占用的存储空间是　。
A. 512 BB. 4096 BC. 1024 BD. 256 B
答案与解析
答案 A。解析 位示图中每一位对应一个磁盘块，4096 个块需 4096 位 = 4096 ÷ 8 = 512B。易错：答 4096B（把位数当作字节数）；答 1024B（按每块 2 位计算）；答 256B（按 4096 ÷ 16 计算）。
30.某磁盘的请求队列为 98, 183, 37, 122, 14, 124, 65, 67，磁头当前位于 53 号柱面并沿柱面号增大的方向移动。若采用 C-LOOK 调度算法，则磁头移动的总柱面数是　。
A. 236B. 322C. 208D. 336
答案与解析
答案 B。解析 C-LOOK 沿增大方向依次服务 65、67、98、122、124、183，到最远请求即折返：53→65(12)→67(2)→98(31)→122(24)→124(2)→183(59)，本段 130。折返到最小请求 14（途中不服务）：183→14 = 169。再沿增大方向服务 37：14→37 = 23。总计 130 + 169 + 23 = 322。易错：答 236（那是 SSTF）；答 336（折返时走到了端点）；答 208（漏算折返段）。
31.某系统采用双缓冲技术，设备把一个数据块送入缓冲区需 80µs，CPU 处理一个数据块需 50µs。则处理 10 个数据块所需的总时间约为　。
A. 1300 µsB. 500 µsC. 800 µsD. 880 µs
答案与解析
答案 C。解析 双缓冲下设备与 CPU 可完全并行，处理节奏由较慢的一方（设备，80µs）决定。第一个数据块需等设备送满 80µs，此后每 80µs 完成一块，故总时间 = 80 + 9 × 80 = 800µs。易错：答 1300µs（那是单缓冲的 n(T+C) = 10×130）；答 500µs（误以为 CPU 是瓶颈）；答 880µs（把首块与 10 块重复累加）。
32.下列关于线程的叙述中，错误的是　。
I. 线程是 CPU 调度的基本单位
II. 同一进程内的各个线程共享该进程的地址空间
III. 每个线程拥有自己独立的栈和寄存器上下文
IV. 线程切换时一定要更换页表
A. 仅 IVB. 仅 IC. 仅 II、IIID. 仅 I、IV
答案与解析
答案 A。解析 只有 IV 错误。同一进程内的线程共享同一个地址空间和页表，故线程切换不需要更换页表（这正是线程切换比进程切换轻量的根本原因）；只有跨进程切换才需更换页表基址并刷新 TLB。I、II、III 均正确：这是线程相对于进程的基本特征。

计算机网络（第 33~40 题，16 分）

33.某 1Gb/s 链路的两端往返时延为 40ms。若采用停等协议发送一个 1500B 的帧，忽略帧首部开销，则链路利用率约为　。
A. 约 3%B. 约 0.03%C. 约 30%D. 约 100%
答案与解析
答案 B。解析 发送时延 = 1500×8 ÷ 1×10⁹ = 12µs；停等协议下每发一帧要等一个 RTT（40ms = 40000µs）才能发下一帧。利用率 = 12 ÷ (12 + 40000) ≈ 0.03%。易错：答 3% 或 30%（把 RTT 的单位算错）；答 100%（以为链路一直有数据在传）；注意这正是需要窗口/流水线协议的原因。
34.某采用 CSMA/CD 协议的以太网中，争用期为 51.2µs。若某帧发生第 3 次重传，则退避算法所取随机数 k 的取值范围是　。
A. 0 ~ 3B. 0 ~ 15C. 1 ~ 8D. 0 ~ 7
答案与解析
答案 D。解析 截断二进制指数退避算法中，第 i 次重传时从整数集合 {0, 1, …, 2^i − 1} 中随机取 k，退避时间为 k × 争用期。第 3 次重传时 k 取 {0,…,2³−1} = 0 ~ 7。易错：答 0 ~ 3（把 i 与 i−1 混淆）；答 0 ~ 15（那是第 4 次重传）；注意重传次数达到 16 次后仍取 {0,…,15} 而不再翻倍。
35.某主机的 IP 地址为 172.16.100.200，子网掩码为 255.255.255.224。则该主机所在子网的网络地址是　。
A. 172.16.100.200B. 172.16.100.224C. 172.16.100.192D. 172.16.100.0
答案与解析
答案 C。解析 掩码 255.255.255.224 即 /27，最后一字节中前 3 位为子网位，子网块大小 = 256 − 224 = 32。200 ÷ 32 = 6 余 8，故子网起点为 6 × 32 = 192，网络地址为 172.16.100.192（可用范围 193~222，广播地址 223）。易错：答 172.16.100.224（把 224 当作网络地址）；答 172.16.100.0（按 /24 计算）；把块大小算成 224。
36.某 TCP 连接初始时 cwnd = 1 MSS、ssthresh = 8 MSS，采用慢开始与拥塞避免。若传输过程中未发生任何超时或丢包，则第 5 个 RTT 结束时 cwnd 的值是　。
A. 16 MSSB. 8 MSSC. 9 MSSD. 10 MSS
答案与解析
答案 D。解析 慢开始阶段 cwnd 每 RTT 翻倍：RTT1 末为 2，RTT2 末为 4，RTT3 末为 8（到达 ssthresh = 8）；此后进入拥塞避免，每 RTT 线性加 1：RTT4 末为 9，RTT5 末为 10。故第 5 个 RTT 结束时 cwnd = 10 MSS。易错：答 16（一直按翻倍算）；答 8（停在 ssthresh 不再增长）；答 9（只加了一次，把 RTT4 末的值当作答案）。
37.某浏览器已与服务器建立 TCP 连接，随后采用 HTTP/1.1 的持久连接与流水线方式请求一个页面。该页面由 1 个 HTML 文件和 3 个引用图像组成，全部位于同一服务器。若忽略 DNS 与传输时延，则从请求 HTML 到收完全部内容至少需要多少个 RTT？
A. 4B. 8C. 3D. 2
答案与解析
答案 D。解析 第 1 个 RTT 请求并收到 HTML；解析出 3 个图像引用后，第 2 个 RTT 内一次性把 3 个请求全部发出并收到全部响应（流水线允许连续发送请求而不等响应）。故共需 2 个 RTT。易错：答 4（那是非流水线持久连接：每个对象 1 个 RTT，共 4 个）；答 8（那是非持久连接：每对象 2 个 RTT）；答 3（漏掉流水线可并行请求）。
38.下列关于域名系统 DNS 的叙述中，错误的是　。
I. DNS 采用层次树状结构的命名空间
II. 根域名服务器知道所有顶级域名服务器的地址
III. 若主机采用递归查询，则主机还需要自己依次向根、顶级和权威域名服务器发出查询
IV. 使用高速缓存可以显著减少 DNS 查询的平均时延
A. 仅 IIB. 仅 IIIC. 仅 ID. 仅 III、IV
答案与解析
答案 B。解析 只有 III 错误。递归查询的含义就是“本地域名服务器替主机把活干完”，主机只需发出一个查询报文并等待最终结果，后续向根、顶级、权威域名服务器的查询全部由本地域名服务器代为完成（它内部可采用迭代方式）。I、II、IV 均正确。
39.主机 A 的地址为 192.168.1.5/24，主机 B 的地址为 192.168.2.6/24，A 的默认网关为 192.168.1.1。若 A 向 B 发送一个 IP 数据报，则该数据报中的目的 IP 地址与所在以太网帧中的目的 MAC 地址分别是　。
A. 192.168.2.6，默认网关的 MAC 地址B. 192.168.2.6，主机 B 的 MAC 地址C. 192.168.1.1，默认网关的 MAC 地址D. 192.168.1.1，主机 B 的 MAC 地址
答案与解析
答案 A。解析 A 与 B 不在同一子网，故 A 必须把数据报交给默认网关转发。IP 首部中的目的地址始终是最终目的主机 B 的地址（192.168.2.6），而以太网帧的目的 MAC 地址填写的是下一跳——默认网关 192.168.1.1 的 MAC 地址。易错：误选（以为目的 MAC 一定是最终主机）；误选（把目的 IP 也改成网关地址，会丢失最终目的地信息）。
40.某 TCP 连接的拥塞窗口 cwnd = 16 MSS，此时发送方连续收到 3 个重复的 ACK。则执行快重传与快恢复后，ssthresh 与 cwnd 的值分别是　。
A. 8 MSS，1 MSSB. 16 MSS，1 MSSC. 8 MSS，8 MSSD. 12 MSS，12 MSS
答案与解析
答案 C。解析 收到 3 个重复 ACK 说明发生了“个别报文段丢失”而非严重拥塞。此时把 ssthresh 设为当前 cwnd 的一半（16/2 = 8 MSS），并进入快恢复：cwnd 也设为新的 ssthresh = 8 MSS（而不是像超时那样降为 1），随后直接进入拥塞避免线性增长。易错：答 8 MSS，1 MSS（那是超时的处理）；答 12 MSS（把 cwnd 除以 4）；注意快重传与超时的处理方式不同。
