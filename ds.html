1.1 基本概念与三要素

  • 数据、数据元素、数据项、数据对象：数据是能被计算机处理的符号集合；数据元素是基本单位，数据项是最小单位，数据对象是同类元素集合。
  • 数据结构三要素：逻辑结构、存储结构（物理结构）、数据的运算，三者共同刻画一个数据结构，缺一不可。
  • 逻辑结构：指数据元素之间的逻辑关系，与计算机无关、与存储无关，由问题本身决定。分为集合（无关系）、线性（一对一）、树形（一对多）、图状（多对多）四类。同一逻辑结构可以有多种存储实现，二者不是一一对应。常见考法：判断某结构属于哪类逻辑结构，或判断"逻辑结构唯一决定存储结构"（错）。结论：逻辑结构分四类，是数据结构的"骨架"，独立于实现。

    例题集合、线性、树形、图状四种逻辑结构的区别是什么？

    解析① 集合：元素间无关系；② 线性：一对一；③ 树形：一对多；④ 图状：多对多。

    易错点把逻辑结构与存储结构混为一谈（顺序、链式属于存储结构）。

    拓展同一逻辑结构可有多种存储实现，如线性表既可顺序也可链式。

  • 存储结构：逻辑结构在计算机中的表示，分顺序、链式、索引、散列四种。顺序存储用相对位置表示关系，链式存储用指针（地址）表示关系。
  • 数据类型：一个值的集合及定义在其上的一组操作的总称，如整型、字符型。
  • 抽象数据类型 ADT：一个数学模型及定义在其上的一组操作，只描述逻辑特性，与实现无关；分原子类型、固定聚合类型、可变聚合类型。

三要素分别回答“关系是什么、如何表示、能做什么”；四类逻辑结构按关系从无到多对多排列。

1.2 算法及其特性

  • 算法五特性：有穷性、确定性、可行性、输入（0 个或多个）、输出（1 个或多个）。有穷性指算法在执行有穷步之后结束，且每一步都在有穷时间内完成；确定性指每条指令含义唯一、无二义，相同输入必得相同输出。注意程序可以不满足有穷性（如操作系统常驻循环），所以"程序 ≠ 算法"。常见考法：判断某说法违反哪条特性，如"算法必须有输入"（错）、"算法必须有输出"（对）、"算法可执行无限步"（违反有穷性）。结论：五特性缺一不可，输入可为 0，输出至少 1。

    例题算法的五个特性是什么？输入和输出各有几个？

    解析① 有穷性、确定性、可行性、输入、输出；② 输入 0 个或多个，输出 1 个或多个。

    易错点认为输入必须至少 1 个；输出可以为 0 个。

    拓展好算法还要求正确性、可读性、健壮性与高效率。

  • 好算法目标：正确性、可读性、健壮性（对非法输入合理反应）、高效率与低存储量需求。

1.3 时间复杂度

  • 时间复杂度与常见量级：由基本语句频度 T(n) 取数量级 O(f(n))，只留最高阶项、忽略系数与低阶项；量级由小到大：O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)。
  • 运算规则：顺序执行的两段代码相加取大者；嵌套（内层每轮跑满）相乘；对数底不影响量级。
  • 循环复杂度分析：以基本语句执行次数（频度）求和得 T(n)，再取最高阶。单层循环 i*=2、i/=2 型执行约 log₂n 次，i+=k 型约 n/k 次。双层循环若内层上界依赖外层，总次数必须用 Σ 累加而不能简单写成 n×n。常见考法：给一段代码求 T(n) 或 O，常与等差、等比数列求和结合。结论：先看循环变量的变化规律，再求和、取最高阶。

    例题for(i=1;i<=n;i*=2) s++; 的时间复杂度是多少？

    解析① i 依次取 1,2,4,…，第 k 次为 2^(k−1)；② 由 2^(k−1) ≤ n 得 k ≈ log₂n；③ T(n)=O(log n)。

    易错点把 i*=2 看成 i++，误答 O(n)。

    拓展双重循环若内外独立则次数相乘，若内层依赖外层则用求和。

例题求下列程序段中 s++ 的执行次数与时间复杂度，n = 16：int i = 1, s = 0; while (i <= n) { for (j = 1; j <= i; j++) s++; i = i * 2; }

解析① 外层 i 依次取 1, 2, 4, 8, 16，共 log₂n + 1 = 5 轮。② 内层对每个 i 执行 i 次：1 + 2 + 4 + 8 + 16 = 31 次。③ 这是等比数列求和，T(n) = 2n − 1，取最高阶得 O(n)。

易错点外层是 i*=2、内层跑满 i 次，误按"外层 log₂n 轮 × 内层 n 次"相乘得 O(nlog₂n)；实际内层次数是随 i 递增的等比级数，和为 2n−1，故为 O(n)。

1.4 递归复杂度与空间复杂度

  • 递归复杂度：设 T(n) 为规模 n 的求解时间，按"子问题个数 × 子问题规模 + 分解/合并代价"写递推式。T(n)=T(n−1)+O(1) 为 O(n)；T(n)=T(n/2)+O(1) 为 O(log₂n)；T(n)=2T(n/2)+O(n) 为 O(nlog₂n)。常用展开法：反复代入到 T(1)，把每层代价相加（多为等差或等比求和）。常见考法：给递归程序求复杂度，或由递推式选结果。结论：子问题规模减半必带 log₂n 因子，再乘每层代价。

    例题T(n)=2T(n/2)+n 的解是多少？

    解析① 递归树每层代价均为 n；② 共 log₂n 层；③ T(n)=n·log₂n，即 O(n log n)。

    易错点把 T(n/2) 当成 T(n−1) 展开，结果变成 O(n²)。

    拓展对照记忆：T(n)=T(n−1)+n → O(n²)；T(n)=2T(n−1)+1 → O(2ⁿ)。

例题已知 T(1) = 1，T(n) = 2T(n/2) + n（n 为 2 的幂）。求 T(8) 的具体值及时间复杂度。

解析① 逐层展开：T(2) = 2×1 + 2 = 4；T(4) = 2×4 + 4 = 12；T(8) = 2×12 + 8 = 32。② 每层代价之和为 n + n + … + n，共 log₂n + 1 层，故 T(n) = n(log₂n + 1) = nlog₂n + n。③ 代入 n = 8：8×3 + 8 = 32，与逐层展开一致。④ 取最高阶得 O(nlog₂n)。

易错点把 2T(n/2) 误当成"两次半规模问题并行、总代价还是 n"，从而答 O(n)；也常漏掉层数中的 +1 而把 T(8) 算成 24。

  • 空间复杂度：S(n) 只计算算法执行所需的辅助空间，不含输入数据本身占用的空间。辅助空间与 n 无关则为 O(1)，称原地工作（如冒泡、直接插入、堆排序）。递归算法的栈空间等于最大递归深度：线性递归为 O(n)，每层规模减半的递归为 O(log₂n)。常见考法：问某算法空间复杂度，注意"额外/辅助"二字。结论：递归深度即栈空间，输入数组不计入。

    例题递归求 n! 的空间复杂度是多少？

    解析① 递归深度为 n，每层栈帧占常数空间；② S(n)=O(n)。

    易错点把输入数据本身占的空间算进去；S(n) 只计辅助空间。

    拓展尾递归在部分编译器下可优化为 O(1)。

  • 最好、最坏、平均：最坏是性能保证值；平均需假设各种输入等概率出现；最好通常无实际参考价值。

例题下列递归函数求 n! 的算法，其时间复杂度与空间复杂度各是多少？int f(int n) { if (n <= 1) return 1; return n * f(n - 1); }

解析① 递推式 T(n) = T(n−1) + O(1)，展开共 n 层，每层常数工作，故 T(n) = O(n)。② 递归深度为 n，每层占一个栈帧，栈空间 S(n) = O(n)。③ 注意函数没有申请数组，全部辅助空间来自递归栈。

易错点看到"没有定义数组"就答空间复杂度 O(1)，忽略递归调用栈本身要占 O(n) 空间；只有当递归深度为常数时才是 O(1)。

易错：O(1) 不是"只执行 1 次"，而是"执行次数与 n 无关的常数"；O 只是上界，说"复杂度为 O(n²)"并不排除实际是 O(n)。
易错：两段并列的循环要相加取大者，只有真正嵌套才相乘；"程序"不要求有穷性，故程序不等价于算法。
记忆：复杂度口诀"取最高阶、去常数、对数不管底"；递归看"子问题个数 × 子问题规模"，规模减半必出 log₂n。
重点：本章必考两处——逻辑结构与存储结构的对应关系（选择题）、循环/递归程序的复杂度分析（选择题必有一道，也常作为算法题的第一问）。
2线性表★★★14 考点▼

2.1 定义与基本操作

  • 线性表：n 个相同类型数据元素的有限序列，除首元素无前驱、尾元素无后继外，每个元素有唯一前驱与后继。
  • 基本操作：InitList、GetElem（按位取）、LocateElem（按值查）、ListInsert、ListDelete；插入位序 1≤i≤n+1、删除 1≤i≤n。

2.2 顺序表

  • 随机存取：LOC(aᵢ)=LOC(a₁)+(i-1)×L，取第 i 个元素 O(1)，是顺序表唯一快于链表之处。
  • 插入删除的平均移动次数：长为 n 的表在第 i 位插入需后移 n-i+1 个元素，等概率平均 [n+(n-1)+…+0]/(n+1)=n/2；删除第 i 个需前移 n-i 个，等概率平均 (n-1)/2。移动元素是顺序表插删的主要开销，故插删均 O(n)，而按位取 O(1)、按值查 O(n)。结论：插入平均移动 n/2、删除平均移动 (n-1)/2，选择题常直接问「平均移动多少次」。

    例题长为 n 的顺序表等概率插入，平均要移动多少个元素？

    解析① 在第 i 位插入需后移 n−i+1 个；② 平均 = [Σ(n−i+1)]/(n+1) = n/2。

    易错点分母写成 n；插入位置共 n+1 个，应除以 n+1。

    拓展删除的平均移动次数是 (n−1)/2，比插入少一半。

  • 动态分配：用 malloc/realloc 申请与扩容，扩容时整表复制为 O(n)，仍是连续空间、仍支持随机存取。

例题顺序表长 n=100，元素存于 a[0..99]。①等概率在第 i 个位置（1≤i≤101）插入一个元素，平均移动多少个？②等概率删除第 i 个元素（1≤i≤100），平均移动多少个？

解析① 插入：i=1 时全部 100 个后移，i=101 时移动 0 个 → 总移动 100+99+…+0=5050，位置共 n+1=101 种，平均 5050/101=50=n/2。② 删除：i=1 时 99 个前移，i=100 时 0 个 → 总移动 99+98+…+0=4950，位置共 100 种，平均 4950/100=49.5=(n-1)/2。答案：50 次、49.5 次。

易错点插入有 n+1 个合法位置、删除只有 n 个，分母不能都取 n；把插入平均写成 (n+1)/2、删除写成 n/2 都错，且删除平均是 49.5 而不是整数 50。

记忆：插删移动口诀「插入移 n-i+1、删除移 n-i；平均 n/2 与 (n-1)/2」，两式只差「插入多一个位置、多移一个」。

2.3 单链表

  • 头插法与尾插法建表：头插法每次插在头结点之后，读入序列与表中次序相反，可用于就地逆置；尾插法必须维护尾指针 r，否则每插一个都要遍历到表尾，退化为 O(n²)。头结点的作用是让空表与非空表、首结点与其它结点的插删操作统一，减少分支判断。结论：建表、逆置用头插，保序用尾插。

    例题读入 1,2,3,4 用头插法建表，表中次序如何？

    解析① 每次都插在头结点之后；② 结果为 4,3,2,1，与读入顺序相反。

    易错点以为头插法能保持原顺序，那是尾插法的效果。

    拓展头插法可用来实现链表的就地逆置。

  • 查找：按位查 GetElem O(n)、按值查 O(n)，均从头遍历；链表不支持折半查找（无法随机定位中点）。
  • 插入与删除：已知前驱 p 时，插入 s、删除其后继均为 O(1)（只改指针）；若只给结点 p，则后插容易、前插可「先插到 p 之后，再交换两结点的数据」。语句顺序必须写 s->next=p->next; p->next=s;，颠倒会丢失后继链。结论：单链表「删给定结点 p 本身」不能 O(1) 完成（删尾结点时无后继可借），必须先找前驱。

    例题已知指针 p 指向某结点，怎样在 O(1) 时间内删除它？

    解析① 把 p->next 的数据复制到 p；② 再删除 p->next（p->next = p->next->next）。

    易错点写 p = p->next，这只是移动指针，结点并未删除。

    拓展尾结点不能用此法（无后继），只能从头找前驱。

插入顺序：① s->next=p->next ② p->next=s，反了就断链；删除 p->next=q->next 后 free(q)，虚线为原指针

2.4 双链表、循环链表与静态链表

  • 双链表：结点含 prior、next，已知结点 p 时插删 O(1)；改指针的顺序不能颠倒——必须先接好新结点的两个指针、再断开 p 的旧链。因有 prior，删除尾结点也是 O(1)，这是双链表相对单链表的关键优势。结论：双链表用「空间换灵活」，常考四条语句的先后顺序。

    例题在双链表结点 p 之后插入 s，指针操作顺序是什么？

    解析① s->next = p->next；② 若后继存在则 p->next->prior = s；③ s->prior = p；④ p->next = s。

    易错点先改 p->next 再取 p->next->prior，原后继丢失导致断链。

    拓展删除 p：p->prior->next = p->next；p->next->prior = p->prior。

  • 循环链表：单/双循环链表判空 head->next==head（双链表另加 head->prior==head），尾指针 r 时表头 r->next，表头表尾操作 O(1)、删尾 O(1)。
  • 静态链表：用数组加游标模拟指针，next 存下标、-1（或 0）表结束，适合无指针语言；插删只改游标、不移动元素。

例题双链表 head⇄A⇄B⇄C（带头结点，p 指向 A），在 A 之后插入新结点 X。写出正确语句顺序，并说明先执行 p->next=s 会怎样。

解析① s->prior=p；② s->next=p->next（先存住 B 的地址）；③ p->next->prior=s（让 B 回指 X）；④ p->next=s（最后才断 p 的旧链）。①与②可互换，③必须在②之后（要用 p->next 找 B），④必须最后。

易错点若先执行 p->next=s，则 ③ 变成 s->prior=s、B 的地址彻底丢失，链断裂；若 p 恰是尾结点（p->next==NULL），③ 会空指针，须先判 p->next!=NULL。

  • 就地逆置：三指针 pre=NULL, cur=head->next，循环中先存 nxt=cur->next，再 cur->next=pre、pre=cur、cur=nxt；也可用头插法重建。时间 O(n)、辅助空间 O(1)，是链表大题的标准套路。结论：凡「不许申请新结点」的改造题，优先想三指针与头插。

    例题用三指针法逆置单链表，循环体怎么写？

    解析① 初始 pre=NULL、cur=head->next；② 循环：nxt=cur->next; cur->next=pre; pre=cur; cur=nxt。

    易错点先执行 cur->next=pre 再取 nxt，后继指针已被覆盖，链表断裂。

    拓展也可用头插法逆置，同样 O(n) 时间、O(1) 空间。

  • 快慢指针（找中点、判环）：两指针同起点，fast 每次 2 步、slow 每次 1 步。fast 到尾时 slow 即中点（偶数个结点时 slow 落在后半段第一个）；有环则两指针必在环内相遇。判环入口：相遇后让一指针回到头结点、两指针同速前进，再次相遇处即环入口。时间 O(n)、空间 O(1)，是近年高频考点。

    例题如何用快慢指针判断链表有环并找出环的入口？

    解析① fast 走 2 步、slow 走 1 步，若相遇则有环；② 相遇后把其中一个指针放回头结点，两指针同速前进，再次相遇处即入口。

    易错点只判相遇不求入口；或忘记判 fast 与 fast->next 为空导致空指针。

    拓展快慢指针还可求中点：fast 到尾时 slow 恰在中点。

  • 合并与定位：两有序表合并用双指针取小者尾插、余段整接，O(m+n)；删倒数第 k 个先让快指针走 k 步；公共后缀先走长度差。

例题带头结点的单链表 head→1→2→3→4→5→6→7→8，用快慢指针求中间结点；若把 8 改为指向 4（成环），说明如何找环入口。

解析① slow、fast 均从首元结点 1 出发，每轮 slow 走 1 步、fast 走 2 步：第 1 轮 slow=2、fast=3；第 2 轮 slow=3、fast=5；第 3 轮 slow=4、fast=7；第 4 轮 fast 走 7→8→NULL 结束，此时 slow=5。② 故 8 个结点时 slow 停在第 5 个结点，即后半段首结点（n=7 时 slow=4 才是正中，因 ⌊(n+1)/2⌋=4）。③ 成环后两指针必相遇；令一指针回头结点、两指针均每次走 1 步，再次相遇的结点即环入口（本例入口为 4）。

易错点偶数个结点时 slow 不是正中而是后半段第一个，取「前半段末结点」需让 fast 初始先走一步；循环条件必须写成 fast!=NULL && fast->next!=NULL，只判 fast 会空指针；头结点不计入表长，也不参与「第几个结点」的计数。

重点：顺序表移动次数公式（n-i+1 / n-i，平均 n/2 / (n-1)/2）与链表指针操作顺序（单链表后插两条、双链表四条），是本章唯一必出分的两类。
重点：链表大题套路四件套——就地逆置（三指针/头插）、快慢指针找中点与判环、两有序表合并、倒数第 k 个与公共后缀，均为 O(n) 时间、O(1) 空间。
易错：位序从 1 开始、数组下标从 0 开始，循环边界与移动个数都差 1；头结点不计入表长，判空看 head->next==NULL（循环链表看 head->next==head）。
易错：删除结点后要 free 释放；单链表删「给定结点」必须先找前驱，不能直接改指针冒充 O(1)；链表不能折半查找，凡说「链表可用二分」一律错。

3.1 栈及其实现

  • 栈：只允许在栈顶插入和删除的线性表，后进先出（LIFO），栈底固定、栈顶浮动。出栈序列数：n 个不同元素依次入栈、可随时出栈，合法出栈序列共 C(2n,n)/(n+1) 种，n=3 为 5 种、n=4 为 14 种。判合法：用栈模拟，如输入 1,2,3,4 时 3,1,4,2 非法——3 出栈后栈顶是 2，1 不可能先出；n=3 时 6 种排列中 312 非法。结论：合法序列数只与元素个数 n 有关，与元素取值无关，看到「n 个元素出栈序列有多少种」直接代卡塔兰数。

    例题n 个元素依次入栈，可能的出栈序列有多少种？n=3 时列举。

    解析① 数目为卡特兰数 C(2n,n)/(n+1)；② n=3 时为 5 种：123、132、213、231、321。

    易错点以为任意排列都能得到，312 就不是合法出栈序列。

    拓展判合法性：按序列模拟入栈，需要时弹栈，能走完即合法。

  • 顺序栈：top 指向栈顶元素时栈空 top==-1、栈满 top==MaxSize-1；top 指向后一位置则整体差 1（空 0、满 MaxSize）。
  • 共享栈：两栈共用一数组、栈底分设两端，top1+1==top2 即满；链栈以表头为栈顶，插删 O(1)，无栈满。

3.2 栈的应用

  • 括号匹配：遇左括号入栈，遇右括号则弹栈比较，栈空即不匹配；扫描结束栈空才合法，栈容量只需等于最大嵌套深度。
  • 中缀转后缀：操作数直接输出；运算符入栈前与栈顶比较，优先级高于栈顶才入栈，否则弹栈输出直到栈顶优先级更低。括号规则：左括号入栈（栈内优先级最低、栈外最高），遇右括号弹出并输出到左括号为止，左括号只弹出不输出。同级处理：同级运算符按左结合，先弹出栈顶再入栈。收尾：扫描完后把栈中剩余运算符依次弹出。结论：后缀表达式无括号、无优先级，运算次序唯一，是计算机求值的标准形式。

    例题A+B*C−D/E 的后缀表达式是什么？

    解析① 先算乘除：B*C → BC*，D/E → DE/；② 再按加减顺序拼接；③ 结果 ABC*+DE/−。

    易错点同级运算符忘了左结合，或括号内的优先级处理错。

    拓展后缀求值也用栈：遇操作数入栈，遇运算符弹出两个数运算后入栈。

  • 后缀求值：遇操作数入栈；遇运算符弹出两个，先弹出者为右操作数，计算后结果回栈，最终栈顶即表达式的值，时间 O(n)。
  • 递归与进制转换：系统栈保存返回地址与局部变量，递归深度即栈深；十进制转其它进制用除基取余，余数入栈后逆序输出即得结果。

例题中缀表达式 A+B*(C-D)-E/F，其中 A=6、B=4、C=3、D=1、E=8、F=2。① 求其后缀表达式；② 用栈求该后缀表达式的值。

解析① 转后缀：A→输出 A；+ 栈空入栈；B→输出；* 高于栈顶 +，入栈；( 入栈；C→输出；- 高于栈内 (，入栈；D→输出；) 弹出输出 - 并弹掉 (；再遇 -：栈顶 * 优先，弹出输出 *，栈顶 + 与 - 同级，弹出输出 +，栈空后 - 入栈；E→输出；/ 高于栈顶 -，入栈；F→输出；结束弹出 /、-。得后缀 A B C D - * + E F / -。② 求值：压 A(6)［6］→ B(4)［6,4］→ C(3)［6,4,3］→ D(1)［6,4,3,1］→ -：3-1=2［6,4,2］→ *：4*2=8［6,8］→ +：6+8=14［14］→ E(8)［14,8］→ F(2)［14,8,2］→ /：8/2=4［14,4］→ -：14-4=10［10］。答案：后缀为 A B C D - * + E F / -，值为 10（校验 6+4×(3-1)-8/2=10）。

易错点遇第二个 - 时栈顶 + 与其同级必须弹出（左结合）；后缀求值时先弹出的是右操作数，必须算 3-1 而不是 1-3；左括号只弹出不输出。

后缀表达式不含括号，运算次序由序列本身确定；同级运算符按左结合，扫描结束必须清空运算符栈。

3.3 队列

  • 队列：只允许队尾插入、队头删除的线性表，先进先出（FIFO）；典型应用为层次遍历、缓冲区、CPU 进程调度。
  • 循环队列：顺序队列表头表尾相连，避免「假溢出」。牺牲一个单元法：空 front==rear，满 (rear+1)%MaxSize==front，元素个数 (rear-front+MaxSize)%MaxSize，最多存 MaxSize-1 个。rear 含义要确认：若 rear 指向队尾元素本身，则入队先移指针后写入，个数公式变为 (rear-front+1+MaxSize)%MaxSize。考法：给 MaxSize、front、rear 求元素个数、还可入队几个、判断是否队满，或问出队若干次后指针值。结论：判空判满口诀「空则同、满则差一」，不牺牲单元时必须借助 size 计数或 tag 标记区分。

    例题容量 M=10、front=6、rear=3，队列中有几个元素？

    解析① 元素个数 = (rear−front+M) % M；② = (3−6+10) % 10 = 7 个。

    易错点直接算 rear−front 得负数；牺牲一个单元法最多只能存 M−1 个。

    拓展判满：(rear+1)%M == front；判空：front == rear。

  • 链队列：带头结点，队头在 front->next、rear 指队尾结点；出队后若变空须令 rear==front。
  • 双端队列：两端都可插入和删除；输入受限指只允许一端插入（删除可两端），输出受限指只允许一端删除（插入可两端）。判合法性：任何时刻可在已插入元素中任选允许的一端取出，逐位模拟尝试即可。例：输出受限（只允许在一端删除）时输入 1,2,3,4，4,1,2,3 合法（1 前插、2 和 3 后插、4 前插，删除端次序恰为 4,1,2,3）；4,2,3,1 非法（要 4 先出，其余元素只能是「前端插入者逆序 + 后端插入者正序」，拼不出 2,3,1）。结论：双端队列能产生的序列比栈多、比全排列少，做题先写清「哪端可删、哪端可插」。

    例题输入受限与输出受限分别指什么？

    解析① 输入受限：只允许一端插入，两端都可删除；② 输出受限：只允许一端删除，两端都可插入。

    易错点把两者的受限端记反，判断出栈序列时结论就错。

    拓展栈是只允许一端插删的双端队列特例。

循环队列用取模把线性数组首尾接起来；判满有两种套路——牺牲一个单元（front==(rear+1)%m）或另设计数器，元素个数恒为 (rear−front+m)%m。

例题循环队列存于 A[0..9]（MaxSize=10），采用牺牲一个单元法，front 指向队头元素、rear 指向队尾元素的后一位置。当前 front=5、rear=2。① 求队列中元素个数；② 还能入队几个元素；③ 再连续入队 2 个元素后是否队满？④ 在 ③ 的基础上再出队 3 个元素，求 front 与元素个数。

解析① 个数 =(rear-front+MaxSize)%MaxSize =(2-5+10)%10 = 7，校验：空位 =(front-rear-1+MaxSize)%MaxSize =(5-2-1)=2，7+2=9=MaxSize-1，正确。② 还能入队 9-7=2 个。③ 入队 2 个后 rear=(2+2)%10=4，个数 =(4-5+10)%10=9=MaxSize-1，此时 (rear+1)%10=5==front，已队满，第 10 个单元永远空着。④ 出队 3 个：front=(5+3)%10=8，个数 =(4-8+10)%10=6。答案：①7 ②2 ③队满 ④front=8、个数 6。

易错点模运算的模数是 MaxSize=10 而不是 9；个数公式是 rear 减 front（算错符号会得 -3）；队满时元素个数是 9 而非 10；③ 之后入队会覆盖未读元素。

4串★★13 考点▼

4.1 概念与存储结构

  • 串：零个或多个字符组成的有限序列，属线性表；空串长度 0，空格串长度等于空格个数，二者不同。
  • 子串与位置：主串中任意连续字符构成的序列为子串，其位置用首字符在主串中的位序（从 1 起）表示。
  • 子串个数：长度为 n 的串共有 n(n+1)/2+1 个子串（含空串），如 "abc" 共 7 个。
  • 存储结构：定长顺序存储（0 号单元存长度或末尾加 '\0'，超长截断）、堆分配存储（malloc 动态申请）、块链存储（密度低）。
  • 基本操作：赋值、复制、判空、比较（字典序，长度相同逐字符比）、串联接、求子串、定位 Index(S,T,pos)，定位即模式匹配。

4.2 朴素模式匹配（BF）

  • 算法过程：主串指针 i、模式串指针 j 均从 1 起逐位比较；失配时 i=i-j+2、j=1，整趟重比。
  • 最坏比较次数：共 n-m+1 趟、每趟最多 m 次，即 (n-m+1)m，时间复杂度 O(nm)；最好 n 次。
KMP 利用模式串已匹配前缀的相等前后缀，避免重复比较；主串指针始终向右。

4.3 KMP 算法

  • KMP 思想：朴素算法的浪费在于失配后主串指针回退、已匹配的前缀信息被丢弃；KMP 用模式串自身的最长相等前后缀信息决定回退位置，使主串指针 i 永不回退，只让模式串右滑。做法是预处理出 next 数组，失配时令 j=next[j]，i 不动。因此 KMP 的比较次数只与 n、m 有关，与主串内容基本无关。

    例题朴素匹配与 KMP 的核心区别是什么？

    解析① 朴素：失配后主串指针回退到 i−j+2；② KMP：主串指针不回退，模式串按 next 右滑继续比。

    易错点说 KMP 主串指针也要回退——那正是 KMP 要消除的浪费。

    拓展KMP 利用模式串自身的前后缀信息，避免重复比较已匹配部分。

  • next[j] 定义：next[j] = 模式串前 j-1 个字符中最长相等前后缀（真前缀=真后缀）的长度 +1，规定 next[1]=0；它表示失配于第 j 位时，模式串应从哪一位继续与主串当前字符比较。手算三步：取前 j-1 个字符 → 找最长相等前后缀长度 L → next[j]=L+1。另有 next[j]=k 说明 p[1..k-1]=p[j-k+1..j-1]。

    例题模式串 ababaa 的 next 数组（下标从 1 起）是什么？

    解析① next[1]=0；② next[2..6] = 0,1,1,2,3,4。

    易错点把 next 定义成「最长相等前后缀长度」，与题给的下标口径不一致。

    拓展不同教材 next 从 0 或从 1 开始，做题先确认下标起点。

  • 失配移动规则：失配于 j 位右移 j-next[j]、j 回 next[j]，i 不动；next[j]=0 则 i 后移 1、j 置 1，起始位 i-m+1。
  • nextval[j] 求法：next 仍有冗余——若回退到的字符与失配字符相同，则必然再次失配。nextval 规定：nextval[1]=0；若 p[j]==p[next[j]]，则 nextval[j]=nextval[next[j]]（一路继承，跳过必然失配的比较）；否则 nextval[j]=next[j]。注意递推时取的是 nextval[next[j]] 而非 next[next[j]]。考试中模式串字符重复越多，nextval 与 next 差别越大。

    例题为什么需要 nextval？举一个例子。

    解析① 若回退到的字符与失配字符相同，回退后必然再次失配；② 如 aaaab，next 回退仍遇 a，nextval 直接跳到更前的位置。

    易错点以为 nextval 与 next 完全等价，只是写法不同。

    拓展nextval 省掉无效比较，实际运行更快。

next[j] 的含义是失配后模式串该跳到哪一位，主串指针不回退；手算口诀：看前 j−1 位的最长相等前后缀长度再加 1。

例题模式串 p = "ababaa"（位序 1~6），求 next 与 nextval 数组。

解析① next[1]=0；j=2 前 1 位 "a" 无真前后缀，L=0 → 1；j=3 前 2 位 "ab" 无 → 1；j=4 前 3 位 "aba"，最长相等前后缀 "a" L=1 → 2；j=5 前 4 位 "abab"，"ab" L=2 → 3；j=6 前 5 位 "ababa"，"aba" L=3 → 4。得 next = 0 1 1 2 3 4。 ② nextval[1]=0；j=2: p2='b'≠p[1]='a' → 1；j=3: p3='a'=p[next[3]]=p1='a' → nextval[3]=nextval[1]=0；j=4: p4='b'=p[next[4]]=p2='b' → nextval[4]=nextval[2]=1；j=5: p5='a'=p[next[5]]=p3='a' → nextval[5]=nextval[3]=0；j=6: p6='a'≠p[next[6]]=p4='b' → nextval[6]=next[6]=4。得 nextval = 0 1 0 1 0 4。 ③ 失配于 j=5 时模式串右移 j-nextval[j]=5-0=5 位，j=6 失配时右移 6-4=2 位。

易错点一是 j=6 忘了「长度 +1」，把 next[6] 写成 3；二是 j=4 用 nextval[next[4]]=nextval[2]=1，误写成 next[next[4]]=next[2]=1 后继续混用 next 与 nextval 两套值。

  • KMP 复杂度：求 next 数组 O(m)，匹配过程 O(n)（i 只增不减、j 的回退总量不超过其增长量，均摊分析），总时间 O(n+m)，空间 O(m)。这是 KMP 优于朴素 O(nm) 的关键结论，选择题常直接考复杂度与「i 是否回退」。

    例题KMP 的时间复杂度是多少？为什么能达到 O(n+m)？

    解析① 求 next 数组 O(m)，匹配 O(n)；② 主串指针 i 只增不减，j 的回退总量不超过 i 的增量。

    易错点答成 O(n·m)，那是朴素匹配的复杂度。

    拓展空间复杂度 O(m)，用于存放 next 数组。

  • next 数组的近年应用：串的最小循环节长度 = n - next[n]，且当 n % (n-next[n]) == 0 时该串由长度 n-next[n] 的循环节重复 n/(n-next[n]) 次构成（否则需在末尾补字符才成周期串）。此类题 2020 年后频繁出现，实质仍是 next 手算。

    例题串 s 长度为 n，怎样求最小循环节长度和循环次数？

    解析① 最小循环节长度 = n − next[n]；② 若 n % (n−next[n]) == 0，循环次数 = n/(n−next[n])。

    易错点忘记先判断能否整除，直接给出循环次数。

    拓展这是 408 近年新增考法，常与字符串匹配综合出题。

例题主串 S = "aaaaaaaaab"（n=10，仅第 10 位为 b），模式串 T = "aaab"（m=4）。分别求朴素匹配与 KMP（用 nextval）成功时的字符比较次数。

解析① 朴素：每趟前 3 位必匹配、第 4 位必失配，共 n-m+1=7 趟，每趟 4 次比较，总 7×4=28 次（正好达到最坏值 (n-m+1)m）。 ② T 的 next = 0 1 2 3（前 3 位都是 a，前后缀逐位相等），nextval = 0 0 0 3（p2=p1、p3=p2 故一路继承 0；p4='b'≠p[3]='a' 故取 next[4]=3）。 ③ KMP：i=1,2,3 依次匹配成功（3 次）；i=4 时 T4='b' 与 S4='a' 失配 → j=nextval[4]=3、i 不回退。此后 i=4~9 每个字符都是「先与 T4 比失败 1 次、再与 T3 比成功 1 次」共 2 次，计 6×2=12 次（含 i=4 的失配）；i=10 时 S10='b'=T4 成功 1 次，j=5>m 结束。 ④ 总比较次数 3+12+1=16 次，远少于朴素的 28 次。

易错点数次数时把 i=4 的首次失配既算进「3 次成功之后」又重复算进「6 个字符各 2 次」里，多出 1 次；另外误以为 nextval[4]=0（其实第 4 位与回退位字符不同，应取 next[4]=3），从而算错 j 的回退路径。

重点：本章几乎只考两件事——手算 next / nextval（给定位序从 1 起，next[1]=0）与两种算法的最坏比较次数、时间复杂度对比；nextval 是 next 的优化版，答案要写全两组数。
易错：next[1]=0 是「位序从 1 起」的教材约定；若题目数组下标从 0 起（存 p[0..m-1]），则 next[0]=-1、整体左移一位，数值全部不同。答题前必须先看清数组下标起点，否则整题作废。

5.1 基本性质与存储

  • 树的术语：结点的度是孩子个数，树的度为各结点度的最大值；层次从根为第 1 层起算，高度（深度）即最大层次，路径是自上而下的结点序列。
  • 结点数与度的关系：总结点数 = 所有结点度数之和 + 1 = 边数 + 1；任意非空二叉树恒有 n₀ = n₂ + 1，与 n₁ 无关。
  • 二叉树五大性质：第 i 层最多 2^(i-1) 个结点；高度 h 的二叉树最多 2^h-1 个结点、最少 h 个；n 个结点的高度最小为 ⌈log₂(n+1)⌉；任何非空二叉树恒有 n₀=n₂+1。常见考法：给出 n₀、n₁、n₂ 中的两个求第三个，或给出总结点数与度分布列方程求各度结点数。结论：把「结点数 = 边数 + 1 = 度数之和 + 1」与 n₀=n₂+1 联立，任何性质题都可解，不必死记公式。

    例题一棵二叉树有 20 个叶结点、30 个度为 1 的结点，求总结点数。

    解析① 由 n₀=n₂+1 得 n₂=20−1=19；② n=n₀+n₁+n₂=20+30+19=69。

    易错点把「度为 1 的结点」硬套进 n₀=n₂+1，其实该式与 n₁ 无关。

    拓展改问边数 = n−1 = 68；或给 n 与 n₁ 反求 n₀。

  • 完全二叉树性质：n 个结点时高度 h = ⌊log₂n⌋ + 1；按层序从 1 编号，结点 i 的左孩子为 2i、右孩子为 2i+1、双亲为 ⌊i/2⌋，i > ⌊n/2⌋ 的结点均为叶子，叶子数 = n - ⌊n/2⌋。度为 1 的结点至多 1 个：n 为偶数时 n₁=1，n 为奇数时 n₁=0。考法：给 n 求 n₀、n₁、n₂ 与高度，或反向由 n₀ 求 n、求某结点的双亲或孩子编号。结论：先由 n 的奇偶定出 n₁，再用 n₀+n₁+n₂=n 与 n₀=n₂+1 联立，一步到位。

    例题1000 个结点的完全二叉树，求叶子数、n₁ 与高度。

    解析① n 为偶数故 n₁=1；② 由 n₀=n₂+1 与 n₀+n₁+n₂=n 得 n₀=500；③ h=⌊log₂1000⌋+1=10。

    易错点n 为偶数时 n₁=1 不是 0；高度别死记 ⌈log₂n⌉。

    拓展用编号法可秒求结点 i 所在层数 = ⌊log₂i⌋+1。

  • 存储结构：顺序存储只适合完全二叉树；二叉链表 n 个结点有 2n 个指针域、n+1 个空链域（线索化来源），三叉链表多 parent 域。
结点 i 的左孩子 2i、右孩子 2i+1、父结点 ⌊i/2⌋，数组下标 1 起存才有此公式；结点 4、5 的下标正好是 2i=4、2i+1=5

5.2 遍历、还原与线索二叉树

  • 四种遍历：先序「根左右」、中序「左根右」、后序「左右根」、层次「逐层从左到右」；前三者用栈（递归），层次用队列，中序由根分左右两段。
  • 由遍历序列还原二叉树：先序 + 中序、后序 + 中序、层序 + 中序都能唯一确定一棵二叉树，而先序 + 后序不能唯一确定（无法区分单孩子是左还是右）。方法固定：先序首元素（或后序末元素、层序首元素）即根 → 在中序中找到该根，其左为左子树、右为右子树 → 按中序左右段的结点个数切分另一序列 → 对两段递归重复。常见考法：给两序列求第三序列、画出树形、求某结点的双亲/孩子或树的高度。结论：中序序列不可缺，它负责「分左右」，先序或后序只负责「定根」。

    例题先序 ABDECF、中序 DBEAFC，求后序序列。

    解析① A 为根，中序左段 DBE、右段 FC；② 左子树先序 BDE → 根 B，左 D 右 E；③ 右子树先序 CF → 根 C，左 F。后序 D E B F C A。

    易错点以为先序 + 后序也能唯一确定——单孩子时无法区分左右。

    拓展层序 + 中序同样可还原，层序首元素定根。

  • 非递归遍历：先序入栈前访问，中序压栈到底再弹出访问，后序需记录上一个访问结点（或双栈、逆序法）；时间 O(n)，空间 O(h)。
  • 线索二叉树：用 n+1 个空链域存放遍历次序下的前驱与后继，ltag=1 时 lchild 指向前驱、rtag=1 时 rchild 指向后继，按遍历次序分为先序、中序、后序线索树。中序线索树求后继：若 rtag=0（有右孩子）则取右子树中最左下的结点，否则 rtag=1 由线索直接给出；求前驱对称，取左子树最右下的结点。考法：画线索、判断某结点的线索指针指向谁、写出线索树的中序遍历序列。结论：先序线索找前驱、后序线索找后继仍需遍历或借助父指针，故这类题常用三叉链表；中序线索最常用，可不用栈完成中序遍历。

    例题n=100 的二叉树线索化后，可用的空指针域有多少个？

    解析① 指针域共 2n=200；② 非空指针数 = 边数 = n−1 = 99；③ 空域 = 200−99 = 101 = n+1。

    易错点把 ltag=1 当成「有左孩子」，实际 1 表示指向遍历前驱。

    拓展中序线索树找后继：rtag=0 走右子树最左结点，rtag=1 直接取 rchild。

先序"根左右"、中序"左根右"、后序"左右根"；中序序列 + 先序/后序/层次任一即可唯一还原树

5.4 哈夫曼树与查找树

  • 哈夫曼树与哈夫曼编码：每次从集合中取权值最小的两棵树合并成一棵新树（新权为二者之和），重复 n-1 次即得 WPL 最小的二叉树；哈夫曼树没有度为 1 的结点，n 个叶子共 2n-1 个结点。WPL = 每个叶子的权值 × 其路径长度之和，也等于所有合并产生的新结点权值之和，两种算法结果必然相同。约定左分支为 0、右分支为 1，从根到叶的路径即该字符编码；因字符只出现在叶子上，故必为前缀码，编码总长恰等于 WPL。考法：构造哈夫曼树、算 WPL、写各字符编码、比较定长编码与哈夫曼编码的位数、判断一组编码是否为前缀码。结论：同一权值集合的哈夫曼树形态与编码可不唯一（等权时左右可互换），但 WPL 唯一。

    例题权值集合 {2,3,5,7}，构造哈夫曼树并求 WPL。

    解析① 合并 2+3=5；② 剩 {5,5,7}，合并 5+5=10；③ 剩 {7,10}，合并 17；WPL=5+10+17=32。

    易错点WPL 是带权路径长度之和，不是权值直接相加；合并后的新权必须放回集合。

    拓展n 个叶子的哈夫曼树共 2n−1 个结点，且没有度为 1 的结点。

  • 二叉排序树：左子树 < 根 < 右子树，中序遍历必得递增序列；查找插入平均 O(log₂n)，单支树 O(n)；删除分三种情形。
  • 平衡二叉树（AVL）与旋转：任一结点的平衡因子（左子树高减右子树高）绝对值不超过 1，故树高为 O(log₂n)。插入后自底向上找到第一个失衡结点，只调整以它为根的最小不平衡子树即可：LL 型做一次右单旋、RR 型做一次左单旋、LR 型先左旋再右旋、RL 型先右旋再左旋。判断类型看失衡结点到新插入结点路径上前两步的方向，两步同向为 LL/RR，异向为 LR/RL。考法：给插入序列求最终树形、求旋转后某结点的左右孩子、求高度 h 的 AVL 最少结点数（N(h)=N(h-1)+N(h-2)+1）。结论：一次插入最多调整一次（祖先随之自动恢复平衡），而删除可能需要沿路径多次调整。

    例题依次插入 1,2,3,4,5 建成 AVL 树，求最终树高与根。

    解析① 插 3 时 RR 失衡，左旋得根 2；② 插 4 后失衡，左旋得根 3；③ 插 5 再左旋得根 4，树高 3。

    易错点只盯插入点的父结点；应从插入点自底向上找「第一个」失衡结点。

    拓展高度 h 的 AVL 最少结点数 N(h)=N(h−1)+N(h−2)+1。

6.1 基本概念

  • 完全图与度边关系：无向完全图 n(n-1)/2 边、有向 n(n-1) 弧；Σdeg(v)=2e，Σ入度=Σ出度=e，奇度顶点为偶数个。

  • 邻接矩阵：n×n 数组，空间 O(n²)，判两顶点是否相邻 O(1)；无向图矩阵对称、第 i 行非零个数即顶点 i 的度，适合稠密图。

  • 十字链表与邻接多重表：有向图用十字链表可同时高效求入度与出度，无向图用邻接多重表每条边只存一个结点、便于删边。

6.3 图的遍历

  • BFS 与 DFS：BFS 借助队列按层向外扩展，DFS 用递归或栈一条路走到底再回退。时间复杂度相同：邻接表 O(n+e)，邻接矩阵 O(n²)（每访问一个顶点都要扫整行找邻接点），空间均为 O(n)。BFS 能求无权图单源最短路（按层数即边数），DFS 常用于判环、求连通分量与拓扑排序。二者序列都不唯一，由存储结构（邻接点次序）和起始顶点决定。

    例题6 个顶点 7 条边的无向图用邻接矩阵存储，从 v1 出发 BFS，求时间复杂度和访问特点。

    解析① 邻接矩阵每访问一个顶点要扫一整行，时间 O(n²)；② 队列按层扩展，同层顶点按编号先后入队。

    易错点把邻接矩阵与邻接表的复杂度记反：邻接表才是 O(n+e)。

    拓展BFS 可求无权图的单源最短路径（边数最少的那条）。

  • 遍历与连通性：非连通图调用遍历次数等于连通分量数；BFS 生成树高度最小，DFS 生成树可能是一条链；一次遍历访问全部顶点即连通。

6.4 最小生成树

  • Prim 算法（稠密图）：从任一顶点出发，每轮把「到已选顶点集合距离最小的顶点」连同那条边并入，直到取满 n-1 条边。实现上维护 lowcost[] 数组，每轮选最小 O(n)、更新 O(n)，共 n-1 轮，总时间 O(n²)，只与顶点数有关，故适合稠密图。MST 的边权之和唯一，但存在等权边时选边次序可不同，树形可能不唯一。

    例题4 顶点图：v1v2=1、v1v3=3、v2v3=2、v2v4=4、v3v4=5，从 v1 起求 MST 权值。

    解析① 选 v1v2=1；② 集合 {v1,v2} 的最小出边 v2v3=2；③ 再选 v2v4=4；合计 1+2+4=7。

    易错点每轮只在「一端已选、一端未选」的边里取最小，不是取全局最小边。

    拓展Prim 适合稠密图（O(n²)），Kruskal 适合稀疏图（O(e log e)）。

  • Kruskal 算法（稀疏图）：把全部边按权递增排序，依次取边，只有当两端点不属于同一集合（并查集 Find(u)≠Find(v)）时才加入并合并，凑满 n-1 条边为止。时间 O(e·log e)（排序主导），与顶点数关系小，适合稀疏图。若图不连通，算法结束时得到的是生成森林而非生成树。

    例题同一张图用 Kruskal 求 MST，写出选边顺序。

    解析① 边按权排序 1,2,3,4,5；② 依次取 1、2；③ 取 3 时 v1v3 与已选边成环，跳过；④ 取 4，合计 7。

    易错点不用并查集判环，结果会选出一棵带环的「树」。

    拓展存在相同权值时 MST 不唯一，但总权值唯一。

  • 并查集：双亲数组实现，Find 找根、Union 合并；按秩合并 + 路径压缩后单次近似 O(α(n))，是 Kruskal 判环工具。
>

6.5 最短路径

  • Dijkstra（单源最短路）：设 S 为已确定最短路的顶点集，每轮从 V-S 中选 dist 最小的顶点 u 加入 S，再用 u 松弛其出边 dist[v]=min(dist[v], dist[u]+w)。邻接矩阵实现 O(n²)（选最小 O(n) + 松弛 O(n)，共 n-1 轮）。要求边权全部非负：存在负权边时，已入 S 的顶点仍可能被更短路径改写，算法失效。顶点进入 S 的次序就是其最短路长度的递增次序。

    例题v1 起求到各点最短路：v1v2=10、v1v5=5、v2v5=2、v5v4=2、v4v3=6、v2v3=3。

    解析① 先定 v5=5；② 经 v5 更新 v2=7、v4=7；③ 经 v2 更新 v3=10，经 v4 更新 v3=13，取 10。

    易错点每轮忘了「从 V−S 中选 dist 最小的顶点」，顺序一乱结果全错。

    拓展边权有负值时 Dijkstra 失效，应改用 Floyd 或 Bellman-Ford。

  • Floyd（多源最短路）：A[i][j]=min(A[i][j],A[i][k]+A[k][j])，O(n³)、O(n²)，允许负权、禁负权回路，初值 0/∞。
每轮只做两件事：在未确定顶点里挑 dist 最小的并入 S（表中加粗值），再用它松弛邻居；选中顺序即最短路径的生成顺序。
>

6.6 拓扑排序与关键路径

  • 拓扑排序：在 AOV 网中反复「输出一个入度为 0 的顶点，并删除它的全部出边（邻接点入度减 1）」，可用栈或队列暂存入度为 0 的顶点，邻接表实现 O(n+e)。结果一般不唯一：同一时刻有多个入度为 0 的顶点时，不同出栈次序得到不同合法序列。若最终输出的顶点数小于 n，说明剩余顶点入度均不为 0，即存在有向环，该 AOV 网不是 DAG，工程不可行。

    例题一个 AOV 网求拓扑序列，并判断序列是否唯一。

    解析① 反复输出入度 0 的顶点并删除其出边；② 若中途找不到入度 0 的点，说明有环；③ 每步只有唯一入度 0 顶点时序列才唯一。

    易错点默认「拓扑序列唯一」，其实只有全序（每步唯一候选）时才唯一。

    拓展也可用 DFS 求逆后序得到拓扑序列，时间 O(n+e)。

  • 关键路径（AOE 网）：事件最早发生时间正推取最大 ve(v)=max{ve(u)+w(u,v)}，最迟发生时间逆推取最小 vl(u)=min{vl(v)-w(u,v)}，汇点 ve=vl= 工期。活动最早开始 e=ve(弧尾)，最迟开始 l=vl(弧头)-w，l-e=0 者为关键活动。关键路径是从源点到汇点的最长路径，长度即工期，可能不止一条。加快某个关键活动可能缩短工期，但一旦它不再是关键活动，工期就由别的路径决定，需重新计算。

    例题AOE 网求工期与关键活动。

    解析① ve 正推取 max；② vl 逆推取 min；③ 满足 e(i)=l(i) 的活动即关键活动。

    易错点把 ve 取 max、vl 取 min 记反；关键路径可能不止一条。

    拓展缩短非关键活动不改变工期；缩短关键活动可能产生新的关键路径。

>
重点：图的应用四问对应四种算法——最小生成树（Prim 稠密 / Kruskal 稀疏）、单源最短路（Dijkstra，非负权）、多源最短路（Floyd）、有向无环图（拓扑排序 + 关键路径），考试常以「给图算过程」形式出现，必须能写全中间量。
记忆：选算法口诀「稠密 Prim、稀疏 Kruskal；单源 Dijkstra、多源 Floyd；无权最短路用 BFS」；关键路径口诀「ve 正推取大、vl 逆推取小，e 看尾、l 看头减权」。
易错：Prim 与 Dijkstra 形式极像，但 Prim 的 lowcost 是「到已选集合的最短边权」、Dijkstra 的 dist 是「从源点出发的累计路径长」，且 Dijkstra 一旦入 S 不再修改。
易错：最小生成树的权值之和唯一但树形可能不唯一；BFS/DFS 序列、拓扑序列也不唯一，题目未指定存储结构或邻接点次序时，按顶点编号升序作答并说明前提。
7查找★★★14 考点▼

7.1 基本概念与顺序查找

  • ASL：平均查找长度 ASL=Σpᵢcᵢ，等概率 pᵢ=1/n；成功/失败 ASL 分开算，分母为 n 与失败区间数。
  • 顺序查找：逐个比较，无有序性要求；成功 ASL=(n+1)/2，失败无序表 n、有序表 n/2（精确 n/2+n/(n+1)），O(n)。

7.2 折半查找

  • 折半查找（二分）：只适用于顺序存储且关键字有序的表——链表无法随机定位中点，不能折半。每比较一次区间减半，比较次数不超过 ⌈log₂(n+1)⌉，时间 O(log₂n)、空间 O(1)。把每次 mid 的取法画成树即判定树：它是平衡二叉树而不是完全二叉树，n 个结点时树高 ⌈log₂(n+1)⌉、外部（失败）结点恰 n+1 个。计算套路固定：成功 ASL=Σ(层号×该层结点数)/n；失败 ASL=Σ(失败结点所在层号)/(n+1)，层号即该次失败的比较次数。

    例题有序表 A[1..11]=(7,14,18,21,23,29,31,35,38,42,46)，查找 30，比较几次后失败？

    解析① low=1,high=11，mid=6 得 29<30，去右半；② low=7,high=11，mid=9 得 38>30，去左半；③ low=7,high=8，mid=7 得 31>30，high=6<low，失败。共 3 次。

    易错点把最后判定 low>high 也算一次比较，次数多算 1。

    拓展判定树是一棵平衡二叉树，失败时最多比较 ⌈log₂(n+1)⌉ 次。

  • 判定树性质：左右子树结点数差 ≤1 故平衡，中序得有序序列，同层尽量满时 ASL 最小；n 相同则折半 ASL 唯一，随 mid 取整略异。
>

7.3 分块查找

  • 分块查找：块间有序、块内无序；ASL=Lᵢ+L_b，ASL=(b+1)/2+(s+1)/2，s=√n 最优 ASL≈√n+1。

7.4 树形查找：BST、AVL、B 树、B+ 树

  • 二叉排序树（BST）：左小右大、中序递增；查找 ASL 取决于树形，最好 O(log₂n)、最坏退化成单支链 O(n)，故需平衡化。
  • 平衡二叉树（AVL）：任一结点左右子树高度差（平衡因子）绝对值 ≤1，查找、插入、删除均 O(log₂n)。插入后失衡只可能是最小失衡子树根处，按插入位置分 LL/RR/LR/RL 四种：LL、RR 单旋一次，LR、RL 双旋（先对子树旋、再对根旋），旋转后该子树高度复原，故插入最多调整一次。高度 h 的 AVL 最少结点数满足 n_h=n_{h-1}+n_{h-2}+1，n_0=0,n_1=1,n_2=2，故 n_3=4,n_4=7,n_5=12,n_6=20；反之含 n 个结点的 AVL 高度不超过 1.44log₂(n+2)。常考：给插入序列画出最终树、判平衡因子、求「高度 h 至少几个结点」。

    例题依次插入 3,2,1,4,5 建 AVL，求最终根与高度。

    解析① 插 1 时 RR 失衡 → 左旋，根变 2；② 插 4 后仍平衡；③ 插 5 时结点 3 失衡 −2 → 左旋，根变 2，结构 2(1,4(3,5))，高度 3。

    易错点盯插入点的父结点找失衡；应找「最小不平衡子树的根」。

    拓展AVL 删除可能沿路径多次旋转，插入最多一次。

  • m 阶 B 树：最多 m 子树、m-1 关键字；非根关键字 ⌈m/2⌉-1~m-1，叶同层；树高 log_⌈m/2⌉((n+1)/2)+1。
  • B 树插入分裂：插入总发生在叶结点；若插入后关键字数超 m-1，取中间关键字（⌈m/2⌉ 位置）上移到父结点，其余左右两半各成一个结点，被上移的关键字在父结点中仍按序插入。若父结点也超限则继续分裂，可能连锁到根；根分裂时中间关键字升为新根，树高 +1——这是 B 树唯一长高的方式。删除时关键字数不足 ⌈m/2⌉-1 才调整：先向兄弟借（经父结点周转），兄弟也刚好够则与兄弟合并，可能连锁合并使树高减 1。

    例题5 阶 B 树依次插入 1~8，说明分裂过程。

    解析① m=5 时每个结点最多 4 个关键字；② 结点满 4 个再插第 5 个 → 取 ⌈m/2⌉=3 位关键字上移；③ 插入 5 时 3 上移，分成 1,2 与 4,5；插到 8 时 6 再上移。

    易错点以为要先分裂再插入；实际是先插入使关键字达 m 个再分裂。

    拓展根分裂时树高加 1；非根结点关键字数在 ⌈m/2⌉−1 ~ m−1 之间。

  • B+ 树：叶结点存记录，非叶仅索引、关键字为子树最大（或最小）关键字副本；n 关键字分支有 n 棵子树；叶链接成有序链表，支持范围查询。
看图记三步：插入找叶 → 叶满 取中位数上移分裂 → 根也满则根再分裂、树高 +1；1~7 插完根为 [4]，共 3 层。
对比项B 树B+ 树

7.5 散列表

  • 散列函数与装填因子：除留余数法 H(key)=key%p（p 取不大于表长 m 的最大质数）；α=n/m，ASL 只取决于 α、与表长无关。
  • 冲突处理（开放定址：线性探测）：冲突时按 Hᵢ=(H(key)+i)%m 依次向后找空位（i=1,2,…，到表尾回绕），查找时遇空单元才算失败。优点是不额外开空间、可用公式估算 ASL；缺点是会产生堆积（聚集）——不同散列地址的记录连成一片，使后续冲突概率增大、ASL 升高，故有平方探测、双散列、再散列等改进。删除时不能直接置空，必须打「删除标记（墓碑）」，否则会截断探测链，使后面的同义词被误判为不存在。常考：按给定序列建表 → 逐个数比较次数求成功 ASL → 再对散列函数每个取值求失败 ASL（分母是值域大小）。

    例题H(key)=key mod 7，依次插入 7,8,30,11,18,9,14，求线性探测的 ASL。

    解析① 7→0、8→1、30→2、11→4 各 1 次；② 18 冲突占 5（2 次）、9 冲突占 3（2 次）；③ 14 冲突占 6（4 次）。合计 12，ASL=12/7≈1.71。

    易错点ASL 的分母用表长 m；应为元素个数 n。探测次数含第一次。

    拓展拉链法 ASL≈1+α/2；开放定址删除要打标记，不能直接清空。

  • 拉链法（链地址法）：同义词链成单链表，无堆积、删除方便，适合冲突多且 α>1；失败 ASL 按链长统计；开放定址要求 α<1。
>

7.6 并查集

  • 并查集（Union-Find）：用双亲数组 parent[] 表示森林，根满足 parent[r]=r（或 -1），同一集合即同一棵树。Find 沿双亲指针上溯至根，Union 把一棵树的根挂到另一棵的根下。朴素实现可能退化成单链，使 Find 达 O(n)；两种优化：按秩/按大小合并（小树挂大树，树高不超 ⌈log₂n⌉+1）与路径压缩（Find 时把路径上所有结点直接挂到根，形成两层「菊花」树）。两者合用后 Find/Union 的均摊时间近 O(1)（O(α(n))）。常考：给 parent 数组画集合树、写出一次 Find 后数组的变化、统计连通分量数（根个数）、Kruskal 判环。

    例题n=6 依次执行 Union(1,2)、Union(3,4)、Union(2,3)，求集合数与 Find(4) 的结果。

    解析① 前两次各成一棵树；② Union(2,3) 把两棵合并成 {1,2,3,4}；③ Find(4) 沿 parent 找到根 1；集合数 6−3=3。

    易错点只读 parent[4] 就当根，忘记沿链一直找到根。

    拓展按秩合并 + 路径压缩后单次操作近似 O(α(n))。

易错折半判定树是「平衡二叉树」不是「完全二叉树」；失败结点数为 n+1，失败 ASL 的分母是 n+1 而非 n。
易错散列表 ASL 必须按题目指定的探测方式逐个数比较次数；开放定址删除要打删除标记；B 树只有「根分裂」才使树高 +1，删除只有「根只剩一个关键字且子女合并」才使树高 −1。
记忆B 树关键字范围记「⌈m/2⌉-1 ~ m-1」，子树数「关键字数 +1」；B+ 树「叶子全、链相连、必到底」；AVL 四种旋转「同号单旋、异号双旋」。
重点：折半判定树 ASL、散列表成功/失败 ASL 是全章两大必考计算题，务必按层号与探测次数逐项列清再求和；B 树插入分裂、AVL 调整是必考画图题。
8排序★★★13 考点▼

8.1 基本概念

  • 稳定性：关键字相同的记录排序后相对次序不变则稳定。稳定：插入、冒泡、归并、基数；不稳定：希尔、快排、简单选择、堆排序。
  • 分类：内部排序（数据全在内存）与外部排序（数据需借外存）；按思想分插入、交换、选择、归并、基数五类。

8.2 插入类排序

  • 直接插入：把待排元素插入前面已有序区，从后往前边比较边后移。最好情况（原已有序）比较 n-1 次、移动 0 次，时间 O(n)；平均与最坏时间 O(n²)，空间 O(1)，稳定。常见考法：给序列求某趟后的中间状态、求比较/移动次数。结论：n 很小时（n<20 左右）它是最实用的方法，故快排小区间常改用它。

    例题对 (49,38,65,97,76,13,27) 做直接插入排序，写出第 3 趟后的结果。

    解析① 38 插入 → 38,49；② 65 → 38,49,65；③ 97 → 38,49,65,97。

    易错点把「趟」当成「比较次数」；一趟只把第 i 个元素插入前面有序区。

    拓展已有序时只比较不移动，最好 O(n)；稳定排序。

  • 折半插入：先用折半查找定插入位置再统一后移。比较次数降为 O(nlog₂n)，但移动次数仍是 O(n²)，时间 O(n²)，稳定。
  • 希尔排序：按增量 d 分组插入，d 递减至 1。不稳定，约 O(n^1.3)，空间 O(1)；增量须以 1 收尾，只能顺序存储。

8.3 交换类排序

  • 冒泡排序：相邻逆序即交换，每趟送极值到一端。加标志后最好 O(n)，最坏比较 n(n-1)/2 次、O(n²)，空间 O(1)，稳定。
  • 快速排序一趟划分：取枢轴 pivot，双指针 low/high 交替「挖坑填数」——high 向左找小于 pivot 者填入 low 坑，low 向右找大于 pivot 者填入 high 坑，最后把 pivot 放进相遇位置。一趟划分后 pivot 已到最终位置且此后不再移动，左侧全小于、右侧全大于（等于者可在任一侧）。每趟至少确定一个元素位置，这是快排与堆排的共有性质；n 个元素共需 n-1 趟递归。平均 O(nlog₂n)，最坏 O(n²)（原序列基本有序或逆序、枢轴总取到极值），空间为递归栈 O(log₂n)、最坏 O(n)，不稳定。

    例题对 (46,79,56,38,40,84) 以 46 为枢轴做一趟划分。

    解析① high 从右找到 40 填到低位；② low 从左找到 79 填到高位；③ 交替直到 low=high，枢轴落位。结果 (40,38,46,56,79,84)。

    易错点用「交换」代替「挖坑填数」，中间过程与最终落位都错。

    拓展平均 O(n log n)、最坏 O(n²)（已有序且取首元素为轴）、不稳定。

挖坑法：high 找小于枢轴者填 low 坑，low 找大于枢轴者填 high 坑，最后枢轴入位，落位后左边全小于它、右边全大于它；一趟只确定枢轴最终位置，不产生有序子序列
>

8.4 选择类排序

  • 简单选择：每趟选最小者与首元素交换。比较恒为 n(n-1)/2、与初态无关，O(n²)，空间 O(1)，不稳定。
  • 堆排序：堆是完全二叉树且每个结点不小于（大根堆）或不大于（小根堆）其孩子，用数组顺序存储，i 的孩子为 2i、2i+1，父为 ⌊i/2⌋。建堆：从 ⌊n/2⌋ 号结点起倒序逐个「向下调整」（与较大孩子比较交换并继续下沉），总代价 O(n)。排序：堆顶与末尾交换、堆长度减 1、再对新堆顶向下调整，共 n-1 次，总时间 O(nlog₂n)，空间 O(1)，不稳定。常见考法：给序列建堆、求建堆后数组、删除堆顶后调整、判是否为大/小根堆。结论：适合从大量数据中取前 k 个最值（n 大 k 小时优于快排）。

    例题对 (46,79,56,38,40,84) 建大根堆。

    解析① 从 ⌊n/2⌋=3 号结点开始下沉：56 与 84 交换；② 79 已最大；③ 46 与 84 交换后再与 79 比较。结果 (84,79,56,38,40,46)。

    易错点从根开始调整；建堆必须从最后一个非叶结点 ⌊n/2⌋ 往前逐个下沉。

    拓展建堆 O(n)、整体 O(n log n)、空间 O(1)、不稳定；Top-K 常用堆。

>

8.5 归并与基数排序

  • 归并排序：相邻有序段两两归并，需 ⌈log₂n⌉ 趟，恒 O(nlog₂n)，空间 O(n)，稳定。
  • 基数排序：不比较关键字，按位 LSD「分配—收集」d 趟，O(d(n+r))，空间 O(r)，稳定。

8.6 外部排序

  • 多路归并：m 个初始归并段做 k 路归并，趟数 s=⌈log_k m⌉，总读写次数约 2(s+1)×数据总块数。增大 k 或减少 m 都能显著减少磁盘 I/O（I/O 是外排的瓶颈）；k 增大后内部比较次数上升，用败者树可把每次选最小者的比较降到 ⌈log₂k⌉，而用置换-选择可生成平均长度约 2 倍内存容量的初始段以减少 m。常见考法：给记录数与内存块数算初始段数 m、算归并趟数与 I/O 次数。

    例题100 个初始归并段做 4 路归并，需几趟？总读写多少段次？

    解析① 趟数 s=⌈log₄100⌉=4（4⁴=256≥100）；② 每趟读写各一遍，共 2×100×4=800 段次。

    易错点把趟数写成 ⌈m/k⌉；正确是 ⌈log_k m⌉。

    拓展败者树只降低内部比较次数，不减少归并趟数。

  • 最佳归并树：以各段长度为权构造 k 叉哈夫曼树，WPL 即总读写块数；段数不足时补虚段 (k-1)-(m-1)%(k-1) 个。
>
重点：比较类排序下界 Ω(nlog₂n)；堆排序是唯一「平均 O(nlog₂n) + 最坏 O(nlog₂n) + 空间 O(1)」的算法；归并排序是唯一「O(nlog₂n) 且稳定但需 O(n) 空间」的算法。
记忆：稳定性「插冒归基稳，希快选堆不稳」；时间 O(nlog₂n) 中只有快排会退化到 O(n²)；建堆 O(n)、排序 O(nlog₂n)。
易错：快排最坏出现在「基本有序/逆序」而非随机序列；一趟划分或一趟堆调整后只确定 1 个元素位置，不能据此判断整个序列已排好；基数排序空间是 O(r) 而非 O(n+r)，且必须稳定才能保证 LSD 正确。
